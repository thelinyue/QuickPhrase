## 使用

1. 聚焦目标输入区，再打开闪语。
2. 单击选中话术；双击正文将内容添加到当前输入位置。
3. 默认点击左侧发送按钮，或右键选择“直接发送”才发送。可在常用设置主动将话术双击改为直接发送；常用短语固定单击插入；已有草稿会保留，发送作用于输入区的最终内容。

支持分类、折叠分组、排序、移动／复制、标题配色、自定义快捷键、搜索、文字／图片／文件与分段。“文件”列表统一关联本地文件和云文件；新增时在独立窗口选择来源，失效记录可重新关联，移除关联不会删除原文件或云端文件。

开发工作区新增云文件改名：管理员可改全部，仍有上传权限的原上传者可改自己的文件，扩展名保持不变。“修改显示名”仅影响本机关联，“重命名云文件”修改公共名称；已有个人附件副本保持独立。改名需要新版闪云，旧服务端会明确提示升级。文件关联保存在本机，云端关联按服务器和账号隔离，切号隐藏、重新登录恢复；闪云断连时保留账号和最近目录，已缓存的关联文件离线可用；未缓存文件须联网下载，再由用户重新触发使用。详见[云文件与文件关联](docs/cloud-files-proposal.md)。


新建本机数据库后，首次主动打开窗口会展示独立“使用指引”：先创建分类、添加话术，再聚焦目标插入；搜索与快捷键、吸附、文件、账号及数据管理可按需查看。指引支持关闭按钮、Esc和“开始使用”，主菜单可随时重开。指引在前台时暂停业务快捷键，切回主窗口或目标应用即可边看边练。展示状态只保存在本机，不随切号、同步或内容导入重置；已有用户升级后从菜单查看。

“设置 → 关于 → 更换目录”可将全部本地库、设备设置、素材和缓存迁移到新的空文件夹。先保存并关闭编辑窗口，完成发送及主动文件传输，再确认“迁移并重启”；迁移期间需容纳一份完整副本。验证成功后启用新目录并自动清理原应用数据，外部关联源文件、未知文件及 WebView 数据保留。失败继续使用原目录；已启用的新目录不可访问时会明确报错，不会创建空库。默认应用目录中的 `data-directory.json` 用于定位新目录，请保留。

每个人使用普通账号登录，管理“个人话术”，需要共享时通过“共享话术 ▾”加入已授权的库。服务管理员维护账号与公共资源；库内角色为查看者、编辑者、库管理员，创建共享话术默认需授权。账号昵称及联系方式可选，已有用户名、名称和内容保持原样。主菜单提供“账号、共享话术管理、闪云中心”，服务管理员另有“账号管理”。

0.2.13将“云文件管理中心”升级为“闪云中心”，顶部切换云文件和云命令。云命令用于共享常用Linux下载／安装命令，只保存、查看和原样复制文本，不执行脚本。新旧普通账号默认关闭，管理员在独立“权限管理”中授予使用或维护权限；维护者可编辑、回收和恢复，永久删除仅管理员可执行。云命令仅在线可用，复制前核对权限与所见修订；云文件离线缓存及传输不受模块切换影响。需要配套闪云0.2.5，先备份并升级服务端，再升级客户端，详见[云命令与安全边界](docs/cloud-commands.md)。

云文件是当前闪云服务的公共文件库，完成初始改密的用户无需加入共享话术即可查看、下载和使用。上传、删除、恢复分别按账号授权；删除会移入回收站，配置权限和永久删除仅服务管理员执行。保留纯图标操作、文件系统图标、分页、传输管理和回收站；共享话术直接引用云文件，个人话术保存独立副本，下载完成不自动投递。

有上传权限时，可在选择器多选文件，或将文件拖到云文件列表／上传管理正文区直接上传。单文件为1字节至128MB，文件夹不递归上传；同一批相同路径去重，同名不同路径分别上传，无效项逐条说明原因，其他文件继续。上传管理显示等待、准备、上传和结果，可停止排队或执行中的任务。关闭窗口后继续，重开读取现有记录；准备与上传最多同时执行两个任务。切号、撤权、上传授权版本变化或离线停止旧队列；退出客户端中止未执行任务，重启只列出已经固化的待核对任务，不自动重传。

个人同步默认关闭，在“账号”预览合并后开启；个人话术、回收站、素材、常用短语及个人偏好按账号同步。退出后可继续离线编辑，同账号登录再同步，切换账号不自动带入内容。暂停只停止同步，不切换内容；旧本机内容通过“导入数据→找回旧本机内容”预览导入。多设备同步可选择本机1／3／5分钟定时检查间隔，默认1分钟，内容变更仍即时同步。账号页显示个人库的最近成功同步时间；各共享话术的时间在“共享话术管理”中查看，支持搜索及每页20个分页。共享话术缓存支持断网及离线重启使用，离线只读；退出清理共享话术缓存。说明及恢复规则见 [账号](docs/private-sync.md)。

“同步与共享”面板统一管理多设备同步、成员话术和开放共享。可共享全部分类（含今后新增分类）或指定一级分类，其他成员直接选择使用，无需逐人审批；共享范围与使用人数同行，点击人数查看昵称和用户名。每账号使用一个来源，分类只读、缓存独立；右键使用中的成员话术可设置“自定义快捷键”，仅保存在本机当前账号，不修改来源成员、不跨设备同步；正文更新保留绑定，停止使用或撤权后停止生效。离线撤销需联网生效。此功能需闪云 0.2.2，旧0.2.1镜像不支持。

话术正文使用连续图文编辑区，图片在当前光标或选区位置插入，保留前后文字与分段顺序。工具栏仅有日期、图片、文件和添加分段；每条最多9张图片、9个文件。列表及搜索结果使用18像素矢量图标：含图片优先显示图片图标，无图片但含文件时显示文件图标，移除全部媒体并保存后恢复文字图标。

从分类标题或话术行右键新增时，自动选择对应的一、二级分类；列表空白处按右键位置判断：二级分类标题至下一标题之间属于该分类，最后一组延伸到列表底部，折叠后同样适用。第一组上方或没有二级分类时，只选择当前一级分类。个人、共享话术及新增云文件使用相同规则。一级分类菜单只保留分类相关操作，账号、云文件中心和管理入口位于主菜单。

删除话术、一级／二级话术分类时，确认窗口默认勾选“移除到回收站”；取消勾选后永久删除。底部主菜单可打开回收站，支持关键词、全拼、首字母搜索和分页，显示原分类、正文、图片及附件。还原恢复原内容与分类；二级分类后来被移动时，在原位置重建所需分组，保留已移动的活动内容。快捷键冲突时保留回收记录，可明确选择不恢复快捷键后重试。文件关联和独立常用短语不进入回收站。

本地文件右键支持复制文件、修改显示名、移除关联、快速排序、移动分类、打开文件／所在位置、重新关联和刷新状态。Ctrl 单击多选、Shift 连续选择、Ctrl+A 选择当前分类；复制、移动和移除支持批量操作。文件分类支持新增、重命名、删除和快速排序。显示名修改及分类移动均不改变源文件。

首次使用不预建话术或文件分类，点击“新增一级分类”自行创建，再添加话术或关联文件。允许删除全部分类，重启后保持为空；已有分类不会因升级自动删除。一级分类和二级分类名称允许重复，各分类独立保存；分类选择框和快速排序显示同名序号，主界面标签保留原名称。雾蓝灰默认主题采用32像素单行列表、暖橙标题及柔和选中态；话术与文件悬停时显示浅灰蓝底色，移出恢复选中色，发送按钮显隐不推动文字。

在话术正文上停留350毫秒后，按参考图在真实鼠标位置右下方显示300像素宽的轻量预览，间距12像素。白底细边框，只显示标题、快捷键和正文，不使用独立标题栏、关闭按钮、底部提示和窗口阴影。优先向右下展开，空间不足时自动向左或向上显示，整个预览框保持在屏幕工作区内并避开任务栏；高度按内容及可用空间自适应。预览保留换行、图文、文件名及分段，短文按内容收紧高度，长文可进入浮层滚动查看。快速掠过或悬停发送按钮不弹出正文；移开鼠标、点击、列表滚动和Esc关闭预览，切换话术从正文开头阅读。预览窗口不激活，不改变原输入目标，主列表、主窗口搜索和底部搜索复用相同交互。

常用短语独立维护，每条为不超过 16 字的单行文字。点击“＋”新增，右键可修改、删除或打开快速排序窗口；排序支持 Ctrl 多选拖动，取消不保存，确定后两处短语栏同步更新。两处均单击插入，双击不重复提交。短语右键菜单仅含“新增个人短语、修改这个短语、删除这个短语、快速排序短语”，空白菜单只含新增和排序；菜单不提供插入或直接发送入口。左右键选择相邻项，上下键选择相邻行中最近的项，Enter 直接发送；主窗口和底部短语栏使用相同行为。

主窗口右上依次为吸附、置顶和最小化。底部按钮可分别显示／隐藏常用短语和搜索框，设置自动保存。每次手动启动都会显示主窗口；重复手动启动恢复已有窗口，包括隐藏和最小化。`--autostart`保持后台驻留，开启吸附后随已识别的企业微信主窗口或独立聊天窗口无激活地显示，不抢焦点，重复自启不解除手动隐藏。主窗口、底栏和正文预览不占任务栏，主动打开的设置、编辑及指引窗口保留任务栏入口。目标最小化、关闭或切换其他程序时侧栏与底栏一起隐藏，返回目标后恢复；使用闪语及其设置、编辑窗口时保持跟随。手动隐藏持续到再次唤起。没有可用目标时可用托盘、快捷键或重新手动启动独立打开。每次进程首次独立显示前完成定位，直接出现在唤起时当前屏幕工作区右侧，右边距12 DIP、垂直居中；同次运行内拖动后隐藏恢复、托盘唤起及重复启动保留位置。有效目标重新激活后恢复吸附；实际吸附期间不能拖动窗口或调整高度，启用自由调整后仅能调整宽度，角落拖动也只改变宽度；关闭左右吸附留在侧栏当前显示器，只有同屏才恢复原独立位置；旧位置属于其他屏幕时保留当前位置，越界时平移回当前工作区，保留吸附结束时的最新宽高，不再套用旧屏幕DPI。隐藏搜索后按 Alt+Q 会展开并聚焦；Alt+E 会显示并聚焦常用短语。

自动吸附按 `WXWork.exe` 和精确窗口类型识别主窗口及独立聊天窗口，不依赖 UI Automation 输入框，也不要求输入焦点。主窗口内切到通讯录或搜索时继续吸附；登录、独立图片／视频、搜索结果及未知类型窗口不吸附。侧栏与底栏共用目标，不向同进程的其他窗口继承吸附关系。v0.1.3 修复了 v0.1.2 拒绝真实企业微信吸附的缺陷；具体实机验证范围见验收记录。

底部短语栏的可见左右边缘与目标窗口对齐，侧栏紧贴目标可见边缘；闪语自身不可见边框按当前窗口动态补偿。底部“隐藏短语”关闭整个短语栏，菜单及新增按钮一起隐藏；可在“设置→界面设置→显示底部吸附常用短语”重新打开。底部搜索若已开启会独立保留。

侧栏移动、缩放和闲置时始终完整展开，旧“吸附时自动隐藏”“贴边显示防误触”选项已移除，旧库对应设置仍可读取。用户宽度按逻辑像素保存、按侧栏自身DPI换算，底栏内容高度按底栏自身DPI换算，跟随定位与屏幕裁剪不覆盖宽度。侧栏跟随目标可见顶部与高度，底栏跟随底边，目标部分移出屏幕时按显示器工作区裁剪。原吸附侧空间不足时，保持设置的侧边在屏幕内完整显示，必要时覆盖目标边缘。激活目标时同步侧栏层级，避免被其他普通窗口遮挡；普通目标保持普通窗口层，目标置顶时跟随置顶，关闭吸附后恢复用户置顶设置。

吸附图标开口朝左，关闭吸附时带左下至右上的斜线，开启时显示普通磁铁。置顶图标开启时实心、关闭时空心；常用短语和搜索框显示时为睁眼图标、隐藏时为斜线眼图标。这四个开关只通过图标区分状态，不叠加开启态浅色底块。界面使用直角，Windows 11 的客户端窗口外框也禁用系统圆角。

一级分类右键与右上角入口共用参考图的11项菜单，第二项为“新增二级分类”，归属菜单所指向的一级分类；“新增同级分类”新建一级分类。菜单使用直角灰底、32像素行高；二级分类保留自己的操作菜单。话术列表空白右键提供“新增话术”和“新增二级分类”，归属当前一级分类；文件列表空白右键仍为“刷新”。底部保留应用菜单。分类复制／移动的目标为其他一级分类，同名二级分组合并，内容追加到目标末尾。移动保留快捷键并移除来源分类，复制清空副本快捷键。“删除一级分类但保留话术”位于底部主菜单，话术移至明确选择的目标并取消分组；二级分类的保留删除仍位于其右键菜单，话术归入原一级分类。

一级分类标签可分别选择十二色色板或恢复默认颜色。菜单中的“设置一级分类背景色”打开设置页的“界面设置”，预选所点击的分类；已有设置窗口也会切换页面与分类。一级分类栏高度默认31像素，可设为31—200像素，增加高度后标签换行。界面设置提供标题和内容、仅标题、仅内容三种显示模式，以及默认展开／收起二级分类。

界面设置提供七种主题、10—18像素话术字体、标题默认色、个人话术／文件分类默认背景色、话术／文件标签顺序、窗口自由调整及吸附状态记忆。源码默认主题已改为[雾蓝灰](docs/theme.md)（未发布），使用中性浅色与低饱和蓝灰；七种主题共用实色主窗口上下栏、分段导航和浅色分组条，标题与一级分类统一使用暖色，快捷键沿用各自主色并叠放于话术文字区域右侧，不占正文宽度。新安装话术字号默认为14像素，已有字号保持原值。单个分类配色优先于默认色，单条话术独立颜色优先于标题默认色；空值及旧版默认橙色使用当前默认标题色或全局自定义色，不改写原记录。话术／文件分类区域分别设置31—200像素，侧边短语区域最大高度28—300像素；底部短语可限制为一、二、三行或自适应，超出内容可以滚动。关闭吸附状态记忆后，当前会话可继续吸附，下次启动不自动吸附，手动启动仍显示独立窗口。

常用设置的“最小化显示悬浮窗”默认开启，独立于“最小化到托盘”。主动最小化主窗口后显示88×34 DIP的白底“图标＋闪语”小条，使用6 DIP圆角、24 DIP图标，文字跟随主题；双击恢复主窗口，单击不打开，拖动调整位置并跨重启记忆。原生右键菜单提供“隐藏悬浮图标”“永久隐藏悬浮图标”“打开主界面（双击）”：临时隐藏只作用于本次最小化，重新打开主界面再最小化时恢复；永久隐藏关闭已有设置，可在常用设置重新开启。小条置顶且不占任务栏，显示和拖动不抢焦点；自动跟随隐藏、手动隐藏、贴边收起和其他窗口最小化不会显示小条。

打开设置或在设置内输入不会阻止主窗口贴边隐藏；主窗口自身输入、菜单、预览、拖动及发送期间仍暂停收起。贴边收起后，在其他软件内点击、右键或长按不会唤出主窗口。主搜索和底部搜索的快捷键标识只在鼠标悬停该行时显示。相同内容的后台通知不重复搜索，真实内容更新保留当前列表、选中身份与滚动位置，更新完成前暂停旧结果投递；切换账号、权限或搜索来源立即撤下旧结果。

主窗口首次使用的默认可见尺寸约306×720 DIP；调整后会记住本机逻辑宽高，重启和升级沿用，贴边隐藏、最小化不覆盖尺寸记录。跨屏保持逻辑尺寸，物理像素随显示器缩放调整。首次从未保存尺寸的旧版升级时，请保持旧客户端打开，由安装器读取尺寸并关闭；旧版已退出且没有记录时无法找回原大小。贴边期间临时置顶，悬停达到设定等待时间后自动浮出且不抢焦点；展开期间快速移入话术区不会反向收回，鼠标停留在窗口内保持展开；收起途中重新移入立即展开，不重复等待边条延时。退出贴边恢复原置顶设置。主窗口保持窄侧栏，标题栏和底栏双击不最大化，避免与吸附定位冲突后显示空白。单击拖动、自由调整和最小化照常；独立排序窗口仍可最大化／还原。

主窗口和底部吸附搜索栏统一混合搜索，覆盖个人、全部授权共享库、已订阅成员话术及已关联的本地／云文件，不受当前浏览库或分类限制。结果按“话术”“文件”分组，空组不显示，不再提供顶部类型筛选；结果行末不显示来源／分类标签，保留未缓存、文件失效等状态；组内保持原查询顺序，编号、上下选择及投递共用先话术后文件的顺序。常用短语位于搜索框上方，继续支持多行设置。搜索聚焦后，历史或结果向上覆盖短语，基础布局保留，进入和退出搜索时输入框的屏幕位置不变；结果最高228 DIP，整体最高420 DIP，超高结果滚动查看。左侧眼睛临时收起搜索面板并保留恢复入口，不修改设置，重新展开保留关键词与标签并刷新；界面设置的底部搜索开关控制整个入口。上方展开区域临时显示在目标前方，收起恢复原跟随层级，不主动抢焦点。搜索共用本地搜索服务和话术行，支持匹配方式、高亮、上下选择、Enter插入、Esc清空、悬停按钮和右键直接发送。“搜索结果使用后”设置作用于主窗口与底部搜索。

主窗口与底部吸附搜索共用最近10条搜索记录，默认隐藏，点击搜索框（或通过键盘进入搜索）后才在输入框上方显示，离开搜索区域或窗口失焦时收起；启动和后台记录更新不主动展开。主窗口历史采用覆盖浮层，首行显示“搜索方式，可使用拼音、关键词、拼音首字母”和清空按钮，无记录仍显示提示；历史标签从下一行开始，22 DIP行高、4 DIP间距，最多三行，超高纵向滚动，长词省略并可悬停查看。底栏继续在搜索聚焦时显示历史，标题与清空按钮独占首行，标签按可用宽度自动换行，标签区最高76 DIP。点击记录按当前入口范围重新搜索，并聚焦搜索框；两处搜索结果都替换历史标签，显示“搜索结果”标题与关闭按钮，底部尖角指向搜索框。底部保留话术／本地文件切换，关闭结果后清空关键词并恢复历史；主窗口浮层覆盖列表及常用短语，来源、分类、列表和常用短语由遮罩压暗，底层布局及输入框位置保持不变。清空或关闭结果后恢复历史提示，重新点击同一关键词也查询最新结果。仅通过搜索结果界面插入／发送且系统操作提交成功后记录，单纯搜索、复制、失败、中断和序号快捷键不记录。记录按个人库保存在本机，重启保留，不上传云端、不进入普通内容备份或日志。“清空搜索记录”仅删除记录，“清空搜索”仅清除输入及结果。主窗口清空记录需在独立“提示”窗口确认，默认聚焦取消；确认绑定打开时的个人库，切库或来源隐藏后失效，失败留窗，不自动重试。底栏保留原有直接清空入口。

普通搜索支持原文、无声调全拼及拼音首字母，不区分大小写，英文、数字和分隔符保留。个人话术、已授权共享／成员话术及本地文件共用匹配服务：模糊模式按空白拆词并要求全部命中，精确模式按完整输入匹配。多音字采用拼音库默认读音，拼音命中不额外标注汉字位置。

编辑器工具栏仅含日期、图片、文件和添加分段。新增与编辑话术的正文均支持粘贴剪贴板图片，图片插入原选区和分段，保存为本地素材。标题最多 200 字，正文总计最多 5000 字，每条最多 9 张图片、9 个文件。图片导入为静态 PNG；GIF 当前保存首帧，动图原文件可以作为文件关联。颜色选择使用居中矢量勾，各窗口标题栏使用软件图标。点击空白或切换话术与短语区域会取消旧选中状态，恢复普通背景。

主窗口、底栏、预览及所有动态窗口均在WebView2层关闭通用表单自动填充，编辑、搜索、设置等输入场景不再显示“保存的信息”建议弹窗。

默认发送键 Enter，可切换 Ctrl+Enter；分段间隔默认 500 毫秒，可调整。Alt+Q 聚焦搜索，上下选择、Enter 插入、Esc 退出；Alt+W 显示／隐藏侧栏，显示时聚焦列表，左右切换分类、上下选择、Enter 插入；Alt+E 显示并聚焦常用短语，Enter 直接发送。Alt 导航键占用冲突会提示。

序号话术快捷键默认关闭，十项默认绑定 Ctrl+1—9、Ctrl+0。点击按键框录入单组合键，“关闭”清空单项，重新录入即可恢复。开启后关闭设置窗口生效，默认插入，勾选“直接发送”后发送。序号对应主窗口当前绘制的编号，折叠后连续编号；主窗口搜索替代普通列表，文件槽位不触发话术，搜索加载和组合输入期间暂停。隐藏主窗口后沿用最后列表，底部搜索不改变序号映射。

自定义话术快捷键通过“功能键／第一键／第二键”录入，兼容原单组合键。`Ctrl+Y+C` 表示按住 Ctrl 依次按 Y、C，`1+1` 表示两次独立按 1，第二键需在一秒内按下。完全同键可绑定多条话术，单条也显示候选；候选覆盖全部本地活动话术，按分类和话术顺序排列。上下键选择，数字 1—9、0 插入前十项，空格插入当前项，Enter 直接发送，Esc 取消；超过十项继续用方向键选择，候选选择不限时。候选使用主题浅色表面、32像素行及柔和选中态，不激活、不占任务栏，优先在目标输入位置上方显示并限制在工作区内。

设置修改即保存；连续修改后关闭设置窗口会等待已提交的保存队列完成，失败时留窗显示错误，不自动重试。序号区的“直接发送”只控制序号快捷键，自定义快捷键仍先打开候选。

序号与自定义话术各有独立开启开关，共用“全局生效”：默认只在闪语或记录的目标窗口生效，开启后可用于其他前台窗口。编辑、录入、模态交互和设置窗口存在期间暂停业务快捷键；搜索允许已配置的序号组合键。普通字母／数字双键即时进入输入框或输入法，匹配后显示话术候选，选择后在标准 Windows 编辑框或已识别的企业微信输入区替换本次触发文字，保留原草稿与光标后内容；取消保留输入。微软拼音下先临时关闭组字，清理实际透传的触发输入并粘贴，再恢复输入法模式；此前未确认的拼音会先上屏，内容保留。中文数字可能用于选择此前拼音，自绘输入区无法核对时停止替换，可改用字母双键或 Ctrl／Alt 组合键。未知自绘输入区不执行自动清理；Ctrl／Alt／Win 组合及 F 键开头的序列仍拦截，未完成时仅在原输入区回放。候选显示时数字、空格和 Enter 操作话术候选；继续普通输入、切换窗口／输入控件或点击外部区域即取消。普通拼音仍可能命中简码，此行为不保证完全避免误触。单键与双键前缀冲突，以及序号之间、序号与导航或自定义话术的冲突会显示中文原因并保留原配置。

发送统一使用 Windows 剪贴板和按键。插入和发送会替换原剪贴板，结束后保留最后写入的内容块，不备份或恢复旧内容；期间发生新的复制会立即停止并保留新内容。剪贴板被占用时，每个内容块最多等待约3秒，释放后自动继续；持续无法打开时尽量提示检测到的占用程序，但 Windows 不保证能识别。目标输入区需要支持对应的文字、图片或文件格式；发送键应与目标软件一致。程序记录的是系统操作提交情况。企业微信识别用于窗口吸附与快捷键目标同步，投递仍使用通用输入链路。

窗口级提示区分成功、进度、错误及需要核对的中断：成功提示短暂显示，悬停或键盘焦点停留时暂停消失；错误与中断保留至关闭，同一窗口相同的普通错误去重，部分执行的警告优先显示。主窗口、设置及回收站使用紧凑悬浮提示，文字被截断时可展开并滚动查看完整内容；部分执行或结果不可用时直接提醒先检查目标。表单校验、确认和任务状态仍在原位置显示。剪贴板实际等待超过约0.5秒时显示等待状态及“停止”；底栏可展开或悬停查看完整提示。已产生的失败或中断投递回执逐条保存在本次运行内，按个人库和账号会话隔离，在可见的来源窗口、主窗口或底栏显示；两个窗口都隐藏时不主动唤醒，重新显示后可查看。无法读取结果时应先检查目标，避免重复操作；退出程序即清除回执，切换会话后不显示旧会话的回执。

## 闪云部署

闪云是闪语的自托管同步与共享服务，原称 Hub；程序、镜像、配置及数据标识保持兼容。专属图标及使用规范见[闪云品牌](docs/shanyun-brand.md)。

服务端项目：[QuickPhrase-Hub](https://github.com/thelinyue/QuickPhrase-Hub)（源码私有）。镜像公开，部署者无需访问源码或登录 GHCR。公开镜像支持 Linux x64（`linux/amd64`），客户端支持 Windows x64。

在 Docker／NAS 的图形界面中新建 Compose 项目，选择一个固定的项目目录，粘贴下面的完整配置。将 `QUICKPHRASE_ADMIN_PASSWORD` 的空字符串填写为自己的初始密码，再点击部署。密码至少8个字符，建议12位以上随机字母和数字；没有公开默认密码。

```yaml
services:
  quickphrase-hub:
    image: ghcr.io/thelinyue/quickphrase-hub:0.2.5
    user: "0:0"
    restart: unless-stopped
    ports:
      - "7823:7823"
    environment:
      QUICKPHRASE_ADMIN_USERNAME: "admin"
      QUICKPHRASE_ADMIN_PASSWORD: ""
    volumes:
      - "./data:/data"
```

服务名称统一为 `quickphrase-hub`。旧项目使用 `shanyu` 时，在图形界面先停止并移除旧容器，保留原项目目录和 `data`，再应用新配置，避免同时启动两个服务。0.2.2镜像支持 `QUICKPHRASE_*` 并兼容旧 `SHANYU_*` 变量；原0.2.0镜像及其配置继续可用，新变量需升级镜像后使用。0.2.2提供成员话术开放共享和共享回收站清空；0.2.3新增云文件改名，并允许管理员清理被引用文件的云端本体；已有完整本机缓存继续可用，未缓存设备不能再下载。镜像发布不会自动替换已部署的闪云。

默认用户名为 `admin`，可自行修改；首次登录必须修改初始密码。用户名支持1—64个字符的普通名称，昵称和联系方式可选。已有数据库不会被初始化变量覆盖；初始化完成后可从图形界面移除初始密码变量。

`./data:/data` 把项目目录下的 `data` 保存到宿主，首次部署可自动创建。单容器直接以 root 运行，无需额外初始化容器或终端权限命令。客户端在“账号”填写 `http://服务器IP:7823` 并登录。HTTP 适用于可信局域网，公网使用 HTTPS 反向代理；客户端不降级或跳过证书校验。代理需关闭 SSE 缓冲和缓存，并允许128MB上传。

升级时先在图形界面停止容器并完整备份原 `data`，再替换镜像版本；核对实际项目目录及挂载，保留旧目录和卷。已有 UID10001 数据可由 root 接入，服务不递归改写原素材属主。root 新建文件可能归 root；回退到非 root 镜像前须停服核对读写权限。不要删除数据卷或覆盖运行中的数据库。

共享数据备份包含账号、共享话术、云文件、云命令及独立授权、回收记录和实际素材，排除个人内容和会话；个人内容使用个人完整备份。完整运维备份在停服后保存整个 `data`。全目录恢复须使用同一份备份还原到新目录，并执行恢复准备以清除旧会话、更换个人同步世代；维护流程见下文。

可复制的配置及备份细节见[共享话术与部署](docs/team-sharing.md)，客户端本版变化见[0.2.13 发布说明](docs/releases/v0.2.13.md)。

## 数据与备份

数据默认位于 `%LOCALAPPDATA%\com.quickphrase.desktop`：`shanyu.sqlite3` 保存分类、话术、有序内容和设置，`images` 保存图片，`thumbnails`／`temp` 是可清理缓存，`shanyu.log` 记录中文错误。

0.1.1 的数据库统一使用版本1的完整初始结构。已有开发库打开时按实际字段和索引无损整理并统一版本标记；后续正式版本按数据兼容需求增加数据库版本。

缓存管理按“一键删除”和“清理本地缓存”分区，仅展示本地可用功能。全部个人话术删除前确认数量，默认进入回收站；取消回收选项才会永久删除。常用短语删除前明确提示不可恢复，建议先导出完整备份。整库删除保留分类、图片素材、文件关联及旧回收记录；其他窗口新增或删除内容后，旧确认会被拒绝，需要重新确认。清理缩略图或临时文件只移除可重建缓存。

导入导出统一在设置中选择个人库或共享话术；共享话术菜单会预选当前组。个人全部分类导出为“完整备份”，分类及共享话术导出为“话术包”。ZIP版本2保存图片和话术附件的实际内容；个人全库另含常用短语、回收和设置。账号导出当前本机版本，包含待同步修改及库内待确认便携设置，不强制同步。共享话术仅包含在用内容，不含回收、成员和角色。独立文件库仍只保存路径关联，源文件需单独备份。ZIP未加密。详见[导入导出](docs/data-transfer.md)。

导入先预览，确认后生成独立副本；同一批次的ID和素材固定，重试不重新复制。合并同名分类及恢复设置默认关闭；合并只匹配同级唯一同名项，多项同名时独立导入并提示。含独立文件关联的旧完整备份可分别选择“个人内容”和“本机文件与设备设置”导入，各自预览并独立提交。共享话术导入要求联网、首次改密完成及编辑权限，仅导入在用内容。私人失败整批回滚并清理本批素材；共享话术结果不明先核对，不盲目重发。发送和快捷键恢复需本机确认，占用不阻塞正文。分类复制／移动的原有同名处理保持原规则。Excel仅保存文字，不能保存图片、附件和完整分段结构。

安装、升级和卸载保留用户数据。产品的安装 AppId 和内部数据标识保持一致，以支持后续升级。

个人完整备份包含回收记录及其实际素材，导入后保持删除状态，需要显式还原。旧完整ZIP及服务器个人ZIP仍可导入。离线素材齐全时可导出；缺素材或取消不会替换已有备份。永久删除或清空回收站只移除记录，不自动删除素材图片或外部源文件。

## 开发与构建

需要 Windows x64、Rust MSVC 工具链、Visual Studio C++ Build Tools／Windows SDK、Node.js 22.22.2／24.15.0以上的相应偶数主版本或26+ 和 WebView2。当前验证环境为 Windows 11 26200、Rust 1.99.0 stable、Node 24.18.0、WebView2 154.0.4258.62。2026-10-11 已将15个 npm、16个 Rust直接依赖升级到各自最新稳定版，并更新锁文件；间接依赖使用上游允许的最新兼容版本。当前使用 React19.3、TypeScript7.0.2、Vite8.3.4、Vitest5.0.3、Tauri2.12.3；开发环境要求以 `package.json` 的 Node engines 为准。

```powershell
npm ci
npm run tauri -- dev
```

使用 Inno Setup 6 生成安装包：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/build-release.ps1 -InnoCompiler "C:\Program Files (x86)\Inno Setup 6\ISCC.exe"
```

脚本运行 Tauri `build --no-bundle`，下载并校验微软 WebView2 引导程序的签名，然后调用 ISCC。可通过 `INNOSETUP_ISCC` 或 `-InnoCompiler` 指定编译器路径；`-SkipInstall` 复用已安装的 npm 依赖。当前正式版本为0.2.13，产物为 `artifacts/QuickPhrase-Setup-0.2.13-x64.exe`，主程序为 `QuickPhrase.exe`；新安装默认使用当前用户的 `Programs\QuickPhrase`，升级沿用原安装目录，无需管理员权限。已发布0.2.0的下载文件仍使用原 `Shanyu` 名称。

默认仍只生成安装器。候选构建可加 `-Version 0.2.13-rc.1`，版本通过临时 Tauri 配置传入，不修改源码或锁文件；设置页显示实际应用版本。需要发布资产时另行运行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/package-release.ps1 -Version 0.2.13`，从当前对应版本的程序和安装器生成 `artifacts/release/0.2.13` 下的 ZIP、安装器、原有 SHA256 清单、manifest及更新签名（需配置签名环境变量，见在线更新文档）。ZIP 需要本机已安装 WebView2。

GitHub 自动 CI 执行单测、静态检查与 Debug 构建。候选和正式发布均只允许手动触发并复用 CI：候选从 `master` 构建 `0.2.13-rc.N`，仅上传 Actions artifact；正式发布在 `master` 手动触发，各阶段均检出对应版本标签，源码版本、标签与提交必须一致。两条流程不再要求人工确认开关；真实验收结果及环境缺口如实记录于验收记录，自动检查不代表未验证环境已经通过。工作流不会覆盖既有标签或 Release。

检测到已验证的新版本后，右下角“闪语”显示“新”角标；悬停提示当前版本和最新版本，点击进入关于页查看并手动升级。不在顶部增加提醒栏，下载中或选择稍后安装时仍可从此进入。

最小化悬浮窗专项 `node scripts/verify-minimized-float.mjs` 覆盖托盘／悬浮开关四种组合、真实拖动和双击、原生右键菜单、临时／永久隐藏、设置写入失败回滚、焦点、辅助窗口与自动隐藏排除、快捷键／重复启动还原、连续操作、贴边兼容、跨重启记位及屏幕越界恢复。仅使用隔离数据库和宿主，运行时暂停键鼠操作。

原生验收使用独立数据目录、Debug 单实例标识和本机输入宿主，可以保留正式客户端运行。`--dock-only` 只运行主窗口吸附和底部短语横条两组检查；`--notices-only` 只运行剪贴板等待及提示专项，不代表完整原生验收。吸附测试使用专用 ShanyuDockHost.exe，仅隔离 Debug 客户端识别。后台跟随专项覆盖普通／开机／重复启动、独立唤起、隐藏恢复、任务栏样式和多窗口遮挡，悬停专项覆盖预览与稳定宽度；这两项不使用系统剪贴板或聊天发送。原生脚本需顺序运行，执行时暂停键鼠操作；发送验收会短暂使用剪贴板，结束时仅恢复仍属于本次验收的内容，保留后来的用户复制。安装验收仅运行安装器，使用独立 AppId、编译时菜单组、启动项和安装目录，验证已发布0.2.0旧安装器夹具的改名升级；需保留其 shanyu.exe 构建产物，完成后清理自己的测试安装。报告和截图位于 `.build` 下对应的专项目录。

鼠标延迟专项运行前退出普通客户端，避免旧实例的全局钩子干扰测量。每组120次左右1像素往返移动，不点击、不按键、不访问剪贴板；比较未启动、关闭吸附、正在吸附、连续移动缩放及退出后的钩子链延迟。检测到其他鼠标移动时不恢复旧光标位置，避免覆盖用户后来移动的位置。

## 回收站

主菜单统一使用“回收站”。窗口顶部使用两个独立按钮：“个人话术”直接切换，“共享话术：名称”展开具有编辑权限的小组列表；当前来源高亮。从当前来源打开时自动定位，复用窗口时更新来源。关键词、全拼和首字母搜索均按回车提交，每页10条。共享回收记录需联网查看；个人来源仍按本机使用规则工作。

还原固定回到原来源和分类，不提供跨来源还原。清空确认显示来源和全部记录数，包含搜索结果之外的记录；提交仅删除确认清单中仍存在的记录，已还原或删除的跳过，随后新增的保留。共享清空使用事务，权限或生命周期失效时拒绝，失败完整回滚；不自动重试或额外删除素材本体、外部源文件。旧版闪云不支持清空时提示升级，仍可逐条永久删除。整组“已删除共享话术”和云文件回收站继续在各自管理界面。

专项联调：构建前端与含 `custom-protocol` 的 Debug 客户端、闪云后，设置 `SHANYU_TEAM_SERVER_EXE` 指向闪云程序，再运行 `node scripts/verify-recycle.mjs`。脚本使用隔离数据与隐藏实际客户端，不操作聊天、剪贴板或实体键鼠，不替代系统 DPI 和安装升级验收。不要与其他使用同一 Debug 单实例标识的客户端脚本同时运行。

底栏与短语菜单专项 `node scripts/verify-common-ui.mjs` 使用隔离数据、真实Windows窗口及鼠标，验证宽窄底栏、多行短语、搜索框坐标稳定、单击插入去重、四项定制菜单与焦点恢复。投递回执模拟，不操作聊天或剪贴板；执行时暂停键鼠操作，不与其他原生专项同时运行。

## 设置、默认共享话术与 AI 连接

设置保持修改即保存：单项显示保存状态，其他选项仍可操作。输入草稿、焦点、标签页和滚动位置保留；失败只恢复对应字段。普通设置保存只通知设置变化，不重读全部话术。

在“设置 → 账号”选择默认共享话术。本机按服务器和账号记忆，点击共享话术名称进入默认库，箭头打开切换列表；未设置或权限失效时展示列表，不自动改选。临时离线不清空默认偏好。

“设置 → AI 连接”可开启本机 MCP（默认关闭），默认地址为 `http://127.0.0.1:17823/mcp`。先勾选允许 AI 读取和整理的库，再复制连接配置给信任的 AI 客户端；素材目录需要单独授权。详见 [MCP 使用说明](docs/mcp.md)。

快捷键支持有序双普通键（如 `Q+W`、`1+1`）及带修饰键的序列（如 `Ctrl+Y+C`），不同键允许短暂重叠，同键必须松开再按。候选仍逐条单行显示，按内容及字号自适应，普通宽度240—360 DIP，最高420 DIP，同时受工作区限制；长内容省略，悬停可查看全文。候选优先靠近文字光标上方，空间不足时放下方；光标不可读时靠近当前输入控件，无法识别输入区时回退目标窗口可见区域左下方。目标窗口移动时候选跟随，保持输入焦点。

云文件回收站：管理员永久删除只需一次明确确认，无需输入文件名；“清空回收站”覆盖全部回收文件，不受搜索或分页限制。管理员也可清理仍被引用的云端文件。已有本机缓存和个人副本保留；未缓存、新设备或清除缓存后无法再下载，恢复旧话术不会恢复云端文件。界面显示逐项结果。此规则需升级闪云，缓存仍受账号和授权约束，注销等既有清理行为不变。
