# 闪语

Windows 10（1607+）／11 x64 本地话术工具，使用 Tauri 2、Rust、React／TypeScript。界面和名称已于 2026-10-10 确认，当前版本为 0.1.1。

## 使用

1. 聚焦目标输入区，再打开闪语。
2. 单击选中话术；双击正文将内容添加到当前输入位置。
3. 默认点击左侧黄色发送按钮，或右键选择“直接发送”才发送。可在常用设置主动将话术双击、常用短语单击改为直接发送；已有草稿会保留，发送作用于输入区的最终内容。

支持分类、折叠分组、排序、移动／复制、标题配色、自定义快捷键、搜索、文字／图片／文件与分段。独立文件库只关联源文件，失效记录可重新关联，删除关联不会删除原文件。

话术正文使用连续图文编辑区，图片在当前光标或选区位置插入，保留前后文字与分段顺序。工具栏仅有日期、图片、文件和添加分段；每条最多9张图片、9个文件。包含图片的话术在列表及搜索结果显示图片图标，移除全部图片并保存后恢复普通话术图标。

删除话术、一级／二级话术分类时，确认窗口默认勾选“移除到回收站”；取消勾选后永久删除。底部主菜单可打开回收站，支持关键词、全拼、首字母搜索和分页，显示原分类、正文、图片及附件。还原恢复原内容与分类；二级分类后来被移动时，在原位置重建所需分组，保留已移动的活动内容。快捷键冲突时保留回收记录，可明确选择不恢复快捷键后重试。文件关联和独立常用短语不进入回收站。

本地文件右键支持复制文件、修改显示名、移除关联、快速排序、移动分类、打开文件／所在位置、重新关联和刷新状态。Ctrl 单击多选、Shift 连续选择、Ctrl+A 选择当前分类；复制、移动和移除支持批量操作。文件分类支持新增、重命名、删除和快速排序。显示名修改及分类移动均不改变源文件。

一级分类和二级分类名称允许重复，各分类独立保存；分类选择框和快速排序显示同名序号，主界面标签保留原名称。话术行鼠标悬停为米黄色，单击选中为淡黄色，移出鼠标后恢复选中色。

在话术正文上停留350毫秒后，按参考图在真实鼠标位置右下方显示300像素宽的轻量预览，间距12像素。白底细边框，只显示标题、快捷键和正文，不使用独立标题栏、关闭按钮、底部提示和窗口阴影。固定展开方向，屏幕边缘也不翻转或反向平移，超出屏幕的部分会被裁切。预览保留换行、图文、文件名及分段，短文按内容收紧高度，长文可进入浮层滚动查看。快速掠过或悬停发送按钮不弹出正文；移开鼠标、点击、列表滚动和Esc关闭预览，切换话术从正文开头阅读。预览窗口不激活，不改变原输入目标，主列表、主窗口搜索和底部搜索复用相同交互。

常用短语独立维护，每条为不超过 16 字的单行文字。点击“＋”新增，右键可修改、删除或打开快速排序窗口；排序支持 Ctrl 多选拖动，取消不保存，确定后两处短语栏同步更新。默认单击选中、双击插入；单击可配置为插入或直接发送，配置后双击不重复提交。左右键选择相邻项，上下键选择相邻行中最近的项，Enter 直接发送；主窗口和底部短语栏使用相同行为。

主窗口右上依次为吸附、置顶和最小化。底部按钮可分别显示／隐藏常用短语和搜索框，设置自动保存。普通启动和开机启动默认驻留托盘，开启吸附后随激活的企业微信无激活地显示，不抢焦点；重复运行不主动唤起。主窗口、底栏和正文预览不占任务栏，主动打开的设置和编辑窗口保留任务栏入口。目标最小化、关闭或切换其他程序时侧栏与底栏一起隐藏，返回目标后恢复；使用闪语及其设置、编辑窗口时保持跟随。手动隐藏持续到再次唤起。没有可用目标时可用托盘或快捷键独立打开，企业微信重新激活后恢复吸附；关闭左右吸附恢复原独立位置和尺寸。隐藏搜索后按 Alt+Q 会展开并聚焦；Alt+E 会显示并聚焦常用短语。

底部短语栏的可见左右边缘与目标窗口对齐，侧栏紧贴目标可见边缘；闪语自身不可见边框按当前窗口动态补偿。底部“隐藏短语”关闭整个短语栏，菜单及新增按钮一起隐藏；可在“设置→界面设置→显示底部吸附常用短语”重新打开。底部搜索若已开启会独立保留。

侧栏移动、缩放和闲置时始终完整展开，旧“吸附时自动隐藏”“贴边显示防误触”选项已移除，旧库对应设置仍可读取。用户宽度按逻辑像素保存、按目标显示器DPI换算，跟随定位与屏幕裁剪不覆盖宽度。侧栏跟随目标可见顶部与高度，底栏跟随底边，目标部分移出屏幕时按显示器工作区裁剪。原吸附侧空间不足时，保持设置的侧边在屏幕内完整显示，必要时覆盖目标边缘。激活目标时同步侧栏层级，避免被其他普通窗口遮挡；普通目标保持普通窗口层，目标置顶时跟随置顶，关闭吸附后恢复用户置顶设置。

吸附图标开口朝左，关闭吸附时带左下至右上的斜线，开启时显示普通磁铁。置顶图标开启时实心、关闭时空心；常用短语和搜索框显示时为睁眼图标、隐藏时为斜线眼图标。这四个开关只通过图标区分状态，不叠加开启态浅色底块。界面使用直角，Windows 11 的客户端窗口外框也禁用系统圆角。

一级分类右键与右上角入口共用参考图的11项菜单，第二项为“新增二级分类”，归属菜单所指向的一级分类；“新增同级分类”新建一级分类。菜单使用直角灰底、32像素行高；二级分类保留自己的操作菜单。话术列表空白右键提供“新增话术”和“新增二级分类”，归属当前一级分类；文件列表空白右键仍为“刷新”。底部保留应用菜单。分类复制／移动的目标为其他一级分类，同名二级分组合并，内容追加到目标末尾。移动保留快捷键并移除来源分类，复制清空副本快捷键。“删除一级分类但保留话术”位于底部主菜单，话术移至明确选择的目标并取消分组；二级分类的保留删除仍位于其右键菜单，话术归入原一级分类。

一级分类标签可分别选择十二色色板或恢复默认颜色。菜单中的“设置一级分类背景色”打开设置页的“界面设置”，预选所点击的分类；已有设置窗口也会切换页面与分类。一级分类栏高度默认31像素，可设为31—200像素，增加高度后标签换行。界面设置提供标题和内容、仅标题、仅内容三种显示模式，以及默认展开／收起二级分类。

界面设置提供七种主题、10—18像素话术字体、标题默认色、私人／文件分类默认背景色、话术／文件标签顺序、窗口自由调整及吸附状态记忆。单个分类配色优先于默认色，单条话术独立颜色优先于标题默认色；旧版默认橙色会跟随全局默认色。话术／文件分类区域分别设置31—200像素，侧边短语区域最大高度28—300像素；底部短语可限制为一、二、三行或自适应，超出内容可以滚动。关闭吸附状态记忆后，当前会话可继续吸附，下次启动驻留后台，由托盘或快捷键唤起独立窗口。

底部吸附搜索栏共用本地搜索服务和话术行，支持匹配方式、高亮、上下选择、Enter插入、Esc关闭、悬停按钮和右键直接发送。“搜索结果使用后”设置作用于主窗口与底部搜索。

编辑器工具栏仅含日期、图片、文件和添加分段。新增与编辑话术的正文均支持粘贴剪贴板图片，图片插入原选区和分段，保存为本地素材。标题最多 200 字，正文总计最多 5000 字，每条最多 9 张图片、9 个文件。图片导入为静态 PNG；GIF 当前保存首帧，动图原文件可以作为文件关联。颜色选择使用居中矢量勾，各窗口标题栏使用软件图标。点击空白或切换话术与短语区域会取消旧选中状态，恢复普通背景。

主窗口、底栏、预览及所有动态窗口均在WebView2层关闭通用表单自动填充，编辑、搜索、设置等输入场景不再显示“保存的信息”建议弹窗。

默认发送键 Enter，可切换 Ctrl+Enter；分段间隔默认 500 毫秒，可调整。Alt+Q 聚焦搜索，上下选择、Enter 插入、Esc 退出；Alt+W 显示／隐藏侧栏，显示时聚焦列表，左右切换分类、上下选择、Enter 插入；Alt+E 显示并聚焦常用短语，Enter 直接发送。Alt 导航键占用冲突会提示。

序号话术快捷键默认关闭，十项默认绑定 Ctrl+1—9、Ctrl+0。点击按键框录入单组合键，“关闭”清空单项，重新录入即可恢复。开启后关闭设置窗口生效，默认插入，勾选“直接发送”后发送。序号对应主窗口当前绘制的编号，折叠后连续编号；主窗口搜索替代普通列表，文件槽位不触发话术，搜索加载和组合输入期间暂停。隐藏主窗口后沿用最后列表，底部搜索不改变序号映射。

自定义话术快捷键通过“功能键／第一键／第二键”录入，兼容原单组合键。`Ctrl+Y+C` 表示按住 Ctrl 依次按 Y、C，`1+1` 表示两次独立按 1，第二键需在一秒内按下。完全同键可绑定多条话术，单条也显示候选；候选覆盖全部本地活动话术，按分类和话术顺序排列。上下键选择，数字 1—9、0 插入前十项，空格插入当前项，Enter 直接发送，Esc 取消；超过十项继续用方向键选择，候选选择不限时。白底蓝细框候选不激活、不占任务栏，优先在目标输入位置上方显示并限制在工作区内。

序号与自定义话术各有独立开启开关，共用“全局生效”：默认只在闪语或记录的目标窗口生效，开启后可用于其他前台窗口。编辑、录入、模态交互和设置窗口存在期间暂停业务快捷键；搜索允许已配置的序号组合键。触发键完整匹配后消费，未完成序列在原输入区回放；候选期间切换窗口、输入控件或点击外部区域即取消。单键与双键前缀冲突，以及序号之间、序号与导航或自定义话术的冲突会显示中文原因并保留原配置。[快捷键视频教程](https://p0xayf3yelk.feishu.cn/docx/TT6IdJyhaoem5UxWH3qcCJl3nwh)也可从设置页和快捷键录入说明打开。

发送统一使用 Windows 剪贴板和按键。目标输入区需要支持对应的文字、图片或文件格式；发送键应与目标软件一致。程序记录的是系统操作提交情况。企业微信识别仅用于窗口吸附。

## 数据与备份

数据默认位于 `%LOCALAPPDATA%\com.quickphrase.desktop`：`shanyu.sqlite3` 保存分类、话术、有序内容和设置，`images` 保存图片，`thumbnails`／`temp` 是可清理缓存，`shanyu.log` 记录中文错误。

产品尚未正式发布，数据库统一使用版本1的完整初始结构，开发期改动直接合并到初始化语句。已有开发库打开时按实际字段和索引无损整理并统一版本标记；正式发布后再按数据兼容需求增加数据库版本。

缓存管理按“一键删除”和“清理本地缓存”分区，仅展示本地可用功能。全部私人话术删除前确认数量，默认进入回收站；取消回收选项才会永久删除。常用短语删除前明确提示不可恢复，建议先导出完整备份。整库删除保留分类、图片素材、文件关联及旧回收记录；其他窗口新增或删除内容后，旧确认会被拒绝，需要重新确认。清理缩略图或临时文件只移除可重建缓存。

完整 ZIP 备份包含分类、话术、常用短语、分段、图片、文件关联和设置。外部文件只保存路径，原文件需另行备份。导入先预览，再事务写入，可合并同名分类和选择恢复设置；未勾选合并时保留每个分类的原名称和独立关联，勾选时合并到同级列表中第一个同名分类。分类复制／移动遇到多个同名分组时，也合并到目标列表中第一组。失败回滚并清理本批次生成的图片。Excel 按分类名称组织文字，保留同名分类的独立结构请使用完整备份。

安装、升级和卸载保留用户数据。产品的安装 AppId 和内部数据标识保持一致，以支持后续升级。

完整备份也包含回收站记录和其中的图片，导入后仍留在回收站，需要显式还原。按分类导出和 Excel 只包含活动话术。永久删除或清空回收站只移除记录，不自动删除素材图片或外部源文件。

## 开发与构建

需要 Windows x64、Rust MSVC 工具链、Visual Studio C++ Build Tools／Windows SDK、Node.js 22.22.2／24.15.0以上的相应偶数主版本或26+ 和 WebView2。当前验证环境为 Windows 11 26200、Rust 1.99.0 stable、Node 24.18.0、WebView2 154.0.4258.62。2026-10-11 已将15个 npm、16个 Rust直接依赖升级到各自最新稳定版，并更新锁文件；间接依赖使用上游允许的最新兼容版本。当前使用 React19.3、TypeScript7.0.2、Vite8.3.4、Vitest5.0.3、Tauri2.12.3；开发环境要求以 `package.json` 的 Node engines 为准。

```powershell
npm ci
npm run tauri -- dev
```

使用 Inno Setup 6 生成安装包：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/build-release.ps1 -InnoCompiler "C:\Program Files (x86)\Inno Setup 6\ISCC.exe"
```

脚本运行 Tauri `build --no-bundle`，下载并校验微软 WebView2 引导程序的签名，然后调用 ISCC。可通过 `INNOSETUP_ISCC` 或 `-InnoCompiler` 指定编译器路径；`-SkipInstall` 复用已安装的 npm 依赖。产物为 `artifacts/Shanyu-Setup-0.1.1-x64.exe`，默认安装到当前用户的 `Programs\Shanyu`，无需管理员权限。

默认仍只生成安装器。候选构建可加 `-Version 0.1.1-rc.1`，版本通过临时 Tauri 配置传入，不修改源码或锁文件；设置页显示实际应用版本。需要发布资产时另行运行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/package-release.ps1 -Version 0.1.1`，从当前对应版本的程序和安装器生成 `artifacts/release/0.1.1` 下的 ZIP、安装器、原有 SHA256 清单及 manifest。ZIP 需要本机已安装 WebView2。

GitHub 自动 CI 执行单测、静态检查与 Debug 构建。候选和正式发布均只允许手动触发并复用 CI：候选从 `master` 构建 `0.1.1-rc.N`，保留企业微信人工验收确认，仅上传 Actions artifact；正式发布从已有 `v0.1.1` 标签运行，源码版本、标签与提交必须一致，并确认企业微信及 Windows 11 安装矩阵。当前实机缺口见验收记录，不能勾选确认来代替实际验证。工作流不会覆盖既有标签或 Release。

## 验证

```powershell
npm test
npm run test:release
npm run check
cargo test --manifest-path src-tauri/Cargo.toml
cargo clippy --manifest-path src-tauri/Cargo.toml --all-targets -- -D warnings
```

执行真实 Windows 验收：

```powershell
npm run build
cargo build --manifest-path src-tauri/Cargo.toml --features custom-protocol
node scripts/verify-background-following.mjs
node scripts/verify-hover-docking.mjs
node scripts/verify-categories.mjs
node scripts/verify-library.mjs
npm run test:native
npm run test:native -- --dock-only
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tests/shortcut-desktop.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/verify-installer.ps1 -InnoCompiler "C:\Program Files (x86)\Inno Setup 6\ISCC.exe"
```

原生验收使用独立数据目录、Debug 单实例标识和本机输入宿主，可以保留正式客户端运行。`--dock-only` 只运行主窗口吸附和底部短语横条两组检查。吸附测试使用专用 ShanyuDockHost.exe，仅隔离 Debug 客户端识别。后台跟随专项覆盖普通／开机／重复启动、独立唤起、隐藏恢复、任务栏样式和多窗口遮挡，悬停专项覆盖预览与稳定宽度；这两项不使用系统剪贴板或聊天发送。原生脚本需顺序运行，执行时暂停键鼠操作；发送验收会短暂使用剪贴板，结束时仅恢复仍属于本次验收的内容，保留后来的用户复制。安装验收需要先关闭运行中的闪语，使用独立 AppId、开始菜单组和安装目录，并清理自己的测试安装。报告和截图位于 `.build` 下对应的专项目录。

快捷键专项 `tests/shortcut-desktop.ps1` 在独立 Windows 输入桌面运行完整监听与发送链路，结束后切回原桌面，使用标准 WinForms 输入宿主。隔离 Debug 实例才接受带专用标记的测试按键。报告、宿主草稿／发送记录和 100%／150%／200% WebView2 渲染截图保存在 `docs/ui/runtime/shortcuts`；这些渲染倍率不代表系统 DPI 或真实聊天软件验收。可加 `-Filter Alt` 单独复现导航组。
