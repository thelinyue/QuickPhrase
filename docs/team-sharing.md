# 共享话术

每个人使用普通账号登录，管理自己的话术，需要共享时加入共享话术。同一账号可加入多组共享话术，服务管理员维护这台 Hub 的账号与公共资源。服务管理员创建账号并授予创建共享话术权限；用户获授权后可创建共享话术，创建者成为该库管理员。创建共享话术权限默认关闭，取消授权不改变已有组角色。个人设置、常用短语及个人快捷键不共享。

主窗口在“个人话术”旁显示“共享话术：库名 ▾”。下拉仅列出获准共享话术，标记当前组和库内角色，超过8组提供搜索。分类、折叠与滚动位置按来源记忆；切换来源清空搜索、选中和旧序号映射。主窗口搜索限定当前来源，底部搜索合并个人库、授权共享话术和本地文件，并标明来源。

## 账号与共享话术管理

从共享话术下拉、主菜单或“账号与同步”分别打开“账号管理”和“共享话术管理”，两窗可同时存在、分别复用。用户名窗口默认620×620 DIP、最小480×440；共享话术窗口默认680×600 DIP、最小560×440，均可调整尺寸。账号管理仅服务管理员可见，使用资料卡，支持搜索、状态筛选和每页20条。用户名使用唯一字符串；昵称与联系方式可选，分别最多50、100字符。资料、安全操作和创建共享话术授权按字段分别提交，避免相互覆盖。未登录、待首次改密或离线时不能提交管理操作。

共享话术列表显示名称、成员数、我的角色和操作，每页20组。人数包括停用用户名，不包括服务管理员的隐式访问；旧服务缺少人数时显示“—”。库管理员默认查看可管理的共享话术，也可切换全部已加入共享话术。点击“管理成员”进入独立详情页；搜索和分页仅改变显示，保存始终提交完整成员草稿。返回、关闭或复用窗口跳转前确认放弃未保存调整。切号、降权和共享话术生命周期变化撤下旧资料与弹窗，旧异步响应不能恢复草稿。

| 身份 | 权限 |
|---|---|
| 服务管理员 | 管理账号和共享话术、授予创建共享话术权限、任免库管理员、恢复和永久删除整库 |
| 库管理员 | 管理本库名称、话术、成员与编辑者；移交管理员；删除本库 |
| 编辑者 | 维护所属库的话术、分类、素材和回收站 |
| 查看者 | 查看、复制和使用所属库话术 |

服务管理员可从用户名列表添加成员，库管理员通过完整用户名查找已有人员，仅取得用户名、昵称和必要状态。成员与角色调整先进入草稿，点击“保存”后生效；失败保留草稿。库管理员不能通过查看者编辑增设管理员或修改任何管理员。

“移交管理员”只允许选择本库已启用的查看者或编辑者，确认中显示共享话术、接收人用户名及昵称。提交后接收人成为管理员，原管理员成为查看者。其他管理员、双方其他库角色和创建共享话术权限不变。移交后原管理员编辑与管理入口撤下，之前启动的旧编辑请求也重新核验权限。

查看者和编辑者可确认“退出共享话术”；管理员必须先移交，再退出。退出仅移除自己的成员关系，撤下该库入口与搜索，取消下载、未完成投递并清理本地缓存。再次加入需管理员添加，个人副本保留。

“删除整组共享话术”将整组移入“已删除共享话术”，确认展示库名、成员数和话术数（含回收记录）。内容、素材、成员角色和原话术回收记录均保留。仅服务管理员可“恢复整组共享话术”，或输入完整名称永久删除整组；恢复前校验素材完整性，已停用用户名不会恢复访问。永久删除事务登记素材清理任务，清理失败保留任务，服务端每30秒重试，界面显示待清理。

## Compose 图形界面部署

服务端项目：[QuickPhrase-Hub](https://github.com/thelinyue/QuickPhrase-Hub)（源码私有）。镜像公开，部署者无需访问源码或登录 GHCR。公开镜像支持 Linux x64（`linux/amd64`），客户端支持 Windows x64。

在 Docker／NAS 的图形界面中新建 Compose 项目，选择一个固定的项目目录，粘贴下面的完整配置。将 `QUICKPHRASE_ADMIN_PASSWORD` 的空字符串填写为自己的初始密码，再点击部署。密码至少8个字符，建议12位以上随机字母和数字；没有公开默认密码。

```yaml
services:
  quickphrase-hub:
    image: ghcr.io/thelinyue/quickphrase-hub:0.2.3
    user: "0:0"
    restart: unless-stopped
    ports:
      - "7823:7823"
    environment:
      QUICKPHRASE_ADMIN_USERNAME: "admin"
      QUICKPHRASE_ADMIN_PASSWORD: ""
    volumes:
      - "./data:/data"
```

服务名称统一为 `quickphrase-hub`。旧项目使用 `shanyu` 时，在图形界面先停止并移除旧容器，保留原项目目录和 `data`，再应用新配置，避免同时启动两个服务。0.2.2支持 `QUICKPHRASE_*` 并兼容旧 `SHANYU_*` 变量，提供成员话术开放共享和共享回收站清空；原0.2.0镜像及其配置继续可用，新变量需升级镜像后使用。

默认用户名为 `admin`，可自行修改；首次登录必须修改初始密码。用户名支持1—64个字符的普通名称，昵称和联系方式可选。已有数据库不会被初始化变量覆盖；初始化完成后可从图形界面移除初始密码变量。

`./data:/data` 把项目目录下的 `data` 保存到宿主，首次部署可自动创建。单容器直接以 root 运行，无需额外初始化容器或终端权限命令。客户端在“账号与同步”填写 `http://服务器IP:7823` 并登录。HTTP 适用于可信局域网，公网使用 HTTPS 反向代理；客户端不降级或跳过证书校验。代理需关闭 SSE 缓冲和缓存，并允许128MB上传。

升级时先在图形界面停止容器并完整备份原 `data`，再替换镜像版本；核对实际项目目录及挂载，保留旧目录和卷。已有 UID10001 数据可由 root 接入，服务不递归改写原素材属主。root 新建文件可能归 root；回退到非 root 镜像前须停服核对读写权限。不要删除数据卷或覆盖运行中的数据库。

共享数据备份包含账号、共享话术、云文件、回收记录及实际素材，排除个人内容和会话；个人内容使用个人完整备份。完整运维备份在停服后保存整个 `data`。全目录恢复须使用同一份备份还原到新目录，并执行恢复准备以清除旧会话、更换个人同步世代；维护流程见下文。

完整运维恢复时，在恢复目录使用下面的一次性 Compose 配置，确认日志“恢复准备完成”后移除临时项目、保留 `data`，再启动上面的常驻服务。原服务必须已停止，恢复到新目录，不覆盖运行中的数据。

```yaml
services:
  prepare-restore:
    image: ghcr.io/thelinyue/quickphrase-hub:0.2.3
    user: "0:0"
    restart: "no"
    command: ["--prepare-restore"]
    volumes:
      - "./data:/data"
```

## 同步、离线和投递

每组有独立版本。写入先提交 SQLite 事务，再发送只包含授权组版本的 SSE 通知。客户端重新获取压缩元数据快照；服务器对同一版本复用压缩结果，每次响应仍重新核验授权。SSE 自动重连，先刷新授权，再补齐各组版本，并以60秒版本检查兜底。

客户端每组只有一个刷新任务，连续通知合并到最高待更新版本；快照不能倒退。账号／会话代数和共享话术授权代数使旧响应失效。授权查询串行，收到移库／停用／删除共享话术后取消相关下载和未完成投递、撤下入口、搜索及编号映射、清理缓存；重新加入同组也不接受移库前的响应。删除和恢复均递增生命周期版本，快速删除恢复不能让旧编辑、快照、下载或投递重新生效。授权落盘失败则移除旧凭据，避免下次离线沿用已撤销授权。

缓存位于个人数据目录的 `teams` 子目录，按服务器、用户名会话分区和共享话术隔离。当前分类图片后台下载，可见话术优先，下载全局最多并行两个；文件按需下载。临时文件完成后才原子落盘，并保存普通长度记录，截断／缺失素材不能视为就绪。图片沿用128MB输入／解码分配及16384像素限制；单文件最多128MB。

账号页仅显示共享话术组数和管理入口，避免库多时撑长页面；共享话术管理支持搜索、每页20组分页，并按库显示本设备最近成功同步时间。授权核验且本机快照达到服务端版本后更新，失败不更新。时间按系统时区显示，离线重启保留，退出或撤权随缓存清理，不代表所有素材已下载。

离线可用此前授权且完整下载的内容；断网时无法立即回收缓存权限，再次联网时生效。退出登录清理本会话共享话术缓存，并在服务器可达时注销会话、清理该会话尚未发布的素材；已提交素材保留。已发出或已复制到个人库的副本无法收回。

投递引用携带来源、teamId、内容ID、屏幕显示版本及生命周期，编号映射也携带这些信息。开始前核验授权、显示版本和全部素材，素材未就绪则先下载并要求再次点击，不自动续发。固定分段及不可变素材ID，复用私人投递的发送锁、目标核验、剪贴板保护和中断规则。系统提交成功不等于企业微信最终发送成功。设置和团队管理窗口各自记录原生句柄，两者均关闭后才恢复业务快捷键。

## 编辑、复制与备份

编辑器明确显示目标共享话术。共享话术写入使用共享话术版本和话术版本，其他成员已保存时拒绝覆盖并保留草稿；可以查看最新正文后明确采用最新版本继续编辑。共享话术版本校验较保守：同组其他分类的修改也可能要求刷新比较。

个人话术或一级分类右键“复制到共享话术”先展示目标和内容数量／素材摘要，确认后上传实际图片、文件并事务发布。不会上传个人设置、常用短语、快捷键或整份私人备份。批次失败只清理本会话新上传且尚未引用的素材；写请求超时不会盲目重试，先刷新确认。共享话术右键可以下载全部素材，或连同图片和附件复制到个人库，两份之后独立维护，复制失败清理本批本地素材，不删除外部原文件。

删除单条话术或分类进入“回收站”，同一窗口顶部用两个独立按钮切换来源：“个人话术”直接切换，“共享话术：名称”展开可编辑的小组列表，当前来源高亮，搜索和操作仅作用于当前来源。整组“已删除共享话术”仍在共享话术管理界面，使用“删除整组共享话术／恢复整组共享话术”明确操作范围。还原固定返回原来源，以事务恢复分类上下文和话术；分类归属冲突或素材缺失时整批拒绝。永久删除记录不会删除外部源文件。

`POST /api/teams/{team}/recycle/clear` 接收 `{ ids, expectedLifecycleVersion }`，返回实际删除数量。确认时取得当前来源全部记录，包含搜索外记录；事务重新核验权限、生命周期和记录归属，只删除确认 ID 中仍存在的记录，跳过已还原或删除的记录，保留后来新增的记录。跨来源 ID 或任何写入失败整批回滚，不自动重试，不额外清理素材本体。旧 Hub 缺少清空接口时客户端提示升级，已有查询、还原和逐条删除仍可使用。

服务管理员从“账号管理→更多→共享数据备份”下载，范围为“账号、共享话术及素材，不含个人库”。包含 `teams.sqlite3` 和共享话术素材，排除个人库、会话及素材上传凭据；SQLite副本压缩清理空闲页，在线会话不受影响。备份包含账号密码摘要，应限制访问。恢复时停服解压到**独立的新数据目录**，核对数据库、素材和权限，再切换挂载。完整运维恢复必须使用同一份全目录备份，并执行 `--prepare-restore`；私人恢复规则见 [账号与同步](private-sync.md)。不要覆盖运行中的数据库。

## Hub 0.2.3 与客户端 0.2.8

云文件改名和新的回收站清理规则需要Hub 0.2.3，建议先升级Hub再升级客户端。管理员可清理仍被引用的云文件本体；已有话术和回收记录保留原引用，完整本机缓存仍可使用，未缓存设备及清除缓存后无法重新下载。还原话术不会恢复已清理的云端本体。升级前先停服并完整备份实际挂载的数据库及素材，保留旧镜像与数据备份；镜像发布不会自动更新现有部署。
