# 闪语 QuickPhrase 0.2.14

本版统一客户端界面样式和弹窗关闭方式，不涉及闪云服务端升级或数据库迁移。

- 统一按钮、表单、颜色与交互状态，保留七种主题、自定义颜色和紧凑窗口布局。
- 表单的关闭按钮、取消和 Esc 使用一致的草稿保护；独立窗口关闭时统一检查未保存内容和正在提交的操作，避免误关丢失编辑。
- 设置自动保存输入在窗口关闭时保留原有等待和失败保护。后台文件传输不因管理窗口关闭而停止。
- 提供 Windows x64 安装器、免安装 ZIP、SHA256 清单、Minisign 签名和更新 manifest；程序和安装器未附带 Windows Authenticode 代码签名。

此前的隔离 Windows WebView2 专项覆盖七主题、窗口关闭和草稿保护；部分确认与失败场景使用模拟。真实企业微信及输入法、Windows 实际多屏／DPI、实体 Alt+F4 和本版安装升级尚未验收。详见[关闭方式验收记录](../ui/dialog-close-2026-11-02.md)和[样式统一验收记录](../ui/style-unification-2026-11-02.md)。
