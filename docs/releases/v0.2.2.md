# 闪语 QuickPhrase 0.2.2

此版本未正式发布。发布CI发现Windows短名称与长名称混用时目录迁移不能正确改写素材路径，工作流在质量检查阶段停止，未生成Release或公开资产；已推送标签保留，由0.2.3修复并继续发布。下方内容为当时准备的版本说明。

本版新增 GitHub 在线更新、本地数据目录迁移、搜索历史和使用指引，完善云文件批量上传、个人同步及回收站操作。

- 设置 → 关于支持自动检查、手动下载和退出安装，可选择默认／备用代理、自定义 HTTPS 代理或直连。固定版本的清单先验证 Minisign 签名，再核对 manifest 和安装器 SHA256；未完成编辑、发送或传输时拒绝安装。0.2.2 是首个具备在线更新能力的版本，已有用户需要先手动安装本版，后续签名版本才可在应用内升级。
- 支持将本地数据迁移到新的空目录并重启，保留 SQLite 已提交数据、账号库、素材和外部文件关联。验证成功后清理原应用数据；失败继续使用原目录，自定义目录不可访问时明确报错，不创建空库。迁移期间需要一份完整副本的空间，先保存编辑并完成传输。
- 主窗口和底部搜索共用最近10条本机历史，仅搜索结果插入／发送的系统操作提交成功后记录。记录不上传、不进入普通内容备份；点击重新查询当前内容，清空历史与清空搜索分开处理。
- 普通和重复手动启动显示主窗口，开机启动保持后台跟随。新本机库首次主动显示提供独立使用指引，已有用户可从菜单重开；指引不生成示例或自动发送。
- 云文件支持多选及拖入批量上传，准备和上传共用两个名额；逐项反馈失败、支持取消、重开管理窗口和继续原任务，切号、撤权及断线停止后续任务，重启不自动重传。
- 个人库按账号保留内容和最近同步时间，移除本机库切换入口，旧内容可显式找回。旧完整备份的个人内容与本机文件／设备设置分别预览确认，不将设备设置跨账号恢复。
- 统一“个人话术”“共享话术”“回收站”名称。回收站提供两个来源按钮、搜索及分页，清空仅处理确认清单，保留后来新增记录；共享清空需支持该接口的新 Hub，旧 Hub 仍可逐条删除。共享库同步时间集中在管理列表展示，键盘焦点反馈覆盖更多窗口。

用户数据标识、安装 AppId、凭据和既有备份保持连续。安装、升级和卸载保留数据；文件库只删除关联，不删除外部源文件。共享话术回收站清空的服务端实现属于独立 Hub 工程，本次客户端发布不替换已部署的 Hub。

前端199项、Rust142项、发布脚本12项及 TypeScript／Vite、Rust格式、Clippy检查通过。各功能已执行隐藏实际 Windows WebView2／Rust／SQLite 联调，在线更新使用真实签名夹具，安装验收使用隔离 AppId 与目录；详细报告和限制见[验收记录](https://github.com/thelinyue/QuickPhrase/blob/master/docs/acceptance.md)。模拟投递、隔离宿主和自动构建不代表本版真实企业微信、用户安装版在线升级、实体拖拽／文件选择器、Windows 10、150%／200%及多显示器 DPI、真实局域网／HTTPS代理已经验收。

程序与安装器未附带 Windows Authenticode 代码签名，可能显示未知发布者。更新清单的 Minisign 签名用于认证下载内容，不等于 Windows 代码签名。发布资产提供安装器、免安装 ZIP、原有 `SHA256SUMS.txt`、`release-manifest.json` 和新增 `SHA256SUMS.txt.minisig`。支持 Windows 11 x64；Windows 10 1607+待实机验收，ZIP需预装 WebView2。
