# 闪语 QuickPhrase 0.2.8

本版新增本机 AI 连接和统一文件关联，完善全局搜索、设置保存及快捷键候选。配套 Hub 0.2.3 提供云文件改名和新的清理规则，建议先升级 Hub，再升级客户端；发布不会自动修改现有服务端部署。

- 设置修改即保存，仅更新对应选项，保留标签页、焦点和输入草稿；连续修改后关闭窗口会等待保存完成，失败保留窗口并提示。
- 快捷键支持不同普通键短暂重叠及带修饰键的有序序列，同键仍需松开再按。候选宽度收窄为240—360 DIP，长内容省略并提供完整悬停提示，优先靠近文字光标或输入控件，支持边缘避让和窗口移动跟随。序号、自定义及全局开关独立生效，“直接发送”仅作用于序号快捷键。
- 主窗口和底部搜索混合检索个人、授权共享、已订阅成员话术及本机关联文件，按“话术／文件”分组；移除顶部范围按钮及行末分类展示，右键菜单保持搜索结果。共享话术支持按服务器、账号设置本机默认库。
- 文件列表统一管理本地和云文件关联，独立宽窗口支持批量选择；文件空白处及分类标签右键均可“关联文件”。移除关联保留源文件，云文件关联按账号隔离。
- 云文件支持公共名称修改，与关联的个人显示名区分；改名保留文件ID、字节及原始上传名称，不要求改写历史话术。回收站永久删除无需再次手输文件名，并可一键清理；管理员可清理被引用文件的云端本体，已有完整本机缓存仍可使用，未缓存设备或清除缓存后无法再下载。还原话术不恢复已清理本体。
- 新增“AI 连接”：官方 Rust MCP SDK、仅本机 Streamable HTTP，默认关闭、默认未授权任何库。独立令牌存入 Windows 凭据管理器，逐次核验账号和库授权，支持分类／话术读取与事务写入、库内移动排序、回收和授权目录素材导入；不提供发送、剪贴板、永久删除或账号管理工具。
- 已验证安装包启动失败时保留安装包并打开所在目录，提供手动打开入口；下载或校验失败不会误开目录，启动安装器不等同安装完成。

验证记录见[验收文档](https://github.com/thelinyue/QuickPhrase/blob/v0.2.8/docs/acceptance.md)。本地前端332项、客户端Rust195项、发布脚本12项及相关格式、Clippy、构建检查纳入本次发布验证；现有隔离WebView2／HTTP／MCP与Windows输入桌面检查覆盖上述核心行为，正式工作流从版本标签重新运行Windows CI并构建发布资产。

真实企业微信、实体键盘／输入法、多屏混合DPI、用户安装版在线升级、Windows 10、真实局域网／HTTPS代理及旧客户端二进制兼容尚未完成本轮验收。搜索基于已授权缓存，不承诺覆盖未同步内容；切号、注销和撤权仍沿用现有访问及缓存清理边界。

程序和安装器未附带 Windows Authenticode 代码签名。Minisign 认证更新清单与下载内容，不等同 Windows 代码签名。提供Windows x64安装器、免安装ZIP、`SHA256SUMS.txt`、`SHA256SUMS.txt.minisig`及`release-manifest.json`；ZIP需预装WebView2，安装、升级和卸载保留用户数据。
