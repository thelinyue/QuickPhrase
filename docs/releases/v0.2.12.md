# 闪语 QuickPhrase 0.2.12

本版改进剪贴板占用时的投递体验和操作结果提示，不改变闪云服务端或数据格式。

- 插入和发送遇到剪贴板占用时，每个内容块最多等待约三秒；等待期间可停止，目标、输入或剪贴板发生变化时停止投递，不重发已执行的内容。持续占用时尽量提示检测到的程序，无法识别时明确说明。
- 失败或中断的投递回执在本次运行内按个人库和账号会话隔离，可在可见的主窗口或底栏逐条确认；部分执行或结果不可用时提醒先检查目标，避免重复操作。
- 统一窗口级成功、错误与警告提示；长提示可展开查看，表单校验与危险确认保留原位置。两个投递提示窗口均隐藏时不会主动唤醒。
- 提供 Windows x64 安装器、免安装 ZIP、SHA256 清单、清单的 Minisign 签名和更新 manifest；安装器和程序未附带 Windows Authenticode 代码签名。

系统操作已提交不代表目标应用最终已粘贴、发送或送达。真实企业微信、实体输入法、Windows 10、多屏及实际 DPI、安装版升级和用户电脑上实际的剪贴板占用场景不属于自动检查范围；隔离宿主或模拟测试不能替代这些实测。客户端独立发布，闪云服务端不需要本次升级。
