# 闪语 v0.1.3

- 修复真实企业微信无法自动吸附：按进程及精确窗口类型识别主窗口和独立聊天窗口，侧栏与底栏共用目标，图片等其他窗口不继承吸附关系。
- 修复运行闪语后系统鼠标卡顿：全局鼠标钩子改用独立消息线程，保留候选外部点击取消保护。
- 修复双击标题栏或底栏导致白窗：窄侧栏禁用最大化，保留拖动、自由调整和最小化，独立编辑及排序窗口仍可最大化。
- 修复 Alt 导航误触隐式系统菜单，以及底栏品牌、常用短语栏双击选中文字；保留 Alt+空格和 Alt+F4。
- 精简快捷键帮助，移除视频入口，保留按键图示及设置、触发、选择、取消和保存说明。
- 清理历史评审与运行截图，保留验收报告和应用素材。

## 支持与验收

正式支持 Windows 11 x64。发布负责人于 2026-10-12 确认本次修复版真实企业微信人工验收，以及 Windows 11 新装／升级／卸载保留数据矩阵，两项均已完成并通过。人工结果由负责人提供，自动化与隔离宿主不替代实机验收。

前端60项、Rust71项、发布脚本14项测试，以及类型、格式、Clippy、前端／Debug／Release与安装器构建、工作流检查通过；隔离吸附／悬停17组、后台跟随20组、鼠标延迟4项、完整原生17组通过。

真实企业微信主窗口和客户独立聊天窗口的吸附对齐、最小化恢复、图片窗口排除及双击专项已有本机记录；普通独立聊天窗口类型另有隔离宿主验证。详细检查范围与历史报告见 `docs/acceptance.md`。

Windows 10 1607+、多显示器及跨屏 100%／150%／200% 系统 DPI、真实中文输入法、实际登录开机启动、不同权限目标及其他软件发送兼容仍待实机验收。系统输入提交成功不代表目标应用最终网络送达。

## 下载与安装

- `Shanyu-Setup-0.1.3-x64.exe`：当前用户安装器，无需管理员权限；缺少 WebView2 时需联网安装微软运行时。
- `Shanyu-0.1.3-win-x64.zip`：程序及许可、安全、隐私、签名政策；运行需要已安装 WebView2。
- `SHA256SUMS.txt` 和 `release-manifest.json`：资产校验、版本、来源提交、平台和发布通道。

程序和安装器均未附带 Authenticode 签名，Windows SmartScreen 可能显示未知发布者提示。请从本项目 GitHub Release 下载并核对 SHA256。安装、升级和卸载保留用户数据；升级前建议导出完整备份。
