# 闪语 QuickPhrase 0.2.15

本版改进同步后的素材缓存和首次投递体验，不涉及闪云服务端升级或数据库迁移。

- 个人、共享和成员话术同步或更新后，后台自动缓存图片与附件，无需先打开对应分类；云文件目录更新后自动缓存当前账号可见的活动文件。各来源复用缓存和下载锁，共用最多两个下载名额；自动缓存会使用本地空间和下载流量。
- 用户明确触发插入或发送时，缺失素材先下载，整条素材就绪并重新核验后继续本次投递，无需再次点击。后台缓存和独立下载本身不触发投递；文件列表的复制、打开仍保留首次下载后重新触发的规则。
- 下载等待期间保持发送锁，并持续核验原目标、账号、取消状态和剪贴板；下载失败、目标或内容变化、新复制及退出账号时停止本次投递，不自动重发已执行内容。
- 修复无标题话术悬浮预览重复显示内容。
- 提供 Windows x64 安装器、免安装 ZIP、SHA256 清单、Minisign 签名和更新 manifest；程序和安装器未附带 Windows Authenticode 代码签名。

已有源码专项通过真实 WebView2、Rust IPC、本机 HTTP 和 Windows 剪贴板／按键，覆盖自动缓存、首次投递补齐、防重入、下载失败及等待期间中断；投递对象为隔离宿主。真实企业微信最终接收、真实服务器网络、用户安装版升级和系统多屏／DPI 尚未验收。发布自动检查及公开资产核验结果另记于[验收记录](../acceptance.md)，不以隔离测试替代上述实机验收。
