# 闪语 QuickPhrase 0.2.9

本版改进快捷键目标与输入行为、成员话术快捷键恢复，并新增临时问题诊断。配套 Hub 仍为 0.2.3，本次不会修改服务端部署或用户数据。

- 自动识别已确认且仍在前台的聊天窗口后，同步快捷键目标；吸附开关关闭时也能使用相应范围内的快捷键。候选跨屏定位使用自身 DPI 重新测量，过渡期间避免裁切数量和关闭按钮。
- 普通字母、数字双键的首键即时透传；话术候选显示时，数字、空格和 Enter 用于选择，继续普通输入会取消候选。选中话术后保留触发文字，不强制提交或取消输入法组字，也不自动重试已执行的投递。
- 成员话术快捷键在启动后从已恢复的成员缓存和本机偏好重建；联网内容未变化、离线重启以及本人同步未开启时也无需重新设置。退出登录或撤销来源后，旧候选不能继续投递。
- “设置 → 问题诊断”可按问题临时记录最多五分钟，停止后手动导出 ZIP。只收集限定的枚举与数值，不打包正文、实际按键、账号密码、原始日志、数据库、素材或截图；重启保留已落盘证据，不自动继续详细采集。范围和局限见[诊断说明](https://github.com/thelinyue/QuickPhrase/blob/v0.2.9/docs/diagnostics.md)。

验证记录见[验收文档](https://github.com/thelinyue/QuickPhrase/blob/v0.2.9/docs/acceptance.md)。本地前端 338 项、Rust 204 项、发布脚本 12 项以及 TypeScript、Rust 格式、Clippy 和 Windows Debug 构建通过；独立 Windows 输入桌面的快捷键与诊断 18 组、成员重启 12 组通过。通用原生脚本的旧常用短语断言与当前产品菜单不符，未取得全套通过结论。正式工作流会从版本标签重新运行 Windows CI 并构建资产。

真实企业微信与实体键盘上的首键和中文输入法行为尚未确认。本机微软拼音测试中，话术候选与组字可共存，但组字期间选话术后宿主未接收粘贴；关闭快捷键后的标准 Ctrl+V 对照同样未粘贴，不能据此确认真实企业微信的插入结果。实际多屏 DPI、Windows 10、用户安装版在线升级及真实局域网／HTTPS代理仍待验收。诊断包不能覆盖所有卡死、系统崩溃或目标应用最终接收情况。

程序和安装器未附带 Windows Authenticode 代码签名。Minisign 认证更新清单与下载内容，不等同 Windows 代码签名。提供 Windows x64 安装器、免安装 ZIP、`SHA256SUMS.txt`、`SHA256SUMS.txt.minisig` 和 `release-manifest.json`；ZIP 需预装 WebView2，安装、升级和卸载保留用户数据。
