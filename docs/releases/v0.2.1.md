# 闪语 QuickPhrase 0.2.1

英文名称统一为 QuickPhrase。主程序改为 `QuickPhrase.exe`，安装包和ZIP使用 `QuickPhrase` 前缀，关于页及Windows程序属性显示“闪语 QuickPhrase”。新安装默认使用 `Programs\QuickPhrase`；升级继续识别原安装并保留原目录，更新快捷方式及开机启动项。

用户数据目录、数据库、凭据和备份格式保持既有标识，旧文件与账号连续可用。Windows应用身份与快捷方式统一；由uTools等启动器直接启动时，任务管理器仍可能按父子关系分组。已发布0.2.0的标签与资产保留原名。

升级后，固定指向 `shanyu.exe` 的外部快捷方式需改为 `QuickPhrase.exe`，uTools等启动器需刷新应用索引。任务管理器分组核对需先从托盘退出旧单实例，再从开始菜单直接启动；重复启动会复用原进程及其启动关系。

Hub源码程序改名为 `quickphrase-hub`，新增 `QUICKPHRASE_*` 配置并兼容原变量。Compose使用0.2.1镜像和新变量；旧变量继续兼容。服务改名需先停止旧容器，保留数据目录。服务端源码：[QuickPhrase-Hub](https://github.com/thelinyue/QuickPhrase-Hub)（私有）；[公开镜像](https://github.com/users/thelinyue/packages/container/package/quickphrase-hub)和[完整可复制部署配置](https://github.com/thelinyue/QuickPhrase/blob/master/docs/team-sharing.md)无需源码访问。

## Hub图形界面部署

在Docker／NAS图形界面新建Compose项目，粘贴以下配置并填写 `QUICKPHRASE_ADMIN_PASSWORD`，密码至少8个字符。旧项目升级前先停止并备份原 `data`；保留原项目目录和挂载，避免新旧服务并行访问数据。首次登录修改初始密码。

```yaml
services:
  quickphrase-hub:
    image: ghcr.io/thelinyue/quickphrase-hub:0.2.1
    user: "0:0"
    restart: unless-stopped
    ports:
      - "7823:7823"
    environment:
      QUICKPHRASE_ADMIN_USERNAME: "admin"
      QUICKPHRASE_ADMIN_PASSWORD: ""
    volumes:
      - "./data:/data"
```
