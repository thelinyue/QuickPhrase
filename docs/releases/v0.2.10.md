# 闪语 QuickPhrase 0.2.10

本版改进快捷键候选选择后的触发字符清理与微软拼音处理，个人和成员话术共用同一投递流程。配套 Hub 仍为 0.2.3。

- 普通字母、数字双键继续即时透传。选择候选后先核验话术、授权及素材，再清理本次触发字符并插入；长按按实际输入次数清理。取消候选保留输入。
- 标准 Edit 输入框核对准确文字范围；已识别的企业微信自绘输入区采用键盘退格路径。微软拼音会临时结束组字，使此前未完成拼音先上屏，再清理触发字符和粘贴；结束后在目标及输入状态未变化时恢复原输入法模式。此前拼音内容保留，但不保留未完成组字状态。
- 切窗、继续输入、光标变化或新复制会停止后续操作。清理后失败明确提示已执行步骤，不自动重试或回填。自绘输入区中的中文数字可能参与选字，无法确认时保留输入并拒绝清理，可改用字母双键或 Ctrl／Alt 组合。
- 修复最后一次插入提交后，用户立即继续输入或按回车导致的中断误报；仍会中止尚未执行的后续内容和发送按键。

验证记录见[验收文档](https://github.com/thelinyue/QuickPhrase/blob/v0.2.10/docs/acceptance.md)。本地前端 338 项、Rust 208 项、发布脚本 12 项以及 TypeScript、Rust 格式、Clippy、Windows Debug 构建通过；0.2.10 隔离宿主快捷键与诊断 20 组、键盘清理专项及成员话术 13 组通过。正式工作流从版本标签重新检查并构建资产。测试输入为标记模拟按键。

此前未发布源码的标准 Edit 和键盘路径微软拼音检查各 9 组通过，报告运行时版本为 0.2.9。本次 0.2.10 复验在交互桌面因前台焦点变化停止；隔离桌面在关闭快捷键的对照中也不能建立组字，因此本次输入法完整复验为环境未完成，不计为通过。

真实企业微信的最终草稿与消息发送、实体键盘输入、其他输入法、Windows 10、实际多屏 DPI 和用户安装版升级仍未验收。未知自绘输入区不执行自动清理。系统提交粘贴或发送按键不等于目标应用最终发送成功。

程序和安装器未附带 Windows Authenticode 代码签名。Minisign 认证更新清单与下载内容，不等同 Windows 代码签名。提供 Windows x64 安装器、免安装 ZIP、`SHA256SUMS.txt`、`SHA256SUMS.txt.minisig` 和 `release-manifest.json`；ZIP 需预装 WebView2，安装、升级和卸载保留用户数据。
