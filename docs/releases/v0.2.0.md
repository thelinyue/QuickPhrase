# 闪语 v0.2.0

普通账号、共享库和公共云文件正式加入 Windows 桌面端。每个人管理“我的话术”，需要协作时加入共享库；已有账号、用户名、库名、文件名和内容保持原样，无需迁移。

## 账号、共享库与同步

- 工号改称用户名，姓名改称昵称；用户名支持1—64个字符的普通名称，昵称和联系方式可选。服务管理员创建账号，用户首次登录改密。
- 主菜单提供账号与同步、共享库管理、云文件；服务管理员另有账号管理。共享库角色为查看者、编辑者、库管理员，创建共享库的权限默认关闭。
- 支持成员草稿、版本冲突、库管理员移交、退出、整库删除、恢复及引用保护；离线只读使用缓存，联网核验权限。
- 个人同步默认关闭，首次预览并确认后开启。按服务器与账号隔离，退出仍可离线编辑，同账号登录继续同步；冲突保留双方内容，设备设置保留本机。

## 云文件

- 所有完成初始改密的用户均可查看、下载、关联云文件，无需加入共享库。服务管理员分别授权上传、删除和恢复；永久删除及配置权限仍仅服务管理员可做。
- 桌面窗口保留蓝色标题栏、浅灰侧栏、文件图标、纯图标操作、搜索、10／20／50条分页、批量操作、上传／下载管理、权限页及回收站；修复上传文字错位和窄窗批量按钮位置。
- 共享库直接引用同一云文件本体；我的话术保存独立附件，同一账号本机库复用可用副本。删除会移入回收站并禁止新增引用，有现有或回收话术引用时拒绝永久删除；个人副本保留。
- 上传使用固定 ID、受控源副本和结果查询；撤权及重新授权不能接收旧任务。下载完成由用户重新触发投递，不自动发送。

## 导入导出与桌面操作

- ZIP 导出包含实际图片和附件字节，导入先预览并生成目标库独立附件，兼容旧备份与个人完整备份。
- 共享数据备份保存账号、共享库、云文件、回收记录和素材，排除个人内容；完整运维备份停服保存整个数据目录。
- 修复多管理窗口快捷键暂停、弹窗内关闭和账号切换时旧响应问题，保留未保存草稿确认。
- 移除投递前旧剪贴板备份与恢复；投递核验剪贴板序号，用户新复制立即停止，完成后保留最后写入内容。

## Hub 部署

先升级 Hub，再升级客户端。Hub 项目：[QuickPhrase-Hub](https://github.com/thelinyue/QuickPhrase-Hub)（源码私有）；[0.2.0 公开镜像](https://github.com/users/thelinyue/packages/container/package/quickphrase-hub)已完成匿名拉取和容器验收，Linux x64 部署无需源码权限或 GHCR 登录。

在 Docker／NAS 图形界面新建 Compose 项目，选择固定目录，粘贴下面配置，填写自己的初始密码后部署。初始密码至少8字符，建议12位以上随机字母数字；首次登录必须改密。

```yaml
services:
  shanyu:
    image: ghcr.io/thelinyue/quickphrase-hub:0.2.0
    user: "0:0"
    restart: unless-stopped
    ports:
      - "7823:7823"
    environment:
      SHANYU_ADMIN_USERNAME: "admin"
      SHANYU_ADMIN_PASSWORD: ""
    volumes:
      - "./data:/data"
```

直接以 root 运行，自动创建 bind 数据目录，无需额外权限命令。已有数据库不会被初始化变量覆盖；升级前停服备份整个 `data`，保留旧目录和卷。部署、回退及恢复说明见[公开部署文档](https://github.com/thelinyue/QuickPhrase/blob/master/docs/team-sharing.md)。共享协议继续固定 `c727d4de57b3855aae445797178d68a12d83f548`，内部 API、数据库字段和目录不改名。

## 验证与限制

本轮真实企业微信发送矩阵及 Windows 11 新装／升级／卸载矩阵全部通过，确认来源为负责人在本会话的明确确认；不虚构逐项人工日志。自动检查及隔离联调证据见[验收记录](https://github.com/thelinyue/QuickPhrase/blob/master/docs/acceptance.md)。Windows 10、系统 DPI／多显示器、真实局域网、HTTPS／代理及旧共享库客户端连接新 Hub 仍未完成本轮实测。

Windows 安装器和 ZIP **未进行代码签名**，Windows 可能显示未知发布者。校验沿用 `SHA256SUMS.txt` 与 `release-manifest.json`。本轮不会自动替换已有安装或 WSL 部署，不移动已发布标签或覆盖资产。
