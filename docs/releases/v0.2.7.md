# 闪语 QuickPhrase 0.2.7

本版集中修复贴边隐藏、吸附和窗口尺寸问题，并完善个人快捷键、预览及更新提示。可从0.2.6安装升级，保留用户数据。本次只发布Windows x64客户端，不部署或更新Hub。

- 贴边隐藏后，点击其他软件的输入框、右键或长按不再意外唤出闪语。触碰边条并停留即可自动展开；展开时临时置顶且不抢输入焦点，退出贴边后恢复原置顶设置。
- 鼠标进入话术区或原生窗口边框后保持展开，收起途中重新移入立即恢复展开；反向动画从实际显示位置接续，避免鼠标仍在窗口内却继续收回。保留三档边条悬停等待和主动唤起。
- 首次独立打开直接定位到当前屏幕右侧，避免先显示在左侧再跳转。首次使用的默认可见尺寸约306×720 DIP，调整后记住本机大小，重启和升级沿用；跨屏按系统缩放保持逻辑尺寸。
- 实际吸附时禁止拖动和改变高度；允许自由调整大小时仅能调整宽度。解除吸附保留最新宽高和当前显示器，不再恢复其他显示器的旧坐标及DPI；同屏仍可恢复原独立位置，越界位置平移回当前工作区。
- 个人话术中使用成员分享内容时，可设置仅属于本机当前账号的自定义快捷键，不修改来源成员正文。重启和重新登录保留绑定，来源撤权后不再参与候选；保留冲突、账号变化和发送目标校验。
- 鼠标正文预览在屏幕边缘自动向左或向上展开，并限制在可用工作区内；长内容可滚动。标题栏文字不再因鼠标拖划被选中。
- 检测到已验证的新版本后，在右下角“闪语”旁显示“新”角标；鼠标悬停查看当前与最新版本，点击进入关于页手动升级，不再占用顶部话术区域。

首次从尚未保存窗口大小的旧版升级时，请保持旧客户端打开，由安装器读取窗口大小并关闭。旧版已退出、最小化或没有可用记录时无法恢复原大小，可能使用默认尺寸。之后客户端会自行保存窗口大小；安装、升级和卸载保留用户数据。

发布前前端301项、Rust180项、发布脚本12项以及TypeScript／Vite、Rust格式与Clippy通过；贴边、窗口恢复、成员快捷键、预览及隔离安装升级的已验证范围见[验收记录](https://github.com/thelinyue/QuickPhrase/blob/v0.2.7/docs/acceptance.md)。正式工作流会从本版标签重新运行Windows CI并构建资产。真实多显示器及混合DPI、企业微信交互、用户安装版在线升级、Windows 10、实际代理和不同权限目标未完成本轮实机验收；单屏及隔离宿主结果不代表这些环境已经通过。

程序与安装器未附带Windows Authenticode代码签名，系统可能提示未知发布者；Minisign只认证更新下载内容，不等同于Windows代码签名。提供Windows x64安装器、免安装ZIP、`SHA256SUMS.txt`、`SHA256SUMS.txt.minisig`和`release-manifest.json`，可按清单核对下载文件。ZIP需预装WebView2；Windows 11 x64为当前验证环境，Windows 10 1607+尚待实机验收。
