# 闪语 QuickPhrase 0.2.5

本版优化最小化悬浮窗、贴边隐藏和搜索刷新，从0.2.4正常升级，保留已发布版本及用户数据。

- 悬浮窗采用88×34 DIP白底布局、6 DIP圆角与24 DIP图标，文字跟随主题色；双击打开主窗口，拖动调整位置并跨重启记忆，单击不打开。
- 悬浮窗原生右键菜单新增“隐藏悬浮图标”“永久隐藏悬浮图标”“打开主界面（双击）”。临时隐藏持续到重新打开主窗口后再次最小化；永久隐藏关闭已有设置，可在常用设置中重新开启，写入失败恢复原设置。
- 打开设置或在设置内输入不再阻止主窗口贴边隐藏，保留主窗口输入、菜单、预览、拖动与发送期间暂停收起的保护。
- 主搜索和底部搜索的快捷键标识仅在鼠标悬停该行时显示。相同内容的后台通知不重复搜索，真实内容更新保留列表、选中项与滚动位置；更新中或失败时暂停旧结果投递，切换账号、权限或来源立即撤下旧结果。

安装、升级和卸载保留用户数据，文件库只管理关联、不删除外部源文件。在线更新沿用签名清单、manifest和安装包校验，自动检查不自动安装；0.2.3及以后客户端可检查本版更新，更早版本需手动安装。本次只发布客户端，不升级已部署的Hub；成员话术与开放共享仍需要配套新版Hub，当前公开0.2.1镜像不含此功能。

发布前前端282项、客户端Rust160项、发布脚本12项，以及TypeScript／Vite、Rust格式、Clippy与Windows CI通过。悬浮窗17组、贴边隐藏8组、搜索10组隔离Windows／WebView2专项通过，详见[验收记录](https://github.com/thelinyue/QuickPhrase/blob/master/docs/acceptance.md)。正式发布工作流继续对本版标签执行完整检查和构建。隔离宿主、模拟投递与构建成功不能代表真实企业微信、用户安装版在线升级、实体托盘／拖拽／文件选择器、Windows 10、125%／150%／200%系统DPI、多显示器或真实局域网／HTTPS代理已验收。

程序与安装器未附带Windows Authenticode代码签名，可能显示未知发布者；更新清单的Minisign签名用于认证下载内容，不等于Windows代码签名。提供Windows x64安装器、免安装ZIP、SHA256SUMS.txt、SHA256SUMS.txt.minisig和release-manifest.json。支持Windows 11 x64；Windows 10 1607+待实机验收，ZIP需预装WebView2。
