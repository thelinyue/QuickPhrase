# 闪语 v0.1.1

本版将 Windows 客户端迁移至 Tauri 2、Rust 和 React，替换旧 .NET／WPF 实现，保留 MIT 许可。

- 提供分类、话术与常用短语管理、搜索、文字／图片／文件分段、快捷键候选、回收站和备份。
- 接入通用 Windows 发送、企业微信侧栏与底部面板吸附、托盘和设置；设置页显示实际应用版本。
- 更新安全、隐私和签名政策，恢复自动 CI，并统一候选与正式版打包流程。

## 支持与验收

正式支持 Windows 11 x64。发布负责人确认当前版本的真实企业微信人工矩阵，以及 Windows 11 新装／升级／卸载矩阵，两项均已通过。前端 57 项、Rust 65 项、发布脚本 14 项测试，以及 TypeScript、格式、Clippy 和构建检查通过。

Windows 10 1607+、系统 150%／200% 缩放、多显示器及跨屏 DPI、真实中文输入法、实际登录开机启动、不同权限目标和其他软件发送兼容仍待验收。隔离宿主和模拟测试不能代替这些实机验证；系统输入提交成功也不能证明目标应用最终网络送达。完整原生自动化回归及旧数据迁移仍有未完成项，详见仓库中的验收记录。

## 下载与安装

- `Shanyu-Setup-0.1.1-x64.exe`：当前用户安装器，无需管理员权限；缺少 WebView2 时需联网安装微软运行时。
- `Shanyu-0.1.1-win-x64.zip`：程序及许可、安全、隐私、签名政策；运行需要已安装 WebView2。
- `SHA256SUMS.txt`：ZIP 与安装器的 SHA256 校验值。
- `release-manifest.json`：版本、来源提交、平台、发布通道和未签名状态。

程序和安装器均未附带 Authenticode 签名，Windows SmartScreen 可能显示未知发布者提示。请从本项目 GitHub Release 下载并核对 SHA256。安装、升级和卸载保留用户数据；升级前建议通过应用导出完整备份。
