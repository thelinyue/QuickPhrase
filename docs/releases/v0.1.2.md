# 闪语 v0.1.2

- 首次使用由用户创建话术和文件分类，允许删除全部分类，重启后保持为空；已有分类与数据保留。
- 吸附侧栏宽度和底栏内容高度按各面板自身 DPI 换算，避免借用目标窗口 DPI；继续保持物理边缘对齐和无激活跟随。
- 自动吸附增加聊天输入控件状态检查，拒绝搜索、图片及不可编辑页面；移除此前显式表情字体覆盖，恢复默认字体回退。

## 支持与验收

正式支持 Windows 11 x64。发布负责人于 2026-10-12 确认当前版本真实企业微信人工矩阵及 Windows 11 新装／升级／卸载矩阵均已完成。人工结果由负责人提供，自动化和隔离宿主不替代实机验收。

前端59项、Rust70项、发布脚本14项测试，以及TypeScript、Rust格式、Clippy、前端／Debug／Release构建和工作流语法检查通过；隔离宿主吸附／悬停11组、后台跟随18组通过。

**当前源码尚无真实企业微信已核实的消息输入控件标识，真实企业微信聊天页暂不自动吸附。** 可通过托盘或快捷键独立打开。隔离 Debug 宿主的吸附结果不代表真实企业微信自动吸附兼容已完成。

Windows 10 1607+、多显示器及跨屏 100%／150%／200% 系统 DPI、真实中文输入法、实际登录开机启动、不同权限目标及其他软件发送兼容仍待实机验收。单屏环境中的双屏专项明确跳过。系统输入提交成功不代表目标应用最终网络送达。详细记录见 `docs/acceptance.md`。

## 下载与安装

- `Shanyu-Setup-0.1.2-x64.exe`：当前用户安装器，无需管理员权限；缺少 WebView2 时需联网安装微软运行时。
- `Shanyu-0.1.2-win-x64.zip`：程序及许可、安全、隐私、签名政策；运行需要已安装 WebView2。
- `SHA256SUMS.txt` 和 `release-manifest.json`：资产校验、版本、来源提交、平台和发布通道。

程序和安装器均未附带 Authenticode 签名，Windows SmartScreen 可能显示未知发布者提示。请从本项目 GitHub Release 下载并核对 SHA256。安装、升级和卸载保留用户数据；升级前建议导出完整备份。
