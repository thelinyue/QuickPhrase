# 闪语 QuickPhrase 0.2.13

“云文件管理中心”升级为“闪云中心”，新增常用命令共享。配套闪云 0.2.5，建议先备份并升级服务端，再升级客户端。

- 在主菜单打开“闪云中心”，顶部切换“云文件”和“云命令”。云文件仍为默认页，切换模块不会停止正在进行的文件传输，原有离线文件缓存继续可用。
- 云命令支持分类、搜索、分页及详情查看，可集中维护常用 Linux 下载、安装等命令。点击“复制命令”只复制原始文本，不执行脚本、不打开终端，也不进入话术投递或 MCP；运行前请自行核对来源和参数。
- 普通账号默认不开通云命令。管理员在独立“权限管理”中按账号授予使用或维护权限，云文件权限保持独立；维护者可新建、编辑、回收和恢复命令，永久删除仅限服务管理员。
- 云命令仅在线可用，复制前重新核对会话、授权和所见版本。命令已更新、回收或权限变化时拒绝复制；断网不显示旧正文，未保存草稿仅保留在当前窗口内存。编辑或授权冲突保留草稿，不自动覆盖他人的改动。
- 提供 Windows x64 安装器、免安装 ZIP、SHA256 清单、清单的 Minisign 签名和更新 manifest。安装与升级保留用户数据；程序和安装器仍未附带 Windows Authenticode 代码签名。

旧闪云仍可使用原有云文件功能，管理员会看到云命令需要升级的提示。闪云镜像发布不会自动升级现有部署；升级前请停服并完整备份实际挂载的 `data` 目录。

本次已完成自动测试、真实 WebView2／Rust IPC 与隔离服务端联调，以及 Linux 容器持久化和备份恢复验收。成功写入真实系统剪贴板、目标终端执行、Windows 10、实际多屏／DPI、用户安装版升级、真实旧新版二进制双向组合及生产网络不属于本次已验证范围。
