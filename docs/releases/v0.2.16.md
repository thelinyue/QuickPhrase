# 闪语 QuickPhrase 0.2.16

- 更新优先通过工具商店获取原始发布清单、签名及安装包；仅未配置商店时允许使用官方更新源，保留既有验签和完整性校验。
- 普通界面文字不再被意外选中；输入、编辑和明确的复制操作继续保留选择能力。
- 云端命令支持分段处理，初次目录加载反馈更明确。
- 正式发布完成后独立通知工具商店同步；同步失败可单独重试，不重新构建或覆盖已发布附件。

提供 Windows x64 安装器、免安装 ZIP、SHA256 清单、Minisign 签名和原始更新 manifest。程序和安装器未附带 Windows Authenticode 代码签名；更新签名不等同于 Windows 代码签名。

发布工作流执行前端、Rust、发布脚本检查和正式构建。模拟与隔离验收不代表真实企业微信最终接收、用户安装版升级或多屏／DPI 已通过；商店同步及真实客户端更新结果另行核验。
