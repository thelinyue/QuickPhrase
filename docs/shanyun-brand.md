# 闪云

闪云是闪语的自托管同步与共享服务，原称 Hub。品牌改名不改变程序、镜像、环境变量、API、健康检查响应或数据目录；历史发布与验收记录保留原名称。

## 图标

- [SVG 主文件](../public/shanyun.svg)：64×64 画布，青绿色 `#159D93` 云形和一道透明负形闪光；没有底座、文字或背景。
- [PNG](../public/shanyun.png)：由 SVG 导出的 512×512 透明图片，用于文档和部署介绍；服务端文档中的副本保持一致。
- 界面优先使用 SVG，兼顾 16／20／32／64 像素；不改变比例，不添加断线角标，不随连接状态变灰。
- 图标与“闪云”文字相邻时作为装饰，不重复朗读；独立使用时提供“闪云”的替代文本。
- 闪语仍使用现有鹦鹉图标；闪云图标不替换客户端标题栏、任务栏或安装包图标。

## 设置页与状态

设置侧栏、页标题和主菜单入口统一为“账号”，页内保留“同步与共享”分组；旧“账号与共享”“账号与同步”“共享话术”导航名称继续兼容。

已登录时以“图标＋闪云＋地址”替代原服务器地址行，地址过长时省略并保留完整悬停提示。断连保留账号、图标和地址，独立显示“已断开连接”和“重连”。未登录及修改连接表单的字段名为“服务地址”。

文件行使用“离线可用／未缓存”，不重复连接状态；目录提示为“连接已断开，显示最近目录；已缓存文件仍可使用。”。离线操作提示“请重连后操作。”，版本、权限、证书和写入结果不确定等具体错误原因仍需保留。
