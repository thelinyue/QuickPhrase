# 云文件：调研与实现

更新日期：2026-10-16。适用版本：当前开发工作区（未发布）。范围：Windows x64 桌面及 QuickPhrase-Hub；不包含手机端。功能代码已接入，验收范围与环境缺口见下文。

## 调研依据

[客服宝云文件教程](https://kefubao.com/userHelp/2024-08-29/18.html)标注日期为2024-08-29。本次读取正文及三段桌面操作动图，确认集中上传、设置文件话术标题、其他用户名下载后使用，以及文件名搜索、大小、上传人、上传时间和传输管理入口。没有登录或实测客服宝。

教程显示权限、空间／流量及回收站入口，但未公开其规则；单文件上限、收费、替换、回收保留期和断点续传不属于已证实的竞品能力。闪语采用自身权限和数据安全规则。

## 桌面窗口与使用

- 主菜单“云文件”打开1000×650独立窗口，最小760×480。采用桌面动图中的蓝色标题栏、浅灰左栏、白色内容区和细线表格，支持最小化、最大化／还原及关闭。左上“云文件管理”；左下按权限显示“云文件权限管理”“云文件回收站”。空间／流量收费管理不纳入此次改版。
- 顶部依次为文件名搜索、刷新、下载管理、上传管理、上传新文件。表格显示勾选、文件名、大小、上传时间、上传者和操作；文件名下显示本机下载状态。操作栏仅显示图标，悬停提示名称并保留键盘及无障碍标签；“更多”菜单提供另存为、生成话术。目录、选择弹窗、传输页及回收站统一使用Windows系统关联图标，未下载也能显示。
- 上传时间默认倒序，可切换正序。分页提供前后页、页码跳转及10／20／50条，默认10条；全选仅选择当前页，搜索、翻页、排序或改变每页数量均清空勾选。批量操作在表格上方独立显示，紧邻已选数量，横向滚动时保持固定；文件页及回收站使用相同位置。批量下载在后台执行；批量删除先列出确认清单，再报告各文件结果。
- 上传／下载管理在右侧切换，保留左栏，提供返回、清空及文件名／进度／状态／操作。Rust保存任务快照，关闭重开窗口不重启任务；未决上传保留受控源副本并跨进程恢复，下载历史仅保留于当前进程。清空仅移除已结束记录，保留运行中和结果待核对的上传。
- 选择器支持多选，云文件列表及上传管理正文区接受Tauri原生拖拽并显示反馈，提交后直接进入上传管理。Rust批量登记固定任务ID、逐项校验文件，准备副本和上传共用两个名额，等待中的项不提前复制。同批相同路径去重，同名不同路径分别上传；文件夹、空文件、超限和不可读项分别显示中文原因，其他项继续。等待及执行中均可停止，关窗不停止；退出只保留已经固化的待核对任务，重启不自动上传。账号、上传授权版本或联网状态失效停止旧队列，后台复制不持账号锁，提交副本前再次复核。
- 已登录且完成初始改密的用户都可查看、下载和使用，无需加入共享话术。服务管理员可按用户名分别委派上传、删除、恢复，三个权限独立且对整个云文件库生效；新用户默认全部关闭。永久删除及权限调整仅服务管理员可执行，共享话术角色不增加云文件管理权。
- 权限页复用现有用户名目录及更新接口，提供用户名／昵称搜索、状态和逐行保存；管理员固定全部权限。并发保存使用配置版本，冲突保留草稿；离开或关闭未保存页面先确认。无授权能力的旧版闪云沿用固定管理员权限，并提示升级后才可配置授权。
- 服务管理员及有删除或恢复权限的用户可进入回收站。回收站显示上传／删除者及时间，历史缺失删除者显示“未知”；恢复支持单项和批量。服务管理员永久删除只需一次确认，无需输入文件名；“清空回收站”处理确认时全部回收文件，不受搜索和分页限制，允许清理仍被引用的云端文件，并报告逐项结果。已有本机缓存和个人副本仍可使用，未缓存或清除缓存后无法再下载。
- 云文件行右键提供下载、另存为、生成话术及有权限的删除；右键已勾选行保留多选并显示批量操作，未勾选行切为单选。空白处提供刷新、上传和传输管理。回收站右键沿用恢复及逐文件永久删除确认；输入框保留编辑菜单，其他区域不显示浏览器默认菜单。菜单支持窗口边缘避让、方向键、Esc及焦点恢复。
- 话术行、列表空白和一级／二级分类菜单提供“从云文件新建话术”：单选文件后进入现有编辑器，带入右键对象所属个人／共享库及分类，以文件名预填标题。选择期间账号、目标库、分类或编辑权限变化会取消；加载附件失败不能保存成空附件话术，已有编辑草稿不被覆盖。
- 编辑器“文件”工具提供“本机文件／云文件”。公共资料也可生成普通文件话术，再选择已有分类和标题；共享话术编辑仍需要共享话术编辑权。已有编辑窗口须先完成或关闭，避免覆盖草稿。
- 共享话术直接引用云文件 ID，多库共用同一服务端本体。个人话术在保存时生成目标个人库自己的实际附件，无论是否开启同步；同一本机个人库再次选择同一来源时复用副本，退出后重新登录也无需重新下载已有可用个人副本。复用键包含服务器、用户名身份和文件 ID，不跨账号共享。
- 公共图片、文档、视频等保留原字节并作为文件附件；行内图片继续用现有图片工具。沿用每条9个文件及单文件128MB限制。
- 文件 ID 对应不可变内容，同名新上传产生新 ID，更新话术须明确替换附件。标题和实际附件名称分开。
- 未缓存时先下载，完成后重新触发投递。全素材检查、目标核验、发送锁、剪贴板保护和中断规则继续生效，不自动发送或重试已执行段。

## 统一文件列表与改名（2026-10-16）

- 主窗口“文件”分类同时展示本地／云端关联。新增和重新关联使用900×600 DIP独立窗口，最小760×480，小工作区优先服从工作区限制。左侧选择一种来源，右侧显示本地清单或云端表格；支持批量选择，切换来源有选择时先确认清空。
- 云端表格包含搜索、刷新、按权限显示的上传入口、名称／大小／上传时间／上传者、10／20／50条分页及固定底栏。搜索、翻页和排序清空选择；失败保留草稿。话术编辑器使用同一表格的独立选择窗口，按请求编号、父窗口与会话接收结果，不覆盖其他编辑草稿。
- 设备库 `files` 无损补充 `cloud` 身份及 `custom_name` 标记，旧记录保留原 ID、路径、分类和顺序。云端身份包含服务器、用户 ID 和资产 ID；路径为空，不持久化缓存路径。备份／恢复保留身份，不新增跨设备同步。
- 云端关联按账号显示，离线不删除；已完整缓存的关联文件离线仍可打开和投递，显示“离线可用”；修改显示名、排序、移动和移除只管理关联。分类若含其他账号隐藏的云端关联，必须先由相应账号移除或移动，避免分类级删除连带清除隐藏记录。
- 两处混合搜索的“文件”组覆盖已关联的本地与云端文件，逐词查询只读取已授权目录缓存，目录刷新和服务端通知更新名称；全目录通过云端选择器检索。移出目录但完整缓存仍在时显示“仅本机缓存”，仍可使用；未缓存的已删除文件不可用。最近一次完整目录按账号保存，断连或离线重启后可查看并按名称筛选；目录连接异常时回退最近快照，标注云端断开。未缓存文件离线不可用，新增关联、下载和云端管理须重连后操作。切号、注销与授权失效沿用既有隔离和清理约束。尚可下载的文件先下载，再次由用户触发操作；批量复制全部就绪后才写入剪贴板。
- 公共名称与关联显示名分开。管理员可重命名全部活动云文件；仍有上传权限的原上传者可改自己的文件。扩展名固定，检查 Windows 文件名。事务只比较本文件旧名称，无关上传不构成冲突，冲突保留输入。
- 闪云增加不可变 `original_name`，迁移时取既有名称；上传重试和结果核对沿用原名，文件 ID 与字节不变。读取目录或接收通知更新客户端名称，按文件身份复用已校验缓存，保留正在使用的旧路径；不重新下载完整文件，也不批量改写历史话术或个人附件副本。
- 改名 API 和 `originalName` 是兼容扩展，当前共享协议依赖及锁文件保持原固定提交，无本机 path patch。旧版闪云的405响应提示升级；旧客户端可能保留快照名称。先升级闪云，再升级客户端；本轮未发布。

## 存储、协议与生命周期

闪云在共享 SQLite 中保存 `company_files`、目录版本及待清理记录，本体位于 `company-files/<ID>`。共享话术 `assets.team_id` 及其原有清理规则保留。

公开协议增加 `CompanyFile`、`CompanyFiles` 和默认关闭的 `capabilities.companyFiles`、`capabilities.companyFilePermissions`；`User.companyFilePermissions`缺省为无委派授权。共享话术快照增加默认空的 `companyAssetIds`，由服务端推导。普通话术仍使用原 `File(assetId,name)`。共享话术下载接口在逐次授权后解析已保留的云文件引用，使现有支持共享话术文件块的客户端可下载。

| 接口 | 用途 |
|---|---|
| `GET /api/company/files?q=&recycled=false` | 当前目录、搜索和目录版本；回收站向管理员及有删除／恢复授权的用户开放 |
| `GET /api/company/files/{id}` | 查询原上传任务结果及文件元数据；新增可选 `originalName` 用于按原名称核对上传 |
| `PATCH /api/company/files/{id}` | `{expectedName, name}` 修改公共名称，权限和旧名称在事务内重新核验 |
| `GET / PUT /api/company/files/{id}/content` | 下载／流式上传不可变本体 |
| `POST /api/company/files/{id}/recycle` | 删除（移入回收站），停止新引用 |
| `POST /api/company/files/{id}/restore` | 恢复同一条资料 |
| `DELETE /api/company/files/{id}` | 管理员确认后永久删除已回收文件，包括仍被引用的文件；界面一次确认后提交读取时的名称，无需用户重新输入 |
| `GET /api/users`、`PUT /api/users/{id}` | 服务管理员按用户名查询和修改云文件授权；普通账号资料更新不覆盖未提供的授权 |

上传先固化本机源副本和任务 ID，待核对任务独立于登录缓存保存，重启及重新登录后可以明确查询并继续。回执丢失先查询同一 ID，只有明确不存在才重新传输；已登记资料不能覆盖。正文选择使用明确的 ID 与位置类型，不能将云 ID 或 URL 当作本地路径。

现有`users`记录增加三个授权位、配置版本和上传授权版本。`UserWrite.companyFilePermissions`为可选更新对象，包含三个授权及`expectedVersion`；未提供时保持原授权。配置有变化时增加配置版本，仅上传授权变化时增加上传版本。上传请求携带`expectedUploadVersion`，闪云在开始及正式登记时逐次核验会话、权限和同一版本；撤权再授权仍拒绝此前的在途上传，删除／恢复授权变化不打断上传。复用授权SSE刷新界面和取消失效上传；撤回上传权限后仍可查询已登记结果。

目录变化通过 `company-files-version` SSE 通知。缓存按连接、账号和文件 ID 隔离，同一账号下多个共享话术共用云文件缓存及下载锁，下载沿用全局两个许可。缓存按素材目录保存合法原文件名，长名称截短保留扩展名；退出、切号、停用和旧任务失效检查沿用现有账号规则，个人附件独立保留。上传只接受标准小写 UUID，避免 Windows 大小写别名覆盖既有本体；云文件与共享话术素材禁止重复 ID，云文件名称由目录决定；共享话术在读取、保存和恢复时规范名称，原快照不因目录改名而批量重写，新增引用及回收生命周期检查仍然生效。

删除会移入回收站，保留本体和原话术引用；原话术编辑、话术回收还原及整库还原仍可用，新增引用被拒绝。永久删除与发布共用数据库锁和事务，允许清理仍被共享话术、话术回收记录及已删除小组引用的云端本体，不修改这些快照或用户个人内容。原引用和云文件身份保留，旧话术可编辑和还原，但不能新增引用，也不能重新下载已清理本体。永久删除保留最小 ID 删除标记，旧上传任务不能复活资料。文件删除失败保留待清理记录，启动时重试；共享话术永久删除仅处理本库素材和引用。

个人副本会增加磁盘和下载流量成本，跨账号仍各自保存；删除云文件无法收回个人副本、另存文件或已发送内容。

## 导入导出与备份

统一 ZIP 版本2包含实际附件字节，云文件导出通过同一共享话术素材解析取得本体；普通导入生成目标库独立附件，不重建云文件目录、用户名或权限。缺失附件、下载失败、取消或身份变化停止打包并保留原备份。

共享数据备份保存用户名授权和版本、云文件目录、删除者和回收状态及实际本体，排除用户个人内容及会话凭据。完整运维备份仍为停服保存整个数据目录，并按现有流程核对身份和同步世代。旧数据无损增加空云文件目录及缺省关闭的用户授权，不自动收录历史共享话术附件。先升级闪云，再更新客户端。
