# 闪语轻量双入口与浮动 Launcher 设计规格

状态：已实现，待发布验收  
日期：2026-08-17

## 1. 设计结论

闪语保留两个互补入口：

1. 贴边话术库：默认收起，保留窄条开关；展开后用于浏览、分类、编辑和快速插入。
2. 浮动 Native Launcher：作为闪语特色入口，通过 `Alt + Space` 独立呼出；不依赖贴边话术库是否展开。

Launcher 的核心目标是“呼出 → 搜索 → 选择 → 插入”一条路径完成，不承担完整管理页职责。

## 2. Launcher 首屏

- 呼出后不显示标题栏、品牌标题或欢迎态。
- 第一可见控件就是加宽的搜索框，并自动获得焦点。
- 搜索框支持关键词、拼音和模糊匹配；搜索结果来自本地内存索引，不直接查询 SQLite。
- 无输入时显示最近使用和常用话术。
- 结果列表最多显示 5 条，避免面板变成滚动管理窗口。
- 每条结果显示标题、单行预览、分类和可选的数字快捷键。
- 目标状态只以轻量信息显示在底部；无目标时进入安全复制/预览模式。

## 3. 交互规格

| 操作 | 行为 |
| --- | --- |
| `Alt + Space` | 呼出 Launcher，搜索框自动聚焦 |
| 输入文字 | 实时过滤本地结果 |
| `↑/↓` | 在结果中移动选中项 |
| 单击结果 | 仅选中，不执行投递 |
| 双击结果 | 对选中话术执行安全插入/复制 |
| `Enter` | 对选中话术执行安全插入/复制 |
| `Esc` | 关闭 Launcher，不改变贴边话术库状态 |
| 数字快捷键 | 直接选中当前列表对应结果；不绕过安全校验 |

双击和 `Enter` 的动作名称统一使用“插入”或“复制降级”，不在未验证能力时显示为无条件“发送”。

## 4. 安全与运行时边界

- Launcher 由 Native Host 负责呼出、目标捕获、Adapter 选择和动作执行；React 管理 UI 不参与投递决策。
- 任何插入前仍须重新验证 TargetIdentity；目标变化、窗口失效或 Adapter 不支持时不得继续动作。
- 当前企业微信 Profile 仅开放已验证的安全插入路径；发送能力保持不开放。
- 无目标、目标不可信或插入验证失败时，降级为安全复制或提示用户，不自动发送、不重复发送。
- Launcher 的打开、关闭和贴边话术库的展开/收起互不改变对方状态，也不抢占普通应用快捷键。
- 搜索、列表和预览不得记录用户话术正文到 DeliveryTrace。

## 5. 贴边话术库与管理页分工

- 话术库是独立工作区，负责浏览、搜索、分类树、排序、移动、新建、编辑、保存、删除、收藏和安全插入。
- 管理后台只保留通用设置、快捷键、Adapter 开关、投递能力和剪贴板策略，不显示话术列表、编辑器或“新建话术”入口。
- 话术编辑器属于话术库内部流程；V1 使用纯文本正文、可选标题、标签、快捷键和 `ColorKey`，图片、文件、日期和复杂富文本保留到 V2。
- 贴边库默认收起，展开/收起只影响可见性，不改变目标、焦点或 Launcher 快捷键。

## 6. 验收标准

- 启动后贴边话术库处于收起状态，并始终有可发现的展开开关。
- `Alt + Space` 呼出后，首个焦点位于搜索框，界面无标题欢迎态。
- 搜索框在常用窗口尺寸下可容纳较长中文关键词和拼音输入。
- 单击结果不会插入；双击结果和 `Enter` 对同一选中结果执行一次安全插入/复制。
- `Esc` 可关闭 Launcher；关闭后原应用焦点和贴边库状态保持不变。
- 目标失效或能力未验证时，界面明确提示并阻止自动发送。
- 管理页、贴边库和 Launcher 的职责不重复，不出现第二套完整编辑器。
- 旧话术缺少颜色字段时迁移为 `default`，颜色键在 Core、SQLite、IPC 和编辑器之间保持稳定往返。

## 7. 暂不纳入本次范围

- 后台自动发送和绕过目标确认的发送链路。
- 在 Launcher 内编辑话术正文或维护分类树。
- 浏览器扩展、团队协作、AI 生成和跨平台 Launcher。
