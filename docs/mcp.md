# 本机 MCP 使用说明

在设置的“AI 连接”页勾选启用，默认地址 `http://127.0.0.1:17823/mcp`。端口被占用时会显示中文错误，可修改端口后重新启用。只支持本机 Streamable HTTP 客户端，不开放网页跨域访问。

1. 勾选允许 AI 操作的个人话术库或共享话术库，默认均未授权。
2. 如需导入素材，添加授权目录。AI 使用目录标识和目录内相对路径，不能指定任意绝对路径。
3. 点击“复制连接配置”，将 JSON 中的地址与 Authorization Bearer 令牌配置到信任的 MCP 客户端。配置中的 `type: http` 可按对应客户端要求调整；协议是 Streamable HTTP。
4. 结束使用可停用服务；令牌泄露时重置令牌并重新配置客户端。切换账号后需要重新连接。

| 工具 | 用途 |
| --- | --- |
| `list_libraries` | 列出明确授权且仍可访问的库和素材目录标识 |
| `list_categories` | 读取指定库的分类与版本 |
| `search_phrases` | 指定授权库的分页搜索，默认50条，最多100条 |
| `read_phrase` | 读取话术、修订号及素材索引 |
| `save_category` | 创建或修改话术分类 |
| `save_phrase` | 创建或修改话术，可在本次保存中导入素材 |
| `move_phrase` | 在同一库中移动话术 |
| `sort_item` | 调整同类话术或分类位置，位置从0开始 |
| `recycle_phrase` | 将话术移入回收站 |

除列库外，每次调用明确提交 `source`（`private` 或 `team`）和 `libraryId`。个人修改提交 `expectedRevision`，共享写入提交读取到的 `expectedVersion` 和 `expectedLifecycleVersion`。旧版本冲突时重新读取核对，不自动覆盖。写入响应不明确时也先读取核对，不能自动重复创建。

个人读取结果直接包含话术及 `revision`；共享读取结果包含 `phrase` 和 `version`。保存时从话术中移除读取附带的 `revision`，将版本放在调用参数中。新建使用空 `id` 或省略话术 `id`；更新使用读取返回的完整 ID。

文字块为 `{ "kind": "text", "text": "内容" }`。新素材块例如 `{ "kind": "image", "rootId": "设置中显示的目录标识", "relativePath": "图片/示例.png" }`；附件使用 `kind: file`。已有素材使用读取返回的 `existing: { segment, block }`，只引用当前话术原有内容，不能跨库借用路径。图片沿用应用解码与转换，单个素材上限128MB；个人素材保存独立副本，共享素材复用上传服务。源文件保留，失败清理本次未提交素材。

服务不提供发送、剪贴板、跨库搬移、永久删除、成员修改或账号管理工具。搜索仅覆盖勾选库当前已授权缓存，不能代表未同步的服务端内容。
