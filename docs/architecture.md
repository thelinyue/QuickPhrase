# 闪语首版架构

React 负责窗口与交互，Rust 负责验证、SQLite 事务、文件处理与 Windows 系统操作。前端只提交内容 ID、目标上下文和 Insert／Send 模式，不构造系统按键或选择聊天软件控件。

账号同步及共享库共享由独立私有仓库 [QuickPhrase-Hub](https://github.com/thelinyue/QuickPhrase-Hub) 的 Rust／Axum 服务、公开公共协议（`crates/team-model`）及桌面 Rust 连接缓存组成。Hub 本地工程为 `D:\code\QuickPhrase-hub`，`main` 维护服务端，固定 Git 提交引用公共协议，独立构建和手动发布公开镜像；默认端口7823，数据映射 `./data:/data`。部署及数据边界见 [共享库话术](team-sharing.md)、[账号与同步](private-sync.md)。现有 `groupId` 仍为二级分类，`teamId` 为共享库权限域；个人库使用独立类型，不是特殊共享库。

## 云文件（0.2.0）

云文件目录独立于共享库 `assets.team_id`；本体按不可变 UUID 保存在 Hub 的 `company-files`。文件和用户名授权能力默认关闭，无共享库用户也能查看和下载；服务管理员按用户名分别委派上传、回收、恢复，权限调整及永久删除不委派。共享库普通 File 块直接引用公司 ID，快照公司 ID 列表由服务端生成；公司、共享库和私人传输共用两个下载许可。账号隔离的云文件缓存保留合法原文件名，多库共用同一缓存和锁，下载完成后必须由用户再次触发投递。

云文件窗口参考客服宝桌面动图，默认1000×650，固定左栏及右侧管理／权限／回收／上传／下载页。各处使用系统关联图标，表格操作仅显示带提示的图标。目录默认10条分页，勾选只在当前页生效；批量操作及已选数量位于表格上方，横向滚动时保持固定。权限草稿用配置版本防覆盖，离开前确认。Rust保存任务快照，未决上传跨重启保存固定ID和受控源副本，清空仅删除已结束记录；下载历史为进程内存。上传授权版本仅在上传位变化时递增，HTTP开始和登记时复核，SSE取消旧版本上传，撤权再授权不能接收旧结果。

个人保存把实际文件复制到目标库受控目录，来源映射与话术同事务提交；可用副本在同一库复用，不跨账号共享。回收只禁止新增引用；永久删除在共享数据事务内检查活动共享库、已回收共享库及话术回收记录，并保留 ID 删除标记。共享库删除不删除云文件本体，普通 ZIP 导入生成目标库独立附件，共享数据备份包含目录状态及本体。当前跨仓验证的本机协议覆盖和正式固定依赖的衔接见[云文件设计与使用](cloud-files-proposal.md)。

## 个人同步（0.2.0）

未绑定的本机库保留。账号库按服务器和不可变 `userId` 隔离，退出登录仍保留个人库和事务队列；独立文件库、连接凭据及设备设置留在本机。首次合并保留原 ID，只有“保留两份”复制分类子树及其关联内容，映射持久化供失败重试。预览冻结素材，确认检验原库修订，不能借用普通备份导入按名称合并或重建全部 ID。

SQLite 触发器将本地修订和待同步键与正文同事务提交。每个活动个人库一个同步循环，写前固化请求 ID、内容及修订，超时先查结果；仅确认对应修订，旧响应不能覆盖新草稿。分类结构冲突保留关联草稿；已删除记录使用基线分类关系暂停关联上传，无关分类继续同步。删除标记不自动过期。编辑和投递按库身份、内容 ID、本地修订核验，投递开始后固定内容与素材。

云端配置和本机生效配置分开保存：外观、搜索自动应用；发送、点击及快捷键需要确认，系统占用不反写清空云端且不阻塞正文。素材最多两个任务，私人与共享库共用下载许可；流式临时落盘，最终核验账号、会话、库身份及恢复世代，缺素材禁止整条投递。

服务端私人提交先锁认证库，再锁个人库，重新核验会话并保持至提交结束；素材网络传输不持数据库锁。共享数据备份排除个人库及会话，个人备份核验全部引用素材。全目录运维备份停服执行；恢复工具通过进程锁拒绝运行中修改，按 `userId` 核对两库、清会话并更换个人同步世代。客户端先检查世代，保留旧改动并重新预览，不能直接回放旧队列。

## 内容与事务

一条话术有多个有序分段，每段含有序的文字、图片和文件块。图片位于受控素材目录，附件及文件库记录普通 Windows 绝对路径。移动保持话术 ID，追加到目标分类；复制分配新 ID 并清空快捷键。快捷键写入前统一 Ctrl／Alt／Shift／Win 的顺序和别名，完全同键通过候选共享，单组合键与顺序双键的前缀歧义仍在事务中拒绝。

SQLite 使用外键、WAL 和事务。保存话术原子更新分段与块；普通导入在预览时一次分配副本ID，正文、回收、可选配置、待同步键及批次回执同事务保存。任何无效记录都使整批回滚，仅移除本批新增素材。预览持久化实际素材，确认不再读原包或外部附件；重启与重试保留编号。ZIP版本2及旧个人包按单素材128MB、元数据32MB限制，旧ZIP和xlsx沿用展开总量限制。拒绝非法路径、重复项目、符号链接和不完整素材，图片解码沿用尺寸与内存限制。

常用短语使用独立 `common_phrases` 表，保持单行、非空和最多 16 个 Unicode 字符。初始结构直接包含该表，已有开发库通过 `CREATE TABLE IF NOT EXISTS` 补齐，原内容与备份保留。编辑只修改文字，保留排序；快速排序提交完整主键顺序，以事务拒绝重复、缺失或已失效的主键。排序窗口接收新增／删除事件更新本地草稿，取消不写库。完整备份包含短语，导入先预览数量，再随其他内容一起事务追加。

一级、二级分类允许同级重名，身份和内容关联使用独立 ID；重命名、配色和删除只作用于指定 ID。选择器和快速排序用同名序号辅助辨认，标签仍显示原名称。分类复制与移动在单个事务中匹配或迁移二级分类，再追加话术；同名匹配沿用 SQLite `NOCASE`，多个目标按 `position,rowid` 选择列表中第一组，其余同名分组保持独立。移动保留话术 ID 和快捷键；删除但保留话术先变更根分类并清空分组外键，再删除来源分类，防止级联丢失内容。新库不预建话术或文件分类，分类由用户自行创建；允许删除最后一个一级分类，重新启动不自动补建。无分类时界面引导新增一级分类，新增内容与二级分类入口禁用；保留话术删除仍必须有有效目标分类。文件分类不参与话术分类迁移。

0.1.1 的 SQLite 使用版本1的完整初始结构。新库直接包含分类 `background` 列、全部业务表和普通 `phrase_shortcuts` 索引；已有开发库按实际结构补缺失列、删除旧 `category_names` 唯一索引、替换快捷键唯一索引，并统一标记 `user_version=1`。这些操作在同一事务内完成，不重建内容表，保留主键、层级、排序及回收记录；保存、导入与回收还原允许同键多条。后续正式版本按实际数据兼容需求引入后续数据库版本。普通导入默认保留各分类的原名称和独立层级；显式合并只选择同级唯一同名项，多项匹配时独立导入并提示。旧备份缺少标签背景色、列表显示模式和分类栏高度时自动采用默认值。按分类导出排除独立常用短语和个人配置；完整备份恢复设置时，也恢复合并分类的标签颜色。

话术一级分类右键与右上角入口共用分类操作定义，第二项“新增二级分类”绑定菜单所指向的一级分类ID，第三项“新增同级分类”创建一级分类。账号与同步、账号管理及共享库管理按身份显示在分隔线后，个人库和共享库库使用相同入口。复用客户端直角菜单，以176像素宽度、32像素行高和统一文字留白对齐参考图。弹出位置按当前视口钳制，菜单位于普通提示上层；方向键跳过禁用项，Esc或外部点击关闭。二级分类继续使用原生菜单，文件分类使用独立的四项客户端菜单。话术空白菜单新增话术／二级分类，绑定当前一级分类ID；文件空白菜单仍为刷新。一级分类的保留删除在底部应用菜单保留，二级保留删除仍在其右键菜单。

一级分类背景色菜单只负责打开“界面设置”并传递分类ID，实际配色统一在设置页完成。已有设置窗口通过定向 `settings-navigation` 事件更新页面和分类，避免重复创建窗口或沿用上次选择；同名分类仍按ID区分。区域高度和显示模式属于客户端设置，不改变话术内容。

设置通过带默认值的Serde字段兼容旧库及备份。主题与字体同步所有WebView；分类和话术的独立颜色优先于全局默认颜色，旧默认橙色在渲染时按全局默认色展示，不改写已有话术。主窗口的可调整属性由Rust实际设置，失败回退原配置；不记住吸附时仅在启动打开库时关闭左右吸附，当前会话仍可开启。高度、主题、颜色、点击模式和底部行数均由Rust验证，错误配置不会写入。常用设置默认继续选中／插入，只有用户主动设置才启用双击或单击发送；短语单击启用操作后忽略双击的第二次点击及双击事件。

连续正文使用每段一个 `contentEditable`，只序列化文字、图片和附件块，不保存任意 HTML。输入时更新模型而不重建自身 DOM，保留浏览器光标、撤销和中文组词状态；工具栏与图片粘贴均先保存 Range，导入完成后在原分段和选区插入。粘贴读取事件中的图片文件，Rust通过临时目录复用图片导入，沿用128MB、16384像素和解码内存限制，转为本地PNG并生成缩略图；失败撤销本批素材和缩略图，临时目录自动释放。每条最多9张图片，导入期间阻止重复导入和话术保存。图片以行内预览显示，可整体删除；列表和搜索通过有序块中的图片类型切换图标。WebView2 有时实际插入附件后返回 false，备用 Range 插入仅在 DOM 未改变时执行，避免重复附件。

编辑器标题色板使用居中的SVG勾，固定尺寸和笔画，不依赖字体基线；深灰色块用白色勾，其余色块用深色勾。各标题栏与快捷键、回收确认弹窗共用现有软件图标。点击话术行以外的空白或短语区域会取消话术选中；短语栏点击空白、栏外或焦点移出短语按钮时取消选中，恢复普通背景，悬停反馈仍由当前鼠标位置决定。

回收站使用 `recycle_bin` 表保存分类与话术快照，删除内容和写入快照在同一事务完成。恢复先补齐分类，再按原位置写入有序内容，最后移除回收记录；不按名称合并、不覆盖活动话术。分类主键仍存在且层级一致时保留其当前名称和颜色；二级分类已移至另一根分类时重建原位置，并在同一事务更新其余回收记录的分组引用，逐条恢复不会反复创建共享库。快捷键冲突或任何写入失败均回滚；用户可明确跳过恢复快捷键。只有话术与话术分类被回收，保留话术删除及分类移动不产生回收记录。

缓存页的批量删除提交确认时固定的完整主键列表。后端仅接受我的话术与常用短语两种范围，以当前主键集合拒绝重复、遗漏、失效及跨窗口增删后的旧确认。我的话术默认逐条复用回收快照，整批快照和删除在一个事务中写入，任意失败全部回滚；还原时先补齐本批全部分类，再按原位置恢复全部话术，避免倒序选择导致排序位置被反复推后。常用短语明确永久删除。操作保留分类、素材图片、文件关联、设置及已有回收记录。确认表单以同步锁防止重复提交，执行期间禁用取消及 Escape。缓存页维护当前个人库与本机缓存；账号同步和共享库管理使用各自入口。

全库 ZIP 备份可选包含 `recycleBin`，旧备份默认空；回收记录的图片纳入受控导入和路径重映射，导入后仍为非活动内容。JSON 快照未落入分类表，不能仅依靠外键验证，因此导入另检查两级层级、颜色及话术归属，错误使活动内容、设置、回收记录和本次图片整体回滚。永久删除与清空只删除回收记录，不删除素材或外部文件。

文件菜单绑定打开时的主键集合，搜索右键使用单项；Ctrl／Shift／Ctrl+A 在当前分类内选择。显示名、移动、排序与移除只更新数据库，失效路径仍可管理。批量复制先验证所有源文件，再构造 Unicode CF_HDROP 的双零结尾文件列表，验证失败不会清空系统剪贴板。打开与定位使用 ShellExecuteW，不拼接命令解释器脚本。文件与文件分类菜单使用客户端直角菜单，长菜单在视口内滚动，并显示在普通提示上方。

## 通用发送

进入闪语前最后聚焦的外部窗口与子输入窗口构成目标上下文。操作开始冻结该上下文，核对窗口、进程及输入焦点，再恢复目标。剪贴板文字使用 CF_UNICODETEXT，图片使用 CF_DIBV5／CF_DIB，文件使用 CF_HDROP。

投递不读取、备份或恢复原剪贴板，原有格式无法读取也不会阻止操作。开始时只记录序号，写入前在剪贴板锁内核对变化；写入后在释放锁后确认所有者及最终序号，以兼容 Windows 自动添加合成格式。粘贴及发送按键提交前继续检查序号，用户复制新内容时立即停止。完成或中断后不清理剪贴板，保留最后写入的内容块或用户新复制的内容；系统写入失败不恢复旧内容，也不继续粘贴或自动重试。

Insert 按顺序粘贴，在分段之间添加换行，不发送。Send 每段粘贴完后提交配置的发送键，再等待分段间隔。目标失效、输入焦点变化、用户新按键／新复制、取消或系统提交失败都会停止；报告包含已执行的段数、内容块数及中文错误，不自动重发。

前端发送按钮固定占据左侧列，按所在行 ID 发送，阻止冒泡并忽略双击第二次点击。Rust 原子锁承担所有入口的防重入；前端忙碌态提供禁用和停止反馈。程序不主动清空目标草稿，也不证明第三方软件已收取或通过网络送达。

快捷键保存仍使用规范字符串，顺序双键用两个普通键，兼容已有修饰组合。单键和同首键双键存在前缀冲突，相同首键但不同第二键可共存，完全同键保留全部候选。低级键盘钩子暂存首键一秒；完成后吞掉触发键，错误第二键、超时或修饰键松开时按顺序回放首键与当前键。目标窗口／输入控件变化时取消，不向新输入区回放；正式注入按键不会再次触发。仅设置了 `SHANYU_TEST_DATA_DIR` 的 Debug 实例接受 `dwExtraInfo=0x53595141` 的验收按键，发送与回放使用内部标记 `0x53594E41`，监听忽略这些内部事件。主窗口和底栏的 WebView2 组合键回调共用原生匹配器，使搜索框中的序号组合键也能匹配。界面 Enter 提交将焦点移回目标时，原生层持续消费按住的 Enter 至松开，避免长按误发已有草稿。

主窗口通过 `sync_sequence_map` 同步前十个实际绘制槽位，文件为 null，并同步搜索加载／组合输入暂停状态；只有主窗口可写，隐藏后保留最后快照。`sequenceHotkeys` 与 `sequenceDirectSend` 默认为 false，`sequenceBindings` 默认为 Ctrl+1—9、Ctrl+0，空字符串表示单项关闭；旧设置与备份缺字段时由 Serde 填默认值。修改绑定或启用时检查序号、Alt 导航与话术快捷键冲突，失败保留原配置。搜索只启用序号绑定，编辑与模态输入暂停业务绑定；原生 `ManagementWindows` 分别记录设置、用户名和共享库窗口句柄，全部关闭后恢复已保存配置，打开任一窗口也取消旧候选。

原生层按一级分类、无分组话术、二级分类及话术顺序缓存活动库，每种规范快捷键只监听一次。完整匹配始终打开候选，保存话术 ID、选中位置、触发窗口／控件及目标上下文。`get_shortcut_candidates`、`select_shortcut_candidate`、`submit_shortcut_candidate`、`cancel_shortcut_candidates` 与定向 `shortcut-candidates` 事件同步界面；原生键盘监听处理上下、数字、空格、Enter、Esc，选择不限时。候选窗口无激活且跳过任务栏，以输入光标为定位依据，缺失时靠近目标下方，并夹在显示器工作区内。鼠标钩子及焦点核对取消外部交互；消费键保持至松开，长按或重复提交不会重发。提交重新核对当前话术快捷键与目标，随后复用 `deliver_content` 的发送锁、剪贴板、分段和中断处理。

低级鼠标钩子安装在独立消息线程，通过`MsgWaitForMultipleObjectsEx`等待并立即响应输入；50毫秒超时仅用于检查退出状态。它不与30毫秒窗口跟随轮询共用线程，避免即使直接放行的鼠标移动也被轮询休眠和窗口查询拖慢。外部点击取消候选仍使用原有状态锁和检查，退出时卸载钩子并等待监听线程结束。

话术行与搜索结果共享选中及悬停规则：选中背景为 `#FFFFCC`，鼠标悬停为 `#FFEDC5`；鼠标停在已选中行时悬停优先，移出恢复选中色。文件库仍使用独立的原有选中样式。

## 吸附与运行

主窗口是窄侧栏，Tauri配置统一关闭最大化，避免标题栏／底栏双击将WebView放大后又被跟随定位缩小外框。单击拖动、自由调整及最小化保留，独立编辑／排序窗口沿用各自的窗口能力。原生跟随遇到已最大化的主窗口时，先用异步、不激活的显示命令还原，下一轮再读取正常尺寸并记录吸附前矩形；不能直接用定位命令缩小最大化窗口，也不能将其宽度记为用户侧栏宽度。

吸附按 `WXWork.exe` 和精确原生窗口类识别：主窗口 `WeWorkWindow`、普通独立聊天窗口 `WwStandaloneConversationWnd`、客户独立聊天窗口 `CRMCustomerStandaloneWindow`。主窗口和客户独立聊天类型已在本机企业微信核实，普通独立聊天类型来自客服宝的识别表。企业微信5.0.10未通过UIA或MSAA暴露输入框；参照实机客服宝的窗口级规则，主窗口内的通讯录、搜索及无消息输入框页面仍吸附，登录、独立图片／视频、搜索结果及未知窗口类型不吸附。不读取窗口标题、输入正文或消息列表，不依赖COM/UIA，也不要求输入框焦点。独立线程每250毫秒复核窗口类型、进程ID、可见性、最小化状态与有效尺寸；切换外部窗口立即作废旧结果，A→B→A不能接受旧查询，结论750毫秒未更新即失效。前台匹配使用目标句柄，不以同进程关系继承后台目标。隔离Debug客户端仅额外接受专用 `ShanyuDockHost.exe` 进程；WinForms包装类去掉框架前后缀后使用同一份精确名单，正式进程不能借用此例外。发送目标记录和通用发送服务继续独立于吸附识别。

后台定位、独立模式恢复和边框刷新使用SWP_ASYNCWINDOWPOS异步提交窗口消息，避免界面线程等待设置响应时与跟随线程的同步定位相互等待；跟随仍保留SWP_NOACTIVATE，不替换用户正在使用的输入焦点。点击侧栏或底栏可以正常获得焦点，目标关系继续保留。

企业微信的进程识别只出现在吸附服务中。后台显示状态明确区分自动跟随、手动独立显示和手动隐藏：普通／开机启动进入自动跟随；目标激活后无激活地显示，目标最小化／关闭或切换其他程序时隐藏。闪语主窗口、编辑和设置窗口在前台时仅延续正在使用的目标，不重新吸附后台的旧目标。激活切换期间前台句柄可短暂为空，此时保留已建立且仍可见、未最小化的目标关系，避免点击侧栏时反向隐藏侧栏和底栏；实际切换其他程序后仍隐藏。无目标时托盘／快捷键可独立唤起，目标重新激活后恢复跟随；手动隐藏只能由明确唤起解除。关闭吸附恢复独立位置、尺寸与用户置顶设置，目标关闭不改写吸附开关。

吸附位置使用物理坐标，逻辑尺寸按闪语各面板自身DPI换算，与各自WebView的界面缩放一致。目标应用的窗口DPI可能固定，且目标与面板可分处不同显示器，因此不能借用目标DPI决定面板尺寸；无效DPI回退96。跨屏后由现有30毫秒跟随循环重新读取面板DPI和边框并校正几何，不新增显示器查询或DPI消息拦截。跟随位置优先使用DWM可见边框，并根据闪语自身外框与可见边框的差值换算SetWindowPos坐标，避免右侧间隙和底部横条两端缩短；边框动态读取，不写死DPI像素值。用户外框宽度以DIP保存，按侧栏自身DPI换算，只有GUI_INMOVESIZE表示真实用户调整大小时才更新；定位、DPI缩放和屏幕裁切不反写宽度。侧栏始终完整展开，旧autoHide、hideDelay字段只兼容读取，不触发收窄。侧栏固定贴在目标指定的左右外侧，上下与目标完整对齐，宽度保留用户设置；不按工作区回挪、不自动换边或裁小宽高，目标纵向移出工作区也继续跟随。超出屏幕或被任务栏挡住的部分允许不可见，但不会移入目标内容。吸附期间侧栏和底栏的置顶层级只跟随目标，独立窗口的置顶设置在退出吸附后恢复。同层顺序固定为目标、侧栏、底栏；仅显示底栏时紧邻目标后方。直接使用目标或已跟随的侧栏作为SetWindowPos锚点，避免任务栏等其他层窗口隐式提升普通吸附面板；目标先于面板显示，30毫秒跟随刷新短暂滞后时也不会遮住目标内容。前台激活及仅改变层内顺序的点击都会重新同步，所有跟随操作保留SWP_NOACTIVATE。增加其他软件只扩展识别模块，不修改发送逻辑。

底部搜索／常用短语面板独立控制两项内容。使用相同库事件更新数据，左右端点始终与目标窗口对齐，目标超出屏幕时仍保留完整宽度；顶部始终贴在目标可见底边的下方，保留内容高度，不因空间不足移进目标内部。显示与跟随使用 `SWP_NOACTIVATE` 保留输入焦点；点击吸附侧栏或目标只改变层内顺序时，也保持目标、侧栏、底栏的同层顺序，不改变正在使用的目标关系。两处面板可见矩形不相交，连续点击侧栏和底栏时短语仍可见；底栏不固定全局置顶。后台启动也可自动跟随；切换其他程序、最小化、关闭目标或手动隐藏时隐藏。短语按宽度换行，可限制1—3行或自适应，超出区域滚动；ResizeObserver上报28—420 DIP内容高度，原生跟随按底栏自身DPI转换物理像素。“隐藏短语”保存dockCommon=false，移除包括菜单和新增按钮的整条短语区域；没有底部搜索时原生窗口一起隐藏，重新显示使用界面设置中的底部短语开关。保存失败保留区域并显示中文错误，快速连点不重复提交。搜索共用实际搜索服务与PhraseRow，插入／发送仍交给同一个通用发送服务，窄面板使用原生菜单避免菜单被窗口裁切。

依赖升级到ZIP9后先显式处理文件名解码失败，再执行路径、符号链接、重复项及解压大小检查。SQLite升级后把删除时间戳显式转换为有符号64位，超范围报中文错误并回滚导入；不截断已有数据，不改变备份格式版本。

主窗口和横条的原生句柄在启动主线程读取并缓存。跟随线程直接使用 Win32 句柄，避免同步 Tauri getter 与设置保存的后台回执形成循环等待。只有快捷键配置变化才重注册热键；启动时某个热键被其他软件占用，不会阻止置顶、吸附、搜索或短语面板开关。

应用使用单实例与托盘。主窗口启动配置visible=false、focus=false、skipTaskbar=true，底栏和预览同样跳过任务栏；Win32扩展样式清除WS_EX_APPWINDOW、设置WS_EX_TOOLWINDOW，避免原生显示或Tauri属性刷新重新生成任务栏入口。设置／编辑窗口保留普通任务栏入口。重复运行不主动唤起。默认关闭／最小化隐藏到托盘；设置可以改变最小化行为，快捷键明确唤起时先恢复最小化窗口。后台窗口跟随与发送分别执行，分段等待不阻塞跟随；图片、备份和缓存命令在 Tauri 工作线程处理。

稳定安装 AppId 为 `{E9DBDCE4-4E86-4F88-A845-7E91B5D7726C}`，数据标识为 `com.quickphrase.desktop`。Inno 安装器只写应用目录和入口；用户数据库、图片及设置在其外。WebView2 缺失时运行官方引导程序，失败停止并提示退出码。

仅 Debug 构建允许 `SHANYU_TEST_DATA_DIR` 隔离验收数据，此环境使用 `.qa` 单实例标识，也不修改真实开机启动项。Release 始终使用正常用户数据目录和产品单实例标识。

自动 CI 复用前端、Rust 单测和 Debug 构建。`check-release.ps1` 统一校验源码版本与手动发布条件；安装器构建使用临时 Tauri 配置传入 RC 版本，设置页通过 Tauri 读取实际版本。`package-release.ps1` 只打包明确指定的当前程序、安装器和许可政策文件，并沿用已有 SHA256 清单与来源 manifest。候选仅上传 Actions artifact，正式发布保留已有标签、人工验收确认和未签名声明；构建或打包不会发布、安装程序或改写用户数据。
