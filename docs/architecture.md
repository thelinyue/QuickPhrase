# 闪语首版架构

React 负责窗口与交互，Rust 负责验证、SQLite 事务、文件处理与 Windows 系统操作。前端只提交内容 ID、目标上下文和 Insert／Send 模式，不构造系统按键或选择聊天软件控件。

统一诊断由 `diagnostics.rs` 管理：固定枚举与数值事件经有界非阻塞队列送到后台线程，日常摘要与限时详细记录分开限额保存；键盘钩子复用已有绑定和焦点快照，不增加进程/输入法查询，不做磁盘 IO。设置页只负责选择问题、开始、停止和导出，原生单调时钟独立执行五分钟截止。导出单独的白名单 ZIP，不混入原始日志、数据库或正文，不自动上传；具体范围和不能证明的结果见 [诊断说明](diagnostics.md)。

搜索记录由 `SearchHistory` 的共用组件及钩子读取，Rust `search_history` 模块在当前个人库 `sync_meta.searchHistory` 元数据项保存最多10个关键词的JSON数组，无需新增表或同步协议。记录写事务先取得写锁，再读取、去重、置顶及裁剪；操作携带个人库身份复用现有校验，写入后仅发送 `search-history-changed` 刷新两处窗口，不唤醒个人同步。关键词在用户触发搜索结果投递时固定，只有 `submitted` 回执才记录；清空搜索不清空历史。记录读取按库身份和请求顺序丢弃旧响应，切号立即隐藏旧快照；普通内容备份不包含这些元数据。

主窗口的历史／结果共用内容区绝对定位，不改变列表、常用短语与输入框的布局；遮罩仅覆盖来源、分类、列表和常用短语，原生窗口失焦也关闭浮层。空记录保留提示和禁用的清空按钮，底栏展示及直接清空不变。`SearchHistoryConfirm`／`search_history_confirm` 使用独立384×256 DIP窗口，显示后按真实客户区与显示器工作区校正尺寸。原生会话固定库身份，来源隐藏／切库轮询失效、提交锁与现有清空事务共同阻止错库和重复操作；只有应用仍在前台才恢复主窗口搜索焦点。确认窗口纳入管理窗口的快捷键与贴边收起暂停集合，不复用删除或预览窗口。原生失焦按窗口身份清除输入标记，`set_shortcut_input`同时校验真实前台窗口，防止WebView2残留DOM焦点持续阻止贴边收起。

`search_match::SearchQuery` 在每次 scoped 搜索入口统一预处理关键词，所有授权来源共用原文优先、按需全拼／首字母匹配。查询在工作线程运行，保留现有读取字段、权限过滤、顺序和返回结构；非汉字及字段分隔符保留，不增加数据库索引、迁移或缓存。拼音采用现有依赖的默认读音，原文高亮机制不变。

搜索框为空且用户已进入搜索区域时显示记录，默认及启动时隐藏；点击搜索框、键盘聚焦或搜索快捷键可展开，历史内部操作保持展开，点击区域外、焦点离开、Esc或窗口失焦时收起。主窗口不再启动自动聚焦搜索，后台记录刷新不激活历史，窗口恢复后重复点击已保留DOM焦点的输入框仍可展开。点击关键词或输入后切换到结果。主窗口搜索结果与历史提示互斥显示，保留常用短语底层布局和显示设置，浮层直接指向搜索框；遮罩覆盖来源、分类、列表及常用短语，保留标题栏、搜索框和底栏操作。两处结果通过SearchResults共用“话术／文件”分组，先话术后文件且空组不显示；标题不参与编号和键盘选择，搜索结果行末不展示来源／分类标签，保留未缓存、文件失效等状态；操作仍使用结果自身的来源身份。主窗口浮层最高420 DIP并受可用高度限制，底部结果仍最多228 DIP；组标题与结果共用滚动容器。清空或关闭结果后恢复历史提示。

账号同步与话术共享由独立私有仓库 [QuickPhrase-Hub](https://github.com/thelinyue/QuickPhrase-Hub) 的 Rust／Axum 服务、公开公共协议（`crates/team-model`）及桌面 Rust 连接缓存组成。闪云本地工程为 `D:\code\QuickPhrase-hub`，`main` 维护服务端，固定 Git 提交引用公共协议，独立构建和手动发布公开镜像；默认端口7823，数据映射 `./data:/data`。部署及数据边界见 [共享话术](team-sharing.md)、[账号](private-sync.md)。现有 `groupId` 仍为二级分类，`teamId` 为共享话术权限域；个人库使用独立类型，与共享话术的权限域分别管理。

## 成员话术只读投影

成员共享独立于共享库角色，闪云通过会话确定本人共享设置，以 `phrase_shares.owner` 唯一约束维护全部／指定范围，以 `phrase_subscriptions.recipient` 主键保证每账号一个来源。全部模式每次从来源个人库解析有效根分类，指定模式只扩展所选根内内容。使用名单仅按当前来源账号查询，计数由该名单得出，不依赖设备数、会话或在线状态。旧逐人表在事务内迁移失效，不推导公开范围；关闭、停用与恢复均清空对应关系并递增版本。

客户端 `member_client.rs` 将过滤快照、目录及本人使用名单保存在账号分区的 `member` 目录；快照必须携带接收账号 ID，旧无绑定缓存不可用。名单连接故障可读取缓存并标为离线；明确拒绝删除名单缓存，并持久化空内容快照。成员分类整类只读，个人写入入口拒绝成员主键，不进入本人 SQLite、同步、备份或回收。使用者可以为成员话术单独设置本机快捷键，原正文保持只读。账号、共享版本、使用关系版本、来源世代和修订共同阻止旧任务落盘或发送。开放目录变更广播通用刷新通知；使用关系变化通知本人和旧／新来源，正文变更只通知实际使用者。

成员快捷键保存在客户端 `teams/member-shortcuts.json`，使用规范服务地址、使用者账号、分享 ID、来源库世代与话术 ID 定位；不保存正文，不写入闪云，不随个人库同步或备份。原子替换文件后再更新内存，退出登录清理授权缓存但保留本机偏好。普通正文修订保留绑定，停止使用、撤权或来源库重建不会沿用失效内容。保存入口核对窗口记录的账号 epoch 和完整授权引用；允许同键候选，拒绝导航／序号及双键前缀冲突。远端本人设置产生冲突时，活动绑定优先保留本人配置，成员偏好暂不生效。候选快照同时保存话术与账号 epoch，提交重新核验绑定、账号、分享范围、素材就绪和目标，复用既有投递链路。

## 云文件（0.2.0）

云文件目录独立于共享话术 `assets.team_id`；本体按不可变 UUID 保存在闪云的 `company-files`。文件和用户名授权能力默认关闭，无共享话术用户也能查看和下载；服务管理员按用户名分别委派上传、回收、恢复，权限调整及永久删除不委派。共享话术普通 File 块直接引用公司 ID，快照公司 ID 列表由服务端生成；公司、共享话术和私人传输共用两个下载许可。账号隔离的云文件缓存保留合法原文件名，多库共用同一缓存和锁，下载完成后必须由用户再次触发投递。

云文件窗口参考客服宝桌面动图，默认1000×650，固定左栏及右侧管理／权限／回收／上传／下载页。各处使用系统关联图标，表格操作仅显示带提示的图标。目录默认10条分页，勾选只在当前页生效；批量操作及已选数量位于表格上方，横向滚动时保持固定。权限草稿用配置版本防覆盖，离开前确认。Rust保存任务快照，未决上传跨重启保存固定ID和受控源副本，清空仅删除已结束记录；下载历史为进程内存。上传授权版本仅在上传位变化时递增，HTTP开始和登记时复核，SSE取消旧版本上传，撤权再授权不能接收旧结果。

多选与Tauri原生拖拽统一调用本地`enqueue_company_uploads(sessionEpoch, paths)`，逐项返回固定任务ID和初始记录；前端只提交、订阅及展示。Rust按同批源路径去重，同名不同路径各自执行，目录和不满足1字节至128MB的项单独失败。等待、准备、传输、完成及错误均进入既有带修订的传输快照。准备副本与上传共用两个执行名额，“继续原任务”使用相同许可，关闭窗口不影响后台任务。副本在后台逐块复制，沿用Windows源文件只读共享保护，不持账号锁进行复制；提交任务元数据前短锁复核账号、上传授权版本和取消状态。准备失败清理本项临时副本；进程退出留下的未提交副本在下次启动清理，固化待核对任务保留。切号、撤权、授权版本变化、离线或退出停止旧队列；重启不恢复尚未执行项，也不自动上传。回执丢失仅核对固定ID，明确继续且原ID不存在时才重传原副本，闪云接口保持兼容。

个人保存把实际文件复制到目标库受控目录，来源映射与话术同事务提交；可用副本在同一库复用，不跨账号共享。回收只禁止新增引用；永久删除在共享数据事务内检查活动共享话术、已回收共享话术及话术回收记录，并保留 ID 删除标记。共享话术删除不删除云文件本体，普通 ZIP 导入生成目标库独立附件，共享数据备份包含目录状态及本体。当前跨仓验证的本机协议覆盖和正式固定依赖的衔接见[云文件设计与使用](cloud-files-proposal.md)。

## 个人同步（0.2.0）

个人同步成功时间保存在账号库 `sync_meta.lastSuccessfulSyncAt`，只有实际完成服务端核对并清空待提交、未确认请求与冲突后更新；旧账号响应不得更新时间。共享话术通过每个缓存库的 `sync-time.json` 持久化核对时间，按已有版本和生命周期校验，注销及撤权随缓存清理。二者使用客户端 UTC Unix 毫秒时间戳，前端转换系统时区，不增加闪云协议。

界面统一呈现“个人话术”，暂停、断网和退出不切库。未绑定的本机库保留，历史内容通过导入页预览找回。首次登录登记账号与原本机内容的引用但不上传；未开启同步就换号时，新账号仍使用独立空库，回到首个账号可继续原内容。账号库按服务器和不可变 `userId` 隔离，退出登录仍保留个人库和事务队列；独立文件库、连接凭据及设备设置留在本机。首次合并保留原 ID，只有“保留两份”复制分类子树及其关联内容，映射持久化供失败重试。预览冻结素材，确认检验原库修订，不能借用普通备份导入按名称合并或重建全部 ID。

SQLite 触发器将本地修订和待同步键与正文同事务提交。每个活动个人库一个同步循环，写前固化请求 ID、内容及修订，超时先查结果；仅确认对应修订，旧响应不能覆盖新草稿。分类结构冲突保留关联草稿；已删除记录使用基线分类关系暂停关联上传，无关分类继续同步。删除标记不自动过期。编辑和投递按库身份、内容 ID、本地修订核验，投递开始后固定内容与素材。

云端配置和本机生效配置分开保存：外观、搜索自动应用；发送、点击及快捷键需要确认，系统占用不反写清空云端且不阻塞正文。素材最多两个任务，私人与共享话术共用下载许可；流式临时落盘，最终核验账号、会话、库身份及恢复世代，缺素材禁止整条投递。

服务端私人提交先锁认证库，再锁个人库，重新核验会话并保持至提交结束；素材网络传输不持数据库锁。共享数据备份排除个人库及会话，个人备份核验全部引用素材。全目录运维备份停服执行；恢复工具通过进程锁拒绝运行中修改，按 `userId` 核对两库、清会话并更换个人同步世代。客户端先检查世代，保留旧改动并重新预览，不能直接回放旧队列。

## 内容与事务

一条话术有多个有序分段，每段含有序的文字、图片和文件块。图片位于受控素材目录，附件及文件库记录普通 Windows 绝对路径。移动保持话术 ID，追加到目标分类；复制分配新 ID 并清空快捷键。快捷键写入前统一 Ctrl／Alt／Shift／Win 的顺序和别名，完全同键通过候选共享，单组合键与顺序双键的前缀歧义仍在事务中拒绝。

SQLite 使用外键、WAL 和事务。保存话术原子更新分段与块；普通导入在预览时一次分配副本ID，正文、回收、可选配置、待同步键及批次回执同事务保存。任何无效记录都使整批回滚，仅移除本批新增素材。预览持久化实际素材，确认不再读原包或外部附件；重启与重试保留编号。ZIP版本2及旧个人包按单素材128MB、元数据32MB限制，旧ZIP和xlsx沿用展开总量限制。拒绝非法路径、重复项目、符号链接和不完整素材，图片解码沿用尺寸与内存限制。

常用短语使用独立 `common_phrases` 表，保持单行、非空和最多 16 个 Unicode 字符。初始结构直接包含该表，已有开发库通过 `CREATE TABLE IF NOT EXISTS` 补齐，原内容与备份保留。编辑只修改文字，保留排序；快速排序提交完整主键顺序，以事务拒绝重复、缺失或已失效的主键。排序窗口接收新增／删除事件更新本地草稿，取消不写库。完整备份包含短语，导入先预览数量，再随其他内容一起事务追加。

一级、二级分类允许同级重名，身份和内容关联使用独立 ID；重命名、配色和删除只作用于指定 ID。选择器和快速排序用同名序号辅助辨认，标签仍显示原名称。分类复制与移动在单个事务中匹配或迁移二级分类，再追加话术；同名匹配沿用 SQLite `NOCASE`，多个目标按 `position,rowid` 选择列表中第一组，其余同名分组保持独立。移动保留话术 ID 和快捷键；删除但保留话术先变更根分类并清空分组外键，再删除来源分类，防止级联丢失内容。新库不预建话术或文件分类，分类由用户自行创建；允许删除最后一个一级分类，重新启动不自动补建。无分类时界面引导新增一级分类，新增内容与二级分类入口禁用；保留话术删除仍必须有有效目标分类。文件分类不参与话术分类迁移。

0.1.1 的 SQLite 使用版本1的完整初始结构。新库直接包含分类 `background` 列、全部业务表和普通 `phrase_shortcuts` 索引；已有开发库按实际结构补缺失列、删除旧 `category_names` 唯一索引、替换快捷键唯一索引，并统一标记 `user_version=1`。这些操作在同一事务内完成，不重建内容表，保留主键、层级、排序及回收记录；保存、导入与回收还原允许同键多条。后续正式版本按实际数据兼容需求引入后续数据库版本。普通导入默认保留各分类的原名称和独立层级；显式合并只选择同级唯一同名项，多项匹配时独立导入并提示。旧备份缺少标签背景色、列表显示模式和分类栏高度时自动采用默认值。按分类导出排除独立常用短语和个人配置；完整备份恢复设置时，也恢复合并分类的标签颜色。

话术一级分类右键与右上角入口共用分类操作定义，第二项“新增二级分类”绑定菜单所指向的一级分类ID，第三项“新增同级分类”创建一级分类。账号、账号管理及共享话术管理按身份显示在分隔线后，个人库和共享话术库使用相同入口。复用客户端直角菜单，以176像素宽度、32像素行高和统一文字留白对齐参考图。弹出位置按当前视口钳制，菜单位于普通提示上层；方向键跳过禁用项，Esc或外部点击关闭。二级分类继续使用原生菜单，文件分类使用独立的四项客户端菜单。话术空白菜单新增话术／二级分类，绑定当前一级分类ID；文件空白菜单仍为刷新。一级分类的保留删除在底部应用菜单保留，二级保留删除仍在其右键菜单。

一级分类背景色菜单只负责打开“界面设置”并传递分类ID，实际配色统一在设置页完成。已有设置窗口通过定向 `settings-navigation` 事件更新页面和分类，避免重复创建窗口或沿用上次选择；同名分类仍按ID区分。区域高度和显示模式属于客户端设置，不改变话术内容。

设置通过带默认值的Serde字段兼容旧库及备份。主题与字体同步所有WebView；分类和话术的独立颜色优先于全局默认颜色，旧默认橙色在渲染时按全局默认色展示，不改写已有话术。主窗口的可调整属性由Rust实际设置，失败回退原配置；不记住吸附时仅在启动打开库时关闭左右吸附，当前会话仍可开启。高度、主题、颜色、点击模式和底部行数均由Rust验证，错误配置不会写入。常用设置默认继续选中／插入，只有用户主动设置才启用双击或单击发送；短语单击启用操作后忽略双击的第二次点击及双击事件。

连续正文使用每段一个 `contentEditable`，只序列化文字、图片和附件块，不保存任意 HTML。输入时更新模型而不重建自身 DOM，保留浏览器光标、撤销和中文组词状态；工具栏与图片粘贴均先保存 Range，导入完成后在原分段和选区插入。粘贴读取事件中的图片文件，Rust通过临时目录复用图片导入，沿用128MB、16384像素和解码内存限制，转为本地PNG并生成缩略图；失败撤销本批素材和缩略图，临时目录自动释放。每条最多9张图片，导入期间阻止重复导入和话术保存。图片以行内预览显示，可整体删除；列表和搜索通过有序块中的图片类型切换图标。WebView2 有时实际插入附件后返回 false，备用 Range 插入仅在 DOM 未改变时执行，避免重复附件。

编辑器标题色板使用居中的SVG勾，固定尺寸和笔画，不依赖字体基线；深灰色块用白色勾，其余色块用深色勾。各标题栏与快捷键、回收确认弹窗共用现有软件图标。点击话术行以外的空白或短语区域会取消话术选中；短语栏点击空白、栏外或焦点移出短语按钮时取消选中，恢复普通背景，悬停反馈仍由当前鼠标位置决定。

回收站使用 `recycle_bin` 表保存分类与话术快照，删除内容和写入快照在同一事务完成。恢复先补齐分类，再按原位置写入有序内容，最后移除回收记录；不按名称合并、不覆盖活动话术。分类主键仍存在且层级一致时保留其当前名称和颜色；二级分类已移至另一根分类时重建原位置，并在同一事务更新其余回收记录的分组引用，逐条恢复不会反复创建二级分类。快捷键冲突或任何写入失败均回滚；用户可明确跳过恢复快捷键。只有话术与话术分类被回收，保留话术删除及分类移动不产生回收记录。

缓存页的批量删除提交确认时固定的完整主键列表。后端仅接受个人话术与常用短语两种范围，以当前主键集合拒绝重复、遗漏、失效及跨窗口增删后的旧确认。个人话术默认逐条复用回收快照，整批快照和删除在一个事务中写入，任意失败全部回滚；还原时先补齐本批全部分类，再按原位置恢复全部话术，避免倒序选择导致排序位置被反复推后。常用短语明确永久删除。操作保留分类、素材图片、文件关联、设置及已有回收记录。确认表单以同步锁防止重复提交，执行期间禁用取消及 Escape。缓存页维护当前个人库与本机缓存；账号同步和共享话术管理使用各自入口。

全库 ZIP 备份可选包含 `recycleBin`，旧备份默认空；回收记录的图片纳入受控导入和路径重映射，导入后仍为非活动内容。JSON 快照未落入分类表，不能仅依靠外键验证，因此导入另检查两级层级、颜色及话术归属，错误使活动内容、设置、回收记录和本次图片整体回滚。永久删除与清空只删除回收记录，不删除素材或外部文件。

文件菜单绑定打开时的主键集合，搜索右键使用单项；Ctrl／Shift／Ctrl+A 在当前分类内选择。显示名、移动、排序与移除只更新数据库，失效路径仍可管理。批量复制先验证所有源文件，再构造 Unicode CF_HDROP 的双零结尾文件列表，验证失败不会清空系统剪贴板。打开与定位使用 ShellExecuteW，不拼接命令解释器脚本。文件与文件分类菜单使用客户端直角菜单，长菜单在视口内滚动，并显示在普通提示上方。

## 通用发送

进入闪语前最后聚焦的外部窗口与子输入窗口构成目标上下文。操作开始冻结该上下文，核对窗口、进程及输入焦点，再恢复目标。剪贴板文字使用 CF_UNICODETEXT，图片使用 CF_DIBV5／CF_DIB，文件使用 CF_HDROP。

投递不读取、备份或恢复原剪贴板，原有格式无法读取也不会阻止操作。开始时只记录序号；每个内容块打开剪贴板失败时按25毫秒间隔等待最多3秒，期间和取得锁后核对取消、目标与序号，释放后继续本次尚未执行的操作。超时仅尝试识别当时打开剪贴板的程序，无法获取时明确说明；内容所有者不代表当前占用者。写入后在释放锁后确认所有者及最终序号，以兼容 Windows 自动添加合成格式。粘贴及发送按键提交前继续检查序号，用户复制新内容时立即停止。完成或中断后不清理剪贴板，保留最后写入的内容块或用户新复制的内容；系统写入失败不恢复旧内容，也不继续粘贴或自动重试。

Insert 按顺序粘贴，在分段之间添加换行，不发送。Send 每段粘贴完后提交配置的发送键，再等待分段间隔。目标失效、输入焦点变化、用户新按键／新复制、取消或系统提交失败都会停止；报告包含已执行的段数、内容块数及中文错误，不自动重发。

窗口提示按成功、进度、错误和需核对的警告分层；窗口级成功提示短暂显示，错误和警告逐条确认，表单校验及任务状态留在原处。主窗口等共用紧凑悬浮提示，按实际布局判断文字是否截断并提供展开；展开后正文滚动、操作按钮保持可见，切换提示或重新展开从头阅读。中断及回执不可用的摘要优先提醒检查目标。投递实际等待剪贴板约0.5秒后发送进度事件，停止按钮绑定投递操作号，迟到的停止请求不能取消下一次操作。非成功的 `DeliveryReport` 在进程内按个人库与账号会话世代保存，不写入话术或剪贴板载荷；窗口可见性改变时重新选择可见来源、主窗口或底栏，不主动显示隐藏窗口。读取或订阅回执失败时提示先检查目标；快照按请求顺序丢弃迟到结果，确认后重新读取，订阅失败后在重新聚焦或关闭警告时重新订阅，不重发投递。尚未产生投递回执的其他错误仍沿用原有事件与提示路径。

前端发送按钮固定占据左侧列，按所在行 ID 发送，阻止冒泡并忽略双击第二次点击。Rust 原子锁承担所有入口的防重入；前端忙碌态提供禁用和停止反馈。程序不主动清空目标草稿，也不证明第三方软件已收取或通过网络送达。

快捷键保存仍使用规范字符串，顺序双键用两个普通键，兼容已有修饰组合。单键和同首键双键存在前缀冲突，相同首键但不同第二键可共存，完全同键保留全部候选。低级键盘钩子对不含 Ctrl／Alt／Win 且首键为字母或数字的双键即时放行，仅在一秒内观察匹配；包括 Shift 输入及同首键后接 F 键，失败、超时或改绑不回放。原生层记录首次透传前的系统光标、布局、实际触发事件（含长按）及共享失效标记，不经 IPC 或数据存储暴露。选中话术并取得发送锁、核验内容及授权、准备首块剪贴板载荷后，对标准 Edit 控件核对触发文字和选区，再清理一次；对已识别的企业微信自绘输入区，按实际透传的字符次数提交完整退格，再粘贴。长按次数来自原生输入记录，不固定为两次。候选取走后发生的新输入、外部点击或失焦仍使替换失效；选择时记录剪贴板序号，授权与素材准备期间的新复制也会中断。微软拼音通过目标默认 IME 窗口临时关闭组字并转为英文，此前未确认的拼音内容先上屏；临时状态覆盖退格和 Ctrl+V，待目标处理输入后，在原目标、原布局且用户未接管时恢复开关及转换模式。该路径不读取跨进程组字上下文，不以 Escape 清空组字。中文数字可能用于选字，自绘区无法核对时拒绝；非简体中文原生组字、无可靠系统光标或未知自绘输入区也拒绝替换。其他输入法尚未实测。透传输入停稳后记录系统光标，程序移动输入位置也使上下文失效，自身清理开始后停止光标比较。清理操作开始后的失败即使完成块数为零也报告中断和已执行步骤，不自动重试或回填。其余组合仍暂存首键，完成后吞掉触发键，错误第二键、超时或修饰键松开时还原首键事件并放行当前键。目标窗口／输入控件变化时取消，不向新输入区回放；正式注入按键不会再次触发。仅设置了 `SHANYU_TEST_DATA_DIR` 的 Debug 实例接受 `dwExtraInfo=0x53595141` 的验收按键，发送与回放使用内部标记 `0x53594E41`，监听忽略这些内部事件。主窗口和底栏的 WebView2 组合键回调共用原生匹配器，使搜索框中的序号组合键也能匹配。界面 Enter 提交将焦点移回目标时，原生层持续消费按住的 Enter 至松开，避免长按误发已有草稿。

主窗口通过 `sync_sequence_map` 同步前十个实际绘制槽位，文件为 null，并同步搜索加载／组合输入暂停状态；只有主窗口可写，隐藏后保留最后快照。`sequenceHotkeys` 与 `sequenceDirectSend` 默认为 false，`sequenceBindings` 默认为 Ctrl+1—9、Ctrl+0，空字符串表示单项关闭；旧设置与备份缺字段时由 Serde 填默认值。修改绑定或启用时检查序号、Alt 导航与话术快捷键冲突，失败保留原配置。搜索只启用序号绑定，编辑与模态输入暂停业务绑定；原生 `ManagementWindows` 分别记录设置、用户名和共享话术窗口句柄，全部关闭后恢复已保存配置，打开任一窗口也取消旧候选。

原生层按一级分类、无分组话术、二级分类及话术顺序缓存活动库，每种规范快捷键只监听一次。完整匹配始终打开候选，保存话术 ID、选中位置、触发窗口／控件及目标上下文。`get_shortcut_candidates`、`select_shortcut_candidate`、`submit_shortcut_candidate`、`cancel_shortcut_candidates` 与定向 `shortcut-candidates` 事件同步界面；原生键盘监听处理上下、数字、空格、Enter、Esc，选择不限时。候选窗口无激活且跳过任务栏，按文字光标、当前可见焦点控件、目标窗口可见区域的顺序定位。整窗大小的焦点容器不作为输入区；优先输入区上方6 DIP，下方回退，两侧不足时选较大一侧再夹边。窗口级回退在可见区域左下方内缩12 DIP，工作区边缘保留6 DIP。鼠标钩子及焦点核对取消外部交互；透传的触发键保持完整按下／松开链路，尚未松开的数字触发键不能作为选择键；松开后，数字、空格、Enter 优先操作话术候选，其他普通输入取消候选并放行。消费的选择键保持至松开，长按或重复提交不会重发。提交重新核对当前话术快捷键与目标，随后复用 `deliver_content` 的发送锁、剪贴板、分段和中断处理。

低级鼠标钩子安装在独立消息线程，通过`MsgWaitForMultipleObjectsEx`等待并立即响应输入；50毫秒超时仅用于检查退出状态。它不与30毫秒窗口跟随轮询共用线程，避免即使直接放行的鼠标移动也被轮询休眠和窗口查询拖慢。外部点击取消候选仍使用原有状态锁和检查，退出时卸载钩子并等待监听线程结束。

七种主题共用实色主窗口上下栏、中性正文、分段导航及32像素单行列表。主色用于上下栏和快捷键白字标记，七种主题的默认话术标题统一为暖橙色，一级分类使用浅杏普通底和深橙选中底；独立窗口及自绘弹窗标题栏同样使用主题实色白字，来源栏、侧栏及辅助表面使用主题浅色，正文保持白底。分组色条铺满列表，左侧发送列保持24像素，分组名称与话术图标统一从26像素处起。雾蓝灰默认主题的选中背景为 `#DFE8F0`，悬停为 `#F0F3F6`，选中行左侧保留主题色标记；话术、文件与搜索均在悬停时覆盖选中色，移出恢复，发送列始终预留。快捷键在独立文字容器中绝对定位，距其右侧4像素，不占标题与正文布局宽度，状态和来源位于容器外；正文预览的快捷键仍在标题栏。列表序号跟随话术字号，与文字基线及18像素话术图标垂直居中。新库话术字号默认14像素，已保存的字号及各级自定义颜色保持原值，空值及历史标题默认色 `#ff5100` 在显示时解析。候选 WebView 使用32像素表头、32像素行和28像素底栏，原生高度同步为 `62 + 32 × min(候选数, 10)` DIP，再复用目标DPI换算、工作区裁切和无激活定位。未增加设置项、SQLite字段、IPC类型或闪云协议，见[主题与验收说明](theme.md)。

## 吸附与运行

正文悬停预览优先显示在鼠标右下12 DIP处；右侧或下方空间不足时分别向左／向上翻转，最终外框限制在显示器工作区内。宽度不超过300 DIP，上下两侧较大的可用高度决定正文上限，长内容保留滚动。原生补偿客户区与外框差值，短文按实际内容收紧，不激活窗口、不改变输入目标。

主窗口的客户区逻辑宽高独立保存到默认本机数据根的 `window-size.json`，不跟随账号切换或数据目录迁移。只观察可见、未最小化／最大化的正常尺寸，稳定250毫秒后原子写入，退出时补存；贴边裁剪不改变客户区大小。启动先恢复逻辑尺寸，首次独立显示前刷新非客户区并按实际边框计算大小和居中位置，避免隐藏窗口的系统标题栏测量导致高度增加30 DIP或显示后跳动；首次可见时仍核对实际客户区，启动即吸附时高度继续跟随目标。安装器只在记录缺失时读取本次安装目录中运行的旧主窗口，在关闭旧进程前记录逻辑尺寸，安装后仍缺记录才写入，已有文件不覆盖，卸载保留。旧客户端已退出或最小化且无记录时无法还原历史大小。

最小化恢复入口由本机字段 `showFloatingOnMinimize` 控制，缺字段的新装／升级默认开启，与托盘开关独立。预创建唯一的 `minimized-float` WebView，入口直接挂载专用React组件，动态加载的主App不进入该页面；只读IPC `get_minimized_float_theme` 与既有设置通知维持主题，不读取话术、账号库或输入状态。小条固定88×34 DIP、6 DIP圆角及24 DIP图标、无激活、置顶，不占任务栏或Alt+Tab；超过6 DIP才进入系统拖动，本次拖动或指针取消后忽略双击，正常双击复用主窗口恢复队列。原生右键菜单的创建与展示防重入，避免WebView重复右键消息产生重叠菜单。`hide_minimized_float(permanent)` 临时隐藏只设置当前最小化的抑制状态，后台轮询与重复最小化不能解除；主窗口恢复后再次最小化才重置。永久隐藏持有库锁读取最新设置，只关闭设备库已有开关，保存失败恢复原生配置，不提交整份前端旧快照。

主动最小化、手动隐藏和明确还原经过同一原生控制队列；主动最小化意图独立于自动跟随模式，只有此意图与设置同时有效才显示小条。贴边裁剪／定位完成后再最小化，界面线程动作执行前复核意图，后续还原等待已排队动作结束。还原激活在窗口所属线程执行，自动跟随和拖动不走激活路径。托盘最小化继续隐藏底栏，普通最小化保留底栏规则。坐标仅以物理像素保存在设备库 `sync_meta.minimizedFloatPosition`，不进入个人同步或内容备份；拖动结束后由工作池事务写入，旧工作任务取得数据库锁后读取最新缓存，不能覆盖后来的位置。正常退出补存坐标，屏幕变化时按最近工作区与实际DPI修正位置。

独立主窗口支持左右贴边隐藏，与企业微信侧栏吸附分开。常用设置使用本机字段 `edgeAutoHide`（新装／升级默认开启）、`edgeRevealDelay`（0、500、1000毫秒，默认500）；旧 `autoHide`／`hideDelay` 仍只兼容读取。用户拖动结束后，可见边框位于工作区左右边缘内2 DIP以内，或已越过边缘但窗口仍与工作区相交，均进入贴边状态；展开时对齐所属工作区边缘，首次定位的12 DIP边距不触发。窗口保持完整尺寸，以约150毫秒滑到屏幕外并留下2 DIP边条；连续悬停满所选时间后展开，中途离开取消计时，反向滑动从当前帧继续。展开一旦开始，鼠标命中使用完整目标窗口外框（包含原生缩放边框），允许鼠标领先动画进入话术区；不能仅使用DWM可见内容区，否则鼠标仍在原生边框内时会被误判离开。收起时仍仅按当前可见区域判断，不扩大发起唤出的范围；鼠标重新进入尚可见的面板时立即恢复展开，仅在原生实际位置已完全收起时应用边条悬停等待，不能凭动画计时结束就继续从鼠标下方收走。

默认主窗口客户区304×718 DIP，在当前 Windows 可见边框约306×720 DIP；跨屏沿用 Tauri 的 DPI 调整，保持逻辑尺寸、随缩放增加物理像素，不额外固定像素大小。

贴边期间边条和面板临时置顶，鼠标悬停展开不激活、不抢输入焦点；退出贴边模式恢复用户原置顶选择，不改写设置。鼠标按键仅在实际命中主窗口或其持有捕获时暂停收起；菜单核对所属根窗口，输入标记还要求主窗口为前台，其他软件的点击和残留状态不会触发展开。贴边状态复用原生轮询，最多排队一帧到界面线程，统一执行区域裁剪及不激活的窗口移动。裁剪排除DWM不可见调整边框，并限制在所属工作区内；显示器工作区或DPI改变时取消旧状态，将完整窗口恢复到仍可访问的位置。主窗口拖动／调整大小、输入、菜单／弹窗、预览及发送期间暂停收起；独立设置窗口及其前台输入／菜单不阻止主窗口收起，其他管理窗口保留原有保护，管理窗口对业务快捷键的暂停不变。显式唤起立即展开，鼠标进入后离开或主窗口失焦才恢复自动收起；关闭开关、吸附切换、手动隐藏和最小化清除裁剪。非托盘最小化排在贴边恢复之后，避免未完成的窗口定位覆盖最小化。吸附侧栏始终完整展开，发送服务与目标校验不受此功能影响。

常用设置将系统缩放作为独立状态行展示“自动适配 Windows 缩放比例”，不提供无效开关；分段发送的三个预设为一行，自定义值独占下一行。发送间隔仍为0—10000毫秒，默认500毫秒，不增加逐条批量发送能力。

主窗口是窄侧栏，Tauri配置统一关闭最大化，避免标题栏／底栏双击将WebView放大后又被跟随定位缩小外框。单击拖动、自由调整及最小化保留，独立编辑／排序窗口沿用各自的窗口能力。原生跟随遇到已最大化的主窗口时，先用异步、不激活的显示命令还原，下一轮再读取正常尺寸并记录吸附前矩形；不能直接用定位命令缩小最大化窗口，也不能将其宽度记为用户侧栏宽度。

吸附按 `WXWork.exe` 和精确原生窗口类识别：主窗口 `WeWorkWindow`、普通独立聊天窗口 `WwStandaloneConversationWnd`、客户独立聊天窗口 `CRMCustomerStandaloneWindow`。主窗口和客户独立聊天类型已在本机企业微信核实，普通独立聊天类型来自客服宝的识别表。企业微信5.0.10未通过UIA或MSAA暴露输入框；5.0.12.6018主聊天窗口的原生COM只读复核也未发现文本或组字范围接口。参照实机客服宝的窗口级规则，主窗口内的通讯录、搜索及无消息输入框页面仍吸附，登录、独立图片／视频、搜索结果及未知窗口类型不吸附。不读取窗口标题、输入正文或消息列表，不依赖COM/UIA，也不要求输入框焦点。独立线程每250毫秒复核窗口类型、进程ID、可见性、最小化状态与有效尺寸；切换外部窗口立即作废旧结果，A→B→A不能接受旧查询，结论750毫秒未更新即失效。前台匹配使用目标句柄，不以同进程关系继承后台目标。隔离Debug客户端仅额外接受专用 `ShanyuDockHost.exe` 进程；WinForms包装类去掉框架前后缀后使用同一份精确名单，正式进程不能借用此例外。发送目标记录和通用发送服务继续独立于吸附识别。

后台定位、独立模式恢复和边框刷新使用SWP_ASYNCWINDOWPOS异步提交窗口消息，避免界面线程等待设置响应时与跟随线程的同步定位相互等待；跟随仍保留SWP_NOACTIVATE，不替换用户正在使用的输入焦点。点击侧栏或底栏可以正常获得焦点，目标关系继续保留。

企业微信的进程识别只出现在吸附服务中。后台显示状态明确区分自动跟随、手动独立显示和手动隐藏：开机自启进入自动跟随；普通启动通过显示队列主动唤起。自动跟随在目标激活后无激活地显示，目标最小化／关闭或切换其他程序时隐藏。闪语主窗口、编辑和设置窗口在前台时仅延续正在使用的目标，不重新吸附后台的旧目标。激活切换期间前台句柄可短暂为空，此时保留已建立且仍可见、未最小化的目标关系，避免点击侧栏时反向隐藏侧栏和底栏；实际切换其他程序后仍隐藏。无目标时托盘／快捷键可独立唤起，目标重新激活后恢复跟随；手动隐藏只能由明确唤起解除。关闭吸附按侧栏当前所属显示器恢复独立窗口与用户置顶设置；旧独立矩形与当前侧栏属于同一显示器时恢复旧位置，否则使用当前位置。坐标限制在当前工作区，超大窗口只保证左上角可访问，不压缩宽高。沿用当前物理尺寸与DPI，不再使用旧显示器DPI；主动关闭吸附已完成定位，不能再次触发首次独立显示的前台屏幕定位。目标关闭不改写吸附开关。每次进程首次独立显示前，将窗口定位在唤起时前台窗口所在显示器的工作区右侧，缺少前台窗口时使用鼠标屏幕；右边距12 DIP、垂直居中，尺寸按屏幕DPI转换；仅无历史记录的默认大小限制在工作区，已有尺寸不被压缩。首次定位与无激活显示在同一界面线程动作中完成，动作结束前跟随轮询不能提前显示旧位置；主动激活排在该动作之后，隐藏／最小化意图会取消尚未执行的显示。后续唤起保留用户位置。若先吸附再首次独立显示，使用退出吸附时提交的最新矩形及其DPI，避免异步定位未完成时读回旧矩形并二次缩放；已有吸附尺寸超出工作区时也不压缩。

吸附位置使用物理坐标，逻辑尺寸按闪语各面板自身DPI换算，与各自WebView的界面缩放一致。目标应用的窗口DPI可能固定，且目标与面板可分处不同显示器，因此不能借用目标DPI决定面板尺寸；无效DPI回退96。跨屏后由现有30毫秒跟随循环重新读取面板DPI和边框并校正几何，不新增显示器查询或DPI消息拦截。跟随位置优先使用DWM可见边框，并根据闪语自身外框与可见边框的差值换算SetWindowPos坐标，避免右侧间隙和底部横条两端缩短；边框动态读取，不写死DPI像素值。用户外框宽度以DIP保存，按侧栏自身DPI换算，只有GUI_INMOVESIZE表示真实用户调整大小时才更新；定位、DPI缩放和屏幕裁切不反写宽度。侧栏始终完整展开，旧autoHide、hideDelay字段只兼容读取，不触发收窄。实际进入目标吸附后，主窗口原生子类拦截系统移动及纵向调整命令，上下边不触发缩放、四角按左右边处理；启用自由调整时只能调整宽度，高度始终跟随目标。限制读取独立原子标记，不在窗口消息回调中等待设置或跟随锁；没有实际目标而独立显示、以及退出吸附时恢复正常移动和缩放。侧栏固定贴在目标指定的左右外侧，上下与目标完整对齐，宽度保留用户设置；不按工作区回挪、不自动换边或裁小宽高，目标纵向移出工作区也继续跟随。超出屏幕或被任务栏挡住的部分允许不可见，但不会移入目标内容。吸附期间侧栏和底栏的置顶层级只跟随目标，独立窗口的置顶设置在退出吸附后恢复。搜索上方区域收起时，同层顺序为目标、侧栏、底栏；仅显示底栏时紧邻目标后方。此时直接使用目标或已跟随的侧栏作为SetWindowPos锚点，避免任务栏等其他层窗口隐式提升普通吸附面板；搜索展开时仅底栏临时移到目标前方，具体几何与层级规则见下文。前台激活及仅改变层内顺序的点击都会重新同步，所有跟随操作保留SWP_NOACTIVATE。增加其他软件只扩展识别模块，不修改发送逻辑。

底部搜索／常用短语面板独立控制两项内容。底栏左右可见端点跟随目标；短语区域从目标可见底边向下排列，输入行位于短语下方。搜索聚焦时历史与结果互斥覆盖短语，更高时向上延伸，输入行屏幕坐标不变；离开搜索区域或窗口失焦时关闭覆盖层并保留关键词。搜索复用search_scoped_content的all结果，个人、授权共享及成员话术归入话术组，已关联的本地和云文件归入文件组；移除类型筛选。眼睛仅切换进程内收起状态，保留关键词，展开时重新查询；dockSearch设置才关闭整个入口。底部历史仅在搜索聚焦时显示，标题与清空按钮独占首行，标签按宽度自动换行，超高纵向滚动；点击历史或输入关键词后切换到独立结果面板，隐藏历史；结果面板带标题、关闭按钮与指向输入框的尖角，关闭时清空关键词、恢复历史并聚焦输入框。内部操作或结果菜单不收起浮层，主窗口历史显示规则不变。

底栏Grid布局上限420 DIP，短语和搜索覆盖层占同一网格并底部对齐，历史标签区最高76 DIP（另有标题行及内边距）、常用短语最高150 DIP、输入行30 DIP，结果区最高228 DIP并滚动。ResizeObserver测量总高度与覆盖层超过短语区域的高度（最小为0），set_common_dock_height校验窗口身份、总高度28—420 DIP及上方高度0—总高度减28 DIP；缺省上方高度为0。两值在同一锁内更新，跟随线程使用底栏自身DPI换算，并补偿原生可见边框占用的客户区高度，防止底部控件被裁掉。上方区域可见时底栏插到目标前方，收起后恢复目标、侧栏、底栏的顺序，始终保留SWP_NOACTIVATE与SWP_NOOWNERZORDER，避免调整共同所有者时把其他面板一起带到目标前面。置顶状态随目标，不全局置顶；切换其他程序、最小化、关闭目标或手动隐藏时同步隐藏。搜索继续复用PhraseRow和通用投递服务。“隐藏短语”保存dockCommon=false，整条短语区域一起隐藏，恢复通过界面设置；保存失败保留区域并显示中文错误。

## 增量设置、混合搜索与本机 MCP

`patch_settings` 在个人库／设备库锁内读取最新设置、合并类型明确的补丁、验证并执行必要的原生变化，返回库身份、实际设置与进程内通知序号。`settings-changed` 只替换设置；前端串行提交并按字段反馈，按通知序号拒绝旧回执和旧整库响应。账号同步仍使用专用事件与既有同步队列。普通偏好不加载整库，只有快捷键字段变化校验绑定。 设置窗口通过原生关闭事件等待同账号串行保存队列，等待期间新提交的设置也须完成；失败留窗，不自动重试，切号不续写旧队列。Tauri关闭监听的销毁权限仅授予设置窗口。

匹配表、候选话术与账号世代作为同一快照更新，实际内容变化会取消未完成序列。原生监听在检查快捷键上下文前，复用吸附识别结果同步仍在前台的企业微信目标和当前输入控件，不等待用户点击闪语；目标同步不依赖吸附开关，也不把无关外部窗口自动纳入非全局快捷键范围。

启动时在成员授权缓存、本机快捷键偏好及原生窗口服务初始化后、后台同步启动前调用统一 `refreshed` 入口，建立本人及成员的完整监听表。不能依赖成员内容变化通知补齐启动绑定：离线、服务端内容未变化或未开启本人同步时，这些通知可能不会发生。仍沿用账号世代、来源身份、授权范围和冲突校验，不定时重装监听。

候选前端按整组内容先测宽再测高，正常宽度240—360 DIP，最大外框为min(360 DIP, 工作区宽度×70%)；长内容省略，提示换行不撑宽。原生核验候选身份、布局身份、DPI与客户区边界，迟到测量不能重新打开已关闭的候选。目标窗口只提供工作区与输入锚点，候选尺寸按自身DPI换算，不能借用可能固定96 DPI的目标值。布局身份包含候选DPI与非客户区尺寸，跨屏更新后重新测量；过渡期间内容宽度不超过当前视口，保留数量、关闭按钮和底部提示。已接受的测量只保留在当前候选会话；已有焦点巡检复用尺寸跟随同屏移动，不发布快照、不重测正文。选择上下移动只滚动列表。

搜索复用 `search_scoped_content(all)` 和既有匹配规则，结果以来源、库、内容 ID 共同标识，执行使用各自内容引用。共享结果读取所属库权限和版本；个人结果操作个人库，成员结果只读，文件只修改关联。

`mcp` 使用官方 `rmcp` Streamable HTTP 服务，由 `axum` 绑定本机地址。独立凭据、Host／Origin 验证、每次请求账号与授权检查、版本检查和业务事务构成边界。授权配置与业务调用串行，停服关闭协议会话；共享写入固定账号上下文，个人写入固定库身份及修订号。素材打开后核对最终句柄路径，禁止越界和并发替换；失败只清理本次生成的副本，已有素材复用当前话术引用。安装交接与数据迁移共用活动互斥，阻止写入中重启。

云文件回收站清空复用逐文件永久删除接口：确认固定未筛选目录中的 ID 和名称，不包含确认后新增的文件；服务器继续校验管理员、回收状态及读取时名称；允许清理仍被引用的本体，保留删除标记和原话术引用。旧引用仍列入companyAssetIds以定位本机缓存，编辑与还原可保留原引用，新增引用被拒绝。界面报告部分失败，不自动重试不明确结果，无需调整闪云协议。


## 统一文件关联与目录改名（2026-10-16）

`linked_files.rs` 统一云端关联的身份过滤、素材准备及事务写入，`LinkedFile.cloud` 明确区分本地路径与服务器／用户／资产身份。`FileAssociation.tsx` 承担独立关联窗口，`CompanyPicker.tsx` 为编辑器建立带请求编号的选择窗口；二者共用 `CloudFileTable`。所有文件使用入口重新核验来源，未缓存只准备下载，批量复制不产生部分剪贴板结果。动态选择窗口纳入快捷键暂停、安装和迁移互斥，关闭一个不会解除其他窗口的暂停。

闪云的重命名事务校验操作者、活动状态和 `expectedName`，只修改目录及目录版本；`original_name` 保留上传幂等语义。共享话术先验证引用及生命周期，再规范名称；读取时解析当前目录，不批量修改历史快照。客户端目录名称按账号世代和目录版本更新，缓存字节按不可变 ID 复用，保留正在投递的旧路径。界面显示名、话术标题与个人附件副本各自独立。
