# 青羽主题与界面验收

2026-10-15，源码已实现，尚未正式发布；现有 v0.2.3 发布资产保持不变。

默认主题继续使用 `default`，展示名为“青羽（默认）”。七种主题共用中性浅色表面、分段导航与32像素单行列表，保留各自主色。通过浅色层次、中性文字与功能分组，与参考软件的连续彩色横条、密集小字和方框表单形成区别。

控件圆角6像素，分类标签与浮层8像素；阴影用于浮层及模态窗口，列表保持平整。搜索命中使用浅色底与字重强调，继承原文字颜色。话术、文件与搜索均在悬停时覆盖选中色，移出恢复；选中标记只绘制左侧2像素线，发送按钮始终占固定列。错误、永久删除及清空操作使用红色；危险确认按钮悬停后继续保持红色。

- 主窗口保持330×720、最小300×400 DIP。40像素浅色标题栏包含品牌图标和内容类型分段导航；来源轻量切换、柔和分类标签、灰色分组标题、32像素单行列表、36像素搜索框及中性底栏共用同一套颜色。
- 基础字号13像素，设置页面标题18像素；设置侧栏112像素，界面设置按面板、主题文字、分类列表及区域高度分组。常规表单及主要按钮32像素，窄窗口中标签与成对控件换行，内容区可滚动；最小编辑窗口保存按钮完整可达。
- 云文件使用对齐的32像素工具栏、中性表头与轻分隔。默认1000×650 DIP窗口完整显示10条记录和分页；最小760×480 DIP窗口保留表格滚动及分页操作。回收站、账号、指引、正文预览与候选共享相同视觉规则。
- 候选为32像素表头、32像素行、28像素底栏和2像素总边框。原生高度为 `62 + 32 × min(候选数, 10)` DIP，继续执行目标DPI换算、工作区裁切与无激活定位；超过10条独立滚动。

32像素行相较24像素行，在相同列表可用高度下约少显示25%的条目；实际数量还随分类换行和分组数量变化。单行标题与摘要控制这一代价。保留无额外焦点外框的约定，通过底色、明暗和图标呈现键盘位置及开关状态。Windows原生菜单和文件对话框继续由系统绘制，文件类型图标保留原识别色。

## 兼容与边界

共用CSS明确区分文字、操作、表面和状态颜色，复用原有主色变量。单条话术自定义色优先于全局自定义色，再由主题提供默认色；空值及不区分大小写的历史 `#ff5100` 均表示默认标记。分类自身背景优先于全局分类背景，空值使用主题默认背景。恢复标题默认仍保存历史标记，分类默认仍保存空值。

新库话术字号默认14像素，已有10—18像素字号、分类和短语区域高度设置保持原值。颜色只在显示时解析，不批量改写用户记录，不增加设置项、SQLite字段、IPC类型、主题枚举或Hub协议，沿用现有跨窗口刷新。发送、双击、快捷键、目标复核、菜单和搜索规则保持原有行为；自定义颜色保留用户选择，不强制调整其对比度。
