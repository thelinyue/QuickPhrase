# 雾蓝灰主题与界面验收

2026-10-15，源码已实现，尚未正式发布；现有 v0.2.3 发布资产保持不变。

默认主题继续使用 `default`，展示名为“雾蓝灰（默认）”。七种主题共用白色正文、分段导航与32像素单行列表，保留各自主色。主窗口上下栏与全部自绘独立窗口标题栏使用主题实色和白字；来源栏、侧栏及辅助区域使用同色系浅底，保留暖橙话术标题。

- 主窗口保持330×720、最小300×400 DIP。40像素实色标题栏包含品牌图标和内容类型分段导航，底栏同色。一级分类普通标签统一使用浅杏底深褐字，当前分类深橙底白字，悬停时底色加深；列表取消左右外边距，28像素分组色条无额外上下间距并铺满宽度。发送入口仍在左侧24像素固定列，展开箭头与其居中对齐；话术图标与分组名称均从26像素处起。话术行32像素、搜索框36像素保持原尺寸。
- 基础字号13像素，设置页面标题18像素；设置侧栏112像素，界面设置按面板、主题文字、分类列表及区域高度分组。常规表单及主要按钮32像素，窄窗口中标签与成对控件换行，内容区可滚动；最小编辑窗口保存按钮完整可达。
- 云文件使用对齐的32像素工具栏、中性表头与轻分隔。默认1000×650 DIP窗口完整显示10条记录和分页；最小760×480 DIP窗口保留表格滚动及分页操作。回收站、账号、指引、正文预览与候选共享相同视觉规则。
- 候选为32像素表头、32像素行、28像素底栏和2像素总边框。原生高度为 `62 + 32 × min(候选数, 10)` DIP，继续执行目标DPI换算、工作区裁切与无激活定位；超过10条独立滚动。

32像素行相较24像素行，在相同列表可用高度下约少显示25%的条目；实际数量还随分类换行和分组数量变化。单行标题与摘要控制这一代价。保留无额外焦点外框的约定，通过底色、明暗和图标呈现键盘位置及开关状态。Windows原生菜单和文件对话框继续由系统绘制，文件类型图标保留原识别色。

默认主题的上下栏与主操作悬停色由底色加深10%得到；其他六种主题保持原有颜色。列表序号取消固定11像素，随话术字号10—18像素变化，与标题、正文保持文字基线，并与18像素话术图标垂直居中。

## 兼容与边界

共用CSS明确区分文字、操作、表面和状态颜色，复用原有主色变量。所有标准标题栏、快捷键候选表头与回收确认标题采用实色白字；预览标题区域只用浅底，保持轻量浮层结构。单条话术自定义色优先于全局自定义色，再由主题提供默认色；空值及不区分大小写的历史 `#ff5100` 均表示默认标记。分类自身背景优先于全局分类背景，空值使用主题默认背景。恢复标题默认仍保存历史标记，分类默认仍保存空值。

新库话术字号默认14像素，已有10—18像素字号、分类和短语区域高度设置保持原值。颜色只在显示时解析，不批量改写用户记录，不增加设置项、SQLite字段、IPC类型、主题枚举或Hub协议，沿用现有跨窗口刷新。发送、双击、快捷键、目标复核、菜单和搜索规则保持原有行为；自定义颜色保留用户选择，不强制调整其对比度。

## 四个开关与预览高度

吸附、置顶、常用短语和搜索框分别维护保存状态，只禁用正在等待的按钮。写入串行执行，每次读取最新设置后合并当前开关，成功后主动刷新；失败提示中文错误并继续处理其他按钮。个人库切换后，尚未执行的旧库操作取消，保存参数仍携带发起库身份。

正文预览按标题与正文实际高度收紧，标题换行、字号变化及图片加载后重新测量。移除480 DIP／工作区65%的固定上限，以鼠标下方剩余工作区（扣除12 DIP间距、8 DIP屏幕边距和原生边框）作为最大高度；空间不足才滚动。保持鼠标右下方，不翻转、不向上挪动，水平方向超出屏幕仍裁切；下方没有可用客户区时不展示。
