# 导入导出（0.2.0，尚未发布）

设置统一使用“导入数据”和“导出数据”。每次选择一个个人库或共享话术，默认私人；从共享话术菜单进入会预选该库。个人库统一显示“个人话术”，已绑定时附所属账号。账号与同步只保留连接、同步、冲突和设置确认。

来源、目标、共享话术及分类统一使用两列表单，下拉框同宽同高；用户名并入个人库选项，不另列重复说明。离线共享话术保留简短状态提示。

## 导出范围

选择来源、共享话术（按需）、分类及格式，分类默认全部。

| 选择 | ZIP内容 |
|---|---|
| 本机个人库全部分类：完整备份 | 分类、话术、有序分段、图片、实际附件、常用短语、回收、个人及设备设置、独立文件路径关联 |
| 账号个人库全部分类：完整备份 | 当前本机分类、话术、有序分段、图片、实际附件、常用短语、回收、库内便携配置，含待同步修改及待确认值 |
| 私人指定一级分类：话术包 | 该分类、子分类、话术及实际素材；文件分类仅含路径关联 |
| 共享话术全部或指定分类：话术包 | 仅在用分类、话术及实际素材，不含回收、成员、角色或个人设置 |
| Excel | 仅文字，不能保存图片、附件和完整分段结构 |

私人导出不强制同步，也不使用服务端快照替代本机版本。账号包只写便携设置白名单，不写本机应用的旧值或设备字段。ZIP没有加密，不包含会话、凭据、账号权限或同步队列。独立文件库只保存路径关联，外部源文件需单独备份；话术附件保存实际内容。

开始时读取固定元数据和素材引用，素材复制到临时目录后打包。在线可补齐未缓存素材，离线必须全部齐备。单素材最多128MB，图片沿用16384像素及解码内存限制；下载共用两个许可。缺失、下载失败、取消或身份变化均停止，临时成品核验后才替换目标文件，已有备份保留。

## 导入和恢复

选择目标、共享话术（按需）、文件，查看预览后确认。普通导入生成独立副本，不覆盖现有内容；首次个人同步合并仍使用自己的保留ID规则。ZIP版本2继续兼容旧完整备份及服务器`private.json`个人包；不支持的版本提示升级。

“合并同级唯一同名分类”和“恢复个人设置／恢复设备设置”默认关闭。多项同名时独立导入并在预览提示。恢复设置仅限包内允许的范围；账号库只恢复便携字段，发送与快捷键通过“账号与同步→设置待确认”另行应用。系统快捷键占用不影响正文，未应用值不反写清空。回收记录导入后仍留在回收站。

旧完整备份明确选择“个人内容”或“本机文件与设备设置”：个人部分包含话术、素材、短语、回收和便携设置；设备部分只包含独立文件关联及设备设置，不进入个人同步。预览说明未选择的部分需要另行导入，两部分分别提交，不承诺跨数据库整包原子提交。设置恢复默认关闭，个人发送与快捷键仍需另行确认。

存在独立历史本机内容时，“找回旧本机内容”可将其预览后导入当前“个人话术”，不改变登录、活动库或同步开关；开启同步时预览明确提示随后上传到所属账号。默认生成独立副本，不合并同名分类、不恢复设置；重复发起可能产生副本，同批次重试保留原编号。原内容保留，正在使用的本机文件与设备设置不重复导入。共享话术导入要求联网、首次改密完成及编辑权限，只导入在用分类和话术，预览列出忽略的常用短语、回收、设置和文件关联。

## 批次、冲突与安全

预览一次生成副本ID及素材，保存于本机受控批次目录，确认和重试沿用；重启恢复上次预览。个人内容、待同步键及批次回执在同一SQLite事务提交，失败整批回滚，仅清理本批新增素材。库更新拒绝旧确认，“重新预览”在保留ID和素材的前提下重新核对。

共享话术复用现有批量发布事务，写前保存完整原请求。提交回执不明时显示“结果待确认”，核对本批ID和共享话术版本后再决定；不能盲目重发或新建副本。并发更新保留预览，重新核对后追加，不覆盖期间新增的内容。个人库、同一服务器账号的共享话术各自保留待处理批次；另一组有待确认批次时须先返回该库核对。

所有导入导出IPC携带私人`libraryId`或共享话术`teamId`、版本、生命周期及当前会话编号。切库、切号、撤权和删除共享话术使旧请求失效。新会话显式恢复原账号批次后，旧会话的确认仍被拒绝。注销及撤权清除相关共享话术快照、批次和缓存；已在执行的提交先取得确定回执或保留待核对状态，不宣称已取消成功。离线共享话术导出只使用此前授权且完整缓存的在用内容。

包内来源仅用于显示，不用于恢复账号身份、权限或队列。共享数据备份继续保存账号、共享话术和公司素材，完整运维恢复继续使用停服备份与世代核对；本次不新增Hub业务接口。

## 验证

执行README现有前端、TypeScript、桌面Rust与发布检查，构建含`custom-protocol`的隔离Debug客户端，再依次运行：

```powershell
$env:SHANYU_TEAM_SERVER_EXE = 'D:\code\QuickPhrase-hub\target\debug\shanyu-team-server.exe'
node scripts/verify-transfer.mjs
node scripts/verify-private.mjs
node scripts/verify-teams.mjs
```

报告及截图位于`.build`，使用真实WebView2、IPC、SQLite、HTTP及SSE。系统选文件对话框替换选择结果，断线及回执丢失由回环代理构造；不能替代真实企业微信、局域网、代理部署、DPI及安装升级验收。正式客户端和镜像仍由负责人手动发布。
