三张新增 PNG 均为1254×1254、32位 RGBA，角点 Alpha 为0；保留生成结果的透明通道。插画为装饰图，使用空 alt，状态含义由旁边文字和操作按钮提供。位置示意提供完整可访问描述。

吸附示意不操作原生窗口，只读取现有设置。快捷键说明将“按住修饰键”和“依次按下、松开普通键”分别展示，保持两键间隔不超过1秒的规则。此改动不添加接口、设置字段或数据库迁移。

回收站读取中、读取失败和搜索无结果均不显示空态插画。读取失败继续使用原有错误反馈，避免把失败显示成空回收站。

## 生成记录与最终提示词

使用内置 imagegen，透明背景选项为 true；每张分别生成。参考图为 [原始鹦鹉图标](../../src-tauri/icons/source.png)，仅用于角色身份与材质参考。文件与回收站素材按不同动作重新生成，未覆盖应用图标。以下是最终采用的提示词。

### phrase-empty.png

```text
用途：闪语 Windows 客户端的空态插画。参考图仅用于角色身份和材质参考，不是要替换应用图标。保留同一只青绿鹦鹉的大黑眼睛、浅薄荷绿脸部、橙黄色弯鸟喙、青绿羽毛与头顶冠羽，延续参考图柔和精致的3D黏土/绒面材质。画面只有一只鹦鹉和指定道具，角色友好克制。居中紧凑构图，完整呈现主体，四周约10%透明留白。为最终96—120像素小尺寸显示减少细节，轮廓清楚，柔和左上光，轻微贴地阴影。输出正方形高分辨率PNG，真实透明背景。不要参考图的奶油白圆角图标底板、边框、场景背景、文字、数字、logo、水印、装饰粒子或其他角色。场景：鹦鹉站在一张浅奶油色、浅蓝描边的简洁话术卡片旁，用翅膀轻轻扶着卡片；卡片上有一个空白对话气泡，表达准备添加第一条话术。鹦鹉侧身回望，鸟喙微张，与参考角色高度一致。
```

### files-empty.png

```text

```
