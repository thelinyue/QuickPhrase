## 评审操作

1. 在主列表选择第10行，再悬停第9行左侧黄色按钮并点击：操作记录应为第9行直接发送。
2. 双击行正文：只记录添加到输入区。快速双击黄色发送按钮：只提交一次发送动作。
3. 输入 ups：上方出现搜索结果浮层；上下键改变选中项，Enter 使用当前结果。
4. 在编辑器输入内容并插入日期、图片、文件和分段；保存后在主列表查看。
5. 查看设置及文件失效场景，确认本地版的菜单范围与展示密度。

## 本次验证

2026-10-10 使用本机 Edge 和 Playwright 完成浏览器交互检查，页面没有 JavaScript 运行错误；脚本通过 node --check。

- 选择第10行、悬停第9行发送：动作对应第9行，选中项不变，标题位置不跳动；双击发送按钮只记录一次发送，不产生插入。
- 正文双击只插入；右键与搜索结果发送使用所在行；搜索上下键、Enter、Esc、无结果和中文输入法组合事件均按约定处理。
- 编辑器保存有序文字、图片、文件和分段；标题可空、二级分类可不选；201字标题、5001字正文及第10张图片／第10个文件被拒绝。日期按系统本地时区插入，跨日期时区场景已检查。
- 分类新增、话术移动／复制／排序、标题配色及快捷键冲突提示通过；文件批量关联、重新打开文件选择器、失效阻止发送、重新关联及删除关联通过。
- 八个设置页在桌面评审尺寸下无横向溢出；默认 Enter、500毫秒可调整；显示设置反馈到列表。760像素宽的评审页保持330×720的主面板。

这些结果只验证评审页的界面与动作记录，不代表真实系统发送、剪贴板、吸附、托盘或导入导出已通过验收；Windows 10／11、多显示器、真实输入法与DPI、安装升级卸载的验收留待客户端实现后执行。

## 边界与后续

这是独立界面评审稿，不是已完成的客户端。发送、托盘、吸附、导入导出和缓存操作均未连接系统服务；页面外的操作记录明确展示演示动作。样例改动仅留在当前页面，刷新还原。

本次实施计划第1步的界面确认已完成。开发采用 React/TypeScript、Tauri 2、Rust、通用 Windows 发送、企业微信窗口吸附及 Inno Setup 安装器。

通用发送将统一使用 Windows 剪贴板和输入流程；软件识别只用于吸附。编辑器不加入表情、颜文字或正文染色工具。
